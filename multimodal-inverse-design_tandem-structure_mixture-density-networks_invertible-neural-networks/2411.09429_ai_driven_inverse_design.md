## Why this paper fits the topic "sequential variation propagation"

이 논문은 재료 역설계(inverse design of materials)에 대한 **포괄적 리뷰**로서, many-to-one 순방향 구조-물성 관계를 one-to-many로 뒤집을 때 발생하는 해의 다중성(ambiguity)을 다루는 핵심 방법론들—Tandem Network, MDN, INN, cGAN, Diffusion—을 체계적으로 비교한다. 각 접근법이 **분산(불확실성)을 어떻게 모델링하고 제어하는가**를 축으로 정리하여, sequential variation propagation의 방법론 지도를 제공한다.

## Methods

### 1. Forward vs Inverse 문제의 비대칭성

- **Forward**: 구조 `x` → 물성 `y` (many-to-one, well-posed)
- **Inverse**: 물성 `y` → 구조 `x` (one-to-many, ill-posed)
- Deterministic inverse model은 여러 유효 해의 비물리적 평균으로 수렴하는 문제(mode collapse / mode averaging)를 갖는다.

### 2. Tandem Network

Forward network를 먼저 학습한 뒤, Inverse network의 출력을 forward network에 통과시켜 target과의 차이로 학습:
```
Loss = MSE(Forward(Inverse(y)), y)
```
- 장점: forward model을 통한 물리적 자기 검증으로 비물리적 해를 걸러냄
- 한계: 여전히 deterministic → 다중 해 중 하나만 출력

### 3. Mixture Density Networks (MDN)

Inverse network의 출력을 Gaussian Mixture로 모델링:
```
p(x|y) = Σ_k π_k(y) · N(x; μ_k(y), σ²_k(y))
```
- 장점: 다중 해의 분포를 명시적으로 학습, 각 모드의 확률과 분산을 정량화
- 한계: mixture 수 K를 사전에 지정해야 하며, 고차원에서 학습이 불안정

### 4. Invertible Neural Networks (INN)

Bijective mapping을 학습하여 forward/inverse를 동시에 수행:
```
Forward: x → [y, z]    (z: latent ∼ N(0,I))
Inverse: [y, z] → x    (z를 변화시키면 다른 해 생성)
```
- 장점: 해의 다중성을 latent space z로 자연스럽게 모델링, posterior p(x|y) 직접 샘플링 가능
- RealNVP, GLOW 등 coupling-based 아키텍처 활용

### 5. 기타 생성 모델

- **cGAN**: 조건부 생성 → 다양한 해 생성, mode collapse 위험
- **VAE**: latent variable로 다중성 포착, posterior collapse 위험
- **Diffusion Models**: denoising을 통한 조건부 생성, 최신 state-of-the-art

### 6. 물리 제약 통합

물리 법칙을 loss에 통합하여 탐색 공간을 물리적으로 가능한 영역으로 제한:
- Physics-informed loss
- Conservation law constraints
- Symmetry priors

## Conclusion

- **Tandem Network**은 간결하지만 single-mode 한계가 있고, **MDN**은 multimodal posterior를 명시적으로 포착하며, **INN**은 가장 유연하게 full posterior를 제공한다.
- 각 방법의 선택은 해의 다중성 정도, 차원, 물리 제약의 강도에 따라 달라진다.
- 향후 방향: diffusion-based 역설계, multi-fidelity 학습, 실험과의 closed-loop 통합.
- 모든 방법의 공통 핵심은 **역문제의 분산을 어떻게 모델링하고 제어하느냐**이며, 이것이 곧 sequential variation propagation의 본질이다.
