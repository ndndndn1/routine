# Simulation Experiment Design for Calibration via Active Learning

- **arXiv:** [2407.18885](https://arxiv.org/abs/2407.18885)
- **저자:** Ozge Surer
- **발표일:** 2024-07-26
- **키워드:** active learning, sequential design of experiments, bayesian adaptive design, surrogate modeling
- **공식 코드:** 없음

## 배경

시뮬레이션 모델의 보정(calibration)은 비용이 큰 시뮬레이터를 반복 실행하여 파라미터의 사후분포를 추정하는 과정이다. 에뮬레이터(GP 서로게이트)로 비싼 시뮬레이터를 대체할 때, 어떤 입력에서 시뮬레이션 데이터를 추가로 수집할지가 에뮬레이터 품질과 보정 정확도를 좌우한다. 본 논문은 **능동 학습 기반 순차적 실험 설계**로 이 문제를 해결한다.

## Methods

1. **GP 에뮬레이터 기반 보정 프레임워크**
   - Kennedy-O'Hagan 프레임워크: 시뮬레이션 출력 = η(x, θ), 관측 = η(x, θ*) + δ(x) + ε
   - GP로 η를 근사하고, 사후분포 p(θ|data)를 MCMC로 샘플링
   - 에뮬레이터의 불확실성이 사후분포 추정에 직접 전파됨

2. **능동 학습 기준 (Active Learning Criteria)**
   - **기준 1: 사후 분산 최소화** — 현재 θ 사후분포 하에서 에뮬레이터 예측 분산의 기대값을 최소화하는 (x, θ) 선택
   - **기준 2: 사후 KL-발산 감소** — 새 시뮬레이션을 추가했을 때 θ 사후분포 변화(KL-발산)를 최대화
   - 두 기준 모두 θ의 사후분포를 고려하여, 보정에 중요한 영역에 시뮬레이션 예산을 집중

3. **순차적 설계 루프**
   - 초기 Latin Hypercube 설계로 GP 에뮬레이터 학습
   - θ 사후분포 추정 → 능동 학습 기준으로 다음 시뮬레이션 포인트 선택 → 시뮬레이터 실행 → GP 업데이트
   - 수렴까지 반복; 예산이 적을수록 능동 학습의 이점이 극대화

4. **비교 기준**
   - 공간 충전 설계(space-filling), 최대 분산(maximum variance), 임의 설계 대비 평가
   - 1D/고차원 시뮬레이터에서 사후분포 정확도와 샘플 효율성 비교

## Conclusion

- 사후분포 인지 능동 학습(기준 1, 2)이 공간 충전 설계 대비 적은 시뮬레이션 횟수로 더 정확한 보정 달성
- 기준 2(KL-발산)가 복잡한 다봉 사후분포에서 특히 효과적
- 에뮬레이터 불확실성을 보정 목적에 직접 연결함으로써, 시뮬레이션 예산의 효율적 배분 가능
- 비용이 큰 역문제에서 순차적 설계가 해의 다중성 억제에 핵심적 역할을 함을 실증

## 주제 연관성

순방향 시뮬레이터가 many-to-one일 때 보정(역문제)의 비유일성을 GP 서로게이트의 불확실성에 기반한 순차적 실험 설계로 효과적으로 축소한다. 능동 학습이 탐색 공간을 사후분포 고밀도 영역으로 집중시켜 분산 제어를 실현하는 전략.
