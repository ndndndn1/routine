# An Efficient Bayesian Framework for Inverse Problems via Optimization and Inversion: Surrogate Modeling, Parameter Inference, and Uncertainty Quantification

- arXiv: [2602.04537](https://arxiv.org/abs/2602.04537)
- Submitted: 2026-02-05 (within routine window 2024-04-20 ~ 2026-04-20)
- Authors: Mihaela Chiappetta, Alexander Raßloff, Massimo Carraturo, Markus Kaestner, Ferdinando Auricchio
- Categories: stat.ML, cs.CE
- Keywords matched (>=2): **bayesian optimization**, **surrogate modeling**

## Why this paper fits the topic "sequential variation propagation"

역문제에서 전방 모델(FEM, PDE solver 등)의 평가 비용이 높으면, posterior sampling을 위한 MCMC가 비실용적이 된다. 이 논문은 **Bayesian Optimization으로 GP surrogate를 적응적으로 구축**하되, **예측 불확실성이 높은 영역에 전략적으로 샘플링**을 집중한다. 그 결과 surrogate 기반 posterior가 true posterior에 빠르게 수렴하며, 역문제의 파라미터 불확실성(variation)이 출력에 전파되는 경로를 효율적으로 정량화할 수 있다.

## Methods

### 1. Problem: Bayesian Inverse Problem with Expensive Forward Model

관측 `y_obs`에서 파라미터 `θ`를 추론:

```
π(θ | y_obs) ∝ L(y_obs | G(θ)) · π_0(θ)
```

`G(θ)`가 비용이 크므로 (예: nonlinear FEM) 직접 MCMC가 불가 → GP surrogate `Ĝ(θ)`로 대체.

### 2. Phase 1: BO-guided Surrogate Construction

GP surrogate를 **Bayesian Optimization의 acquisition function**으로 적응적으로 구축:

```
for k = 1, ..., K:
    θ_k = argmax α(θ; GP_k)     # acquisition function
    y_k = G(θ_k)                 # expensive forward model
    GP_{k+1} = update(GP_k, θ_k, y_k)
```

Acquisition function: **uncertainty-weighted posterior relevance**

```
α(θ) = σ_GP(θ) · w(θ)
```

- `σ_GP(θ)`: GP posterior standard deviation (탐색: 불확실성이 큰 곳)
- `w(θ)`: posterior relevance weight (집중: posterior가 높은 곳)

이를 통해 posterior에 중요한 영역의 surrogate 정확도를 우선 개선.

### 3. Phase 2: Surrogate-based Inversion

구축된 GP surrogate 위에서 효율적 posterior sampling:

```
π̂(θ | y_obs) ∝ L̂(y_obs | Ĝ(θ)) · π_0(θ)
```

MCMC (Metropolis-Hastings 또는 emcee) 수행 — 각 likelihood 평가가 GP inference (O(n²))로 대체되어 수천~수만 sample 생성 가능.

### 4. Uncertainty Quantification

Surrogate 불확실성을 posterior에 전파:

```
Var_total[θ] = Var_MCMC[θ] + Var_surrogate[θ]
```

- `Var_MCMC[θ]`: MCMC sampling에 의한 posterior uncertainty
- `Var_surrogate[θ]`: GP surrogate 자체의 예측 불확실성이 posterior에 전파되는 양

이를 통해 surrogate 오차가 추론 결과에 미치는 영향을 명시적으로 정량화.

### 5. Validation

- Nonlinear heat conduction inverse problem (2D FEM)
- Elasticity parameter identification
- BO-guided surrogate vs. LHS-based surrogate vs. uniform grid surrogate 비교
- BO-guided 방식이 동일 forward model 호출 횟수에서 **posterior KL divergence를 크게 감소**
- Uncertainty propagation: GP variance가 posterior credible interval에 적절히 반영됨

## Conclusion

- **BO acquisition function**을 통한 적응적 surrogate 구축이 passive design 대비 inverse problem의 수렴 효율을 크게 향상.
- **Two-phase 접근**(surrogate 구축 → surrogate 위 MCMC)이 end-to-end MCMC 대비 forward model 호출을 **1-2 order of magnitude 감소**.
- Surrogate uncertainty를 posterior에 명시적으로 전파하여 **total uncertainty budget**을 관리 → variation propagation의 정량적 제어.
- 범용 프레임워크로 FEM, PDE solver 등 다양한 비용이 큰 전방 모델에 적용 가능.
