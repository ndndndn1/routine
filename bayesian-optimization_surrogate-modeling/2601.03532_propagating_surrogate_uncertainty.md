# Propagating Surrogate Uncertainty in Bayesian Inverse Problems

- **arXiv**: [2601.03532](https://arxiv.org/abs/2601.03532)
- **Authors**: Andrew Gerard Roberts, Michael Dietze, Jonathan H. Huggins
- **Submitted**: 2026-01-07
- **Keywords**: bayesian optimization, surrogate modeling, process variation

## Methods

This paper addresses a critical gap in surrogate-based Bayesian inference: when a computationally cheap surrogate replaces an expensive forward model, the surrogate's approximation error is typically ignored, leading to overconfident posterior estimates.

1. **Expected Posterior (EP) Formulation**: The authors propose the "expected posterior" distribution — a mixture distribution that integrates over the surrogate's uncertainty. Rather than treating the surrogate as a perfect substitute for the true forward model, the EP marginalizes over the distribution of possible surrogate errors, producing a posterior that honestly reflects both observational noise and model approximation uncertainty.

2. **RKpCN MCMC Algorithm**: A novel MCMC algorithm (Randomized Kernel preconditioned Crank-Nicolson) is developed for sampling from the expected posterior. Standard MCMC algorithms cannot directly handle the integrated-out surrogate uncertainty; RKpCN uses randomized kernel evaluations to efficiently propagate surrogate uncertainty through the sampling process.

3. **Quantifying Overconfidence**: The paper demonstrates through theory and experiments that ignoring surrogate uncertainty systematically underestimates posterior spread. This is particularly dangerous in inverse problems where the posterior is used for decision-making or design: an overconfident posterior can exclude the true parameter values.

4. **Gaussian Process Surrogate Integration**: The framework is instantiated with GP surrogates, where the posterior predictive distribution naturally provides uncertainty estimates. The GP's predictive variance directly feeds into the expected posterior computation.

5. **Computational Trade-offs**: The additional cost of propagating surrogate uncertainty through MCMC is analyzed, showing that the overhead is modest compared to the cost of generating more training data to reduce surrogate error.

## Conclusion

The expected posterior framework provides a principled mechanism for propagating surrogate approximation error into Bayesian inference, preventing the overconfident conclusions that arise from treating imperfect surrogates as exact. The RKpCN algorithm efficiently samples from the resulting integrated posterior with modest computational overhead. Experiments demonstrate that the standard practice of ignoring surrogate error can produce posteriors that fail to cover the true parameters, while the expected posterior maintains appropriate coverage. The approach is relevant to any inverse problem where computational constraints necessitate surrogate models, including engineering design under process variation.

import numpy as np
from sklearn.gaussian_process import GaussianProcessRegressor
from sklearn.gaussian_process.kernels import Matern

class ExpectedPosteriorSampler:
    def __init__(self, gp_surrogate, obs_data, obs_noise_std, param_bounds):
        self.gp = gp_surrogate
        self.obs = obs_data
        self.obs_noise = obs_noise_std
        self.bounds = param_bounds

    def log_expected_likelihood(self, params, n_draws=20):
        mu, std = self.gp.predict(params.reshape(1, -1), return_std=True)
        mu, std = mu.flatten(), std.flatten()
        total_var = std**2 + self.obs_noise**2
        log_ll = -0.5 * np.sum(
            (self.obs - mu)**2 / total_var + np.log(2 * np.pi * total_var)
        )
        return log_ll

    def log_prior(self, params):
        for i, (lo, hi) in enumerate(self.bounds):
            if params[i] < lo or params[i] > hi:
                return -np.inf
        return 0.0

    def rkpcn_step(self, current, step_size=0.1):
        dim = len(current)
        beta = np.sqrt(1 - step_size**2)
        noise = step_size * np.random.randn(dim)
        proposal = beta * current + noise
        proposal = np.clip(proposal, [b[0] for b in self.bounds],
                          [b[1] for b in self.bounds])
        log_alpha = (
            self.log_expected_likelihood(proposal) + self.log_prior(proposal)
            - self.log_expected_likelihood(current) - self.log_prior(current)
        )
        if np.log(np.random.rand()) < log_alpha:
            return proposal, True
        return current, False

    def sample(self, n_samples=1000, burn_in=500, step_size=0.1):
        dim = len(self.bounds)
        current = np.array([(b[0]+b[1])/2 for b in self.bounds])
        samples = []
        for i in range(n_samples + burn_in):
            current, _ = self.rkpcn_step(current, step_size)
            if i >= burn_in:
                samples.append(current.copy())
        return np.array(samples)

    def coverage_check(self, true_params, samples, level=0.95):
        dists = np.linalg.norm(samples - true_params, axis=1)
        threshold = np.percentile(dists, level * 100)
        covered = np.linalg.norm(
            np.mean(samples, axis=0) - true_params
        ) < threshold
        return covered, threshold
