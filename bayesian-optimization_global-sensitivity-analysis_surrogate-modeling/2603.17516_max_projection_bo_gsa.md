## Why this paper fits the topic "sequential variation propagation"

고차원 설계 공간에서 surrogate(GP) 기반 Bayesian optimization을 수행할 때, 파라미터 간 이방적(anisotropic) 영향력 차이가 해의 탐색 효율을 결정한다. 이 논문은 Polynomial Chaos Expansion (PCE) 기반 global sensitivity analysis (Sobol' indices)를 통해 영향력이 큰 파라미터 부분공간을 식별하고, 해당 부분공간에서 집중적으로 BO를 진행하여 탐색 공간 폭발을 억제한다. Maximum-projection initial design이 저차원 투영에서의 space-filling 특성을 보장하여 sparse data 환경에서도 surrogate 품질을 유지한다.

## Methods

### 1. Maximum-Projection Initial Design

- Latin Hypercube 기반이되 모든 저차원 투영(1D, 2D, …)에서 space-filling 최적화
- `MaxPro criterion: min Σ_{i<j} Π_{k=1}^{d} 1/|x_{ik} - x_{jk}|²`
- 이방적 파라미터 영향력 하에서도 초기 surrogate 품질 보장

### 2. Gaussian Process Surrogate

- Matérn 5/2 kernel + Maximum Likelihood Estimation (MLE)으로 hyperparameter 학습
- 330개 CFD 시뮬레이션 예산 하에서 순차적 실험 설계

### 3. Bayesian Optimization (UCB Acquisition)

- `α(x) = μ(x) + β·σ(x)` (Upper Confidence Bound)
- Exploration-exploitation tradeoff를 β로 제어
- 매 batch 평가 후 GP 갱신 → sequential design

### 4. Global Sensitivity Analysis via PCE

- Polynomial Chaos Expansion으로 Sobol' first-order 및 total-order sensitivity indices 계산
- `S_i = Var[E[Y|X_i]] / Var[Y]` (first-order)
- `S_{Ti} = 1 - Var[E[Y|X_{~i}]] / Var[Y]` (total-order)
- 높은 sensitivity 파라미터 부분공간 식별 → reduced subspace에서 BO 계속

### 5. Validation

- 방사형 터빈 효율 최적화: 85.77% → 91.77% (330회 CFD 예산)
- PCE GSA로 12개 설계 변수 중 4-5개가 전체 분산의 90% 이상 설명
- 축소된 부분공간에서의 BO가 전체 공간 BO 대비 30% 적은 예산으로 동등 성능 달성

## Conclusion

- Maximum-projection design + PCE GSA + GP-BO를 통합한 **3단계 data-efficient 설계 최적���** 워크플로우.
- GSA가 탐색 공간 차원을 효과적으로 축소하여 sparse data 환경에서의 BO 수렴 가속.
- 산업적 터빈 설계 문제에서 실용적 예산(330회) 내 유의미한 성능 향상 달성.
