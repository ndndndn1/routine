# Design-GenNO: A Physics-Informed Generative Model with Neural Operators for Inverse Microstructure Design

- **arXiv**: [2509.08749](https://arxiv.org/abs/2509.08749)
- **Authors**: Yaohua Zang, Phaedon-Stelios Koutsourelakis
- **Submitted**: 2025-09-10
- **Keywords**: physics-informed, invertible neural networks, multimodal inverse design, surrogate modeling

## Methods

Design-GenNO unifies generative modeling with operator learning for inverse microstructure design, addressing data scarcity through physics-informed training.

1. **Latent Space Encoding**: Microstructures are encoded into a low-dimensional, well-structured latent space. This latent space serves dual purposes: generating microstructures and predicting PDE solution fields. The compression removes redundant geometric detail while preserving structure-property linkages.

2. **MultiONet Decoders**: Two neural operator decoders (based on the DeepONet architecture) map latent variables to (a) reconstructed microstructures and (b) full PDE solution fields (e.g., temperature, stress). This enables evaluating multiple design objectives without retraining, since any functional of the solution field can be computed from the decoded output.

3. **Normalizing Flow Prior**: A normalizing flow (a class of invertible neural networks) regularizes the latent space, imposing a tractable probability distribution that enables efficient sampling and gradient-based optimization. The flow transforms a simple base distribution (Gaussian) into the complex manifold of physically valid microstructures.

4. **Physics-Informed Training**: PDE residuals are embedded directly into the training objective. By penalizing violations of governing equations (e.g., heat conduction, elasticity), the framework dramatically reduces reliance on labeled simulation data. In the extreme case, it can operate in a self-supervised setting with zero labeled examples.

5. **Diverse Inverse Design**: Given a target property (e.g., effective conductivity), the framework generates diverse microstructures by sampling from the posterior distribution in latent space. The normalizing flow enables computing the exact likelihood of each design, facilitating principled selection among multiple valid solutions.

## Conclusion

Design-GenNO achieves high accuracy in inverse microstructure design while generating physically meaningful and diverse solutions across a suite of tasks: effective property matching, microstructure recovery from sparse measurements, and conductivity ratio maximization. The physics-informed training strategy enables operation with minimal labeled data, with the self-supervised mode eliminating the need for pre-computed simulation labels entirely. The normalizing flow prior provides a principled mechanism for navigating the one-to-many nature of inverse design, and the neural operator decoders enable flexible multi-objective optimization without retraining. The method consistently outperforms state-of-the-art approaches in both accuracy and diversity of generated designs.

import torch
import torch.nn as nn
from torch.distributions import Normal

class LatentEncoder(nn.Module):
    def __init__(self, input_channels, latent_dim, hidden=128):
        super().__init__()
        self.conv = nn.Sequential(
            nn.Conv2d(input_channels, 32, 4, 2, 1), nn.SiLU(),
            nn.Conv2d(32, 64, 4, 2, 1), nn.SiLU(),
            nn.Conv2d(64, hidden, 4, 2, 1), nn.SiLU(),
            nn.AdaptiveAvgPool2d(1),
        )
        self.fc_mu = nn.Linear(hidden, latent_dim)
        self.fc_logvar = nn.Linear(hidden, latent_dim)

    def forward(self, x):
        h = self.conv(x).squeeze(-1).squeeze(-1)
        return self.fc_mu(h), self.fc_logvar(h)

class AffineCouplingLayer(nn.Module):
    def __init__(self, dim, hidden=128):
        super().__init__()
        self.split = dim // 2
        self.net = nn.Sequential(
            nn.Linear(self.split, hidden), nn.SiLU(),
            nn.Linear(hidden, hidden), nn.SiLU(),
            nn.Linear(hidden, (dim - self.split) * 2),
        )

    def forward(self, x):
        x1, x2 = x[:, :self.split], x[:, self.split:]
        params = self.net(x1)
        s, t = params.chunk(2, dim=-1)
        s = torch.tanh(s)
        y2 = x2 * torch.exp(s) + t
        log_det = s.sum(dim=-1)
        return torch.cat([x1, y2], dim=-1), log_det

    def inverse(self, y):
        y1, y2 = y[:, :self.split], y[:, self.split:]
        params = self.net(y1)
        s, t = params.chunk(2, dim=-1)
        s = torch.tanh(s)
        x2 = (y2 - t) * torch.exp(-s)
        return torch.cat([y1, x2], dim=-1)

class NormalizingFlowPrior(nn.Module):
    def __init__(self, dim, n_layers=6):
        super().__init__()
        self.layers = nn.ModuleList([AffineCouplingLayer(dim) for _ in range(n_layers)])
        self.base_dist = Normal(torch.zeros(dim), torch.ones(dim))

    def forward(self, x):
        log_det_total = 0
        for layer in self.layers:
            x, log_det = layer(x)
            log_det_total += log_det
        log_prob = self.base_dist.log_prob(x).sum(-1) + log_det_total
        return x, log_prob

    def sample(self, n):
        z = self.base_dist.sample((n,))
        for layer in reversed(self.layers):
            z = layer.inverse(z)
        return z

class PhysicsLoss:
    @staticmethod
    def heat_residual(u_field, k_field, source, dx=1.0):
        laplacian = (
            torch.roll(u_field, 1, -1) + torch.roll(u_field, -1, -1) +
            torch.roll(u_field, 1, -2) + torch.roll(u_field, -1, -2) -
            4 * u_field
        ) / dx**2
        residual = k_field * laplacian + source
        return torch.mean(residual**2)
