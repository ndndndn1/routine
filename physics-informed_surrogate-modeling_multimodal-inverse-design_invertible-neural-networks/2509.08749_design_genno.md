## Why this paper fits the topic "sequential variation propagation"

역방향 미세구조 설계는 전형적인 일대다(one-to-many) 문제이다: 동일한 유효 물성을 생성하는 미세구조가 무수히 많다. Design-GenNO는 **normalizing flow prior** 로 잠재공간을 정규화하고, **물리 잔차(PDE residual)를 학습 목적함수에 직접 내장**하여 라벨 데이터 의존성을 줄이면서 다양하고 물리적으로 유효한 설계를 생성한다. 이는 역문제의 해 다중성에서 비롯되는 분산을 물리 법칙으로 제약하여 억제하는 접근이다.

## Methods

### 1. Latent Space Encoding

미세구조를 저차원 잠재 벡터 **z** 로 인코딩:

```
z = Encoder(microstructure)
```

- 잠재공간에 **normalizing flow prior** 를 부여하여 분포를 정규화
- flow의 가역성(invertibility)으로 잠재공간↔데이터 공간 양방향 매핑 보장

### 2. MultiONet-based Decoders

하나의 잠재 벡터로부터 두 가지 출력을 동시에 생성하는 이중 디코더:

```
Decoder_μ(z) → microstructure reconstruction
Decoder_u(z) → PDE solution field u(x)
```

- MultiONet: 복수 출력에 대응하는 neural operator 구조
- 설계 목표가 달라져도 디코더만 교체하면 되므로 **재훈련 불필요**

### 3. Physics-Informed Training

PDE 잔차를 loss에 직접 포함:

```
L = L_recon + λ_phys · L_PDE + λ_flow · L_NF

L_PDE = ||R(u; microstructure)||²   (PDE residual)
L_NF  = -log p_flow(z)              (normalizing flow likelihood)
```

- **self-supervised** 설정에서도 작동: 라벨 없이 PDE 잔차만으로 학습 가능
- 물리 법칙이 탐색 공간을 제약 → 비물리적 해를 자동 배제

### 4. Gradient-based Inverse Design

학습된 모델로 역설계 수행:

```
z* = argmin_z ||Property(Decoder_μ(z)) - target||²
```

- normalizing flow prior 덕분에 잠재공간에서의 gradient descent가 안정적
- **다양한 z* 초기값**에서 출발하면 복수의 유효한 설계를 획득 (multimodal)

### 5. 검증

- 비선형 동역학 분기(bifurcation), 확률적 PDE, 원자 스케일 충격 역학에서 평가
- 기존 SOTA (cGAN, cVAE, TopOpt) 대비 **물리적 유효성과 설계 다양성 모두 우수**
- 학습 분포 밖 물성에 대해서도 외삽(extrapolation) 능력 확인

## Conclusion

- 생성 모델 + neural operator + 물리 잔차의 통합 프레임워크로, 역설계의 해 다중성을 **다양하면서도 물리적으로 유효한 설계 후보 집합**으로 전환.
- normalizing flow prior가 잠재공간의 분포를 제어하여 탐색 효율을 높이고, PDE 잔차가 비물리적 해를 걸러냄.
- 라벨 데이터 없는 self-supervised 학습이 가능하여, 고비용 시뮬레이션 예산이 제한된 상황에서 특히 유용.
