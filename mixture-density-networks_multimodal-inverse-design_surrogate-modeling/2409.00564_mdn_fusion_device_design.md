# Using Deep Learning to Design High Aspect Ratio Fusion Devices

- **arXiv**: https://arxiv.org/abs/2409.00564
- **Authors**: P. Curvo, D. R. Ferreira, R. Jorge
- **Published**: 2024-08
- **Categories**: physics.plasm-ph, cs.LG
- **Keywords**: mixture density networks, multimodal inverse design, surrogate modeling

## Methods

본 논문은 stellarator(비축대칭 핵융합 장치) 설계를 역문제(inverse problem)로 정의하고, Mixture Density Networks(MDN)를 활용하여 일대다(one-to-many) 매핑의 본질적 다중성을 확률적으로 처리한다.

핵심 구성:
1. **Forward Surrogate Model**: Near-axis expansion (NAE) 모델을 기반으로 한 고속 물리 서로게이트. 입력 파라미터(자기장 구성)에서 구속 성능(물성)을 예측.
2. **Inverse Design via MDN**: 목표 물성(타겟) → 설계 파라미터의 역매핑을 MDN으로 학습.
   - MDN은 조건부 확률 p(x|y)를 Gaussian mixture로 모델링: p(x|y) = Σ_k π_k(y) · N(x; μ_k(y), σ_k(y))
   - 각 mixture component가 역문제의 서로 다른 해 모드(mode)를 포착.
   - 다대일 순방향 매핑으로 인한 비유일성(non-uniqueness)을 자연스럽게 표현.
3. **Design Constraints**: 생성된 설계 후보의 물리적 타당성을 forward model로 검증. 낮은 elongation, 높은 rotational transform, 유한 plasma beta, 우수한 fast particle confinement 등의 조건 확인.
4. **Multi-objective Selection**: MDN이 생성한 복수의 해 모드 중에서 추가 목적함수(예: 공학적 실현 가능성)를 기준으로 최적 설계 선택.

다중성 억제 전략:
- MDN의 mixture 가중치 π_k(y)가 각 모드의 상대적 likelihood를 학습 → 비현실적 모드 자동 억제.
- 물리 서로게이트 기반 사후 검증으로 비유효 해 필터링.
- 적은 수의 mixture component(K=5~10)로도 주요 해 모드 포착 가능 → 탐색 공간 축소.

## Conclusion

- MDN 기반 역설계가 stellarator 구성을 신뢰성 있게 생성함을 실증.
- Non-uniqueness를 확률적으로 모델링하여 단일 해 방식 대비 설계 공간의 다양성과 커버리지 향상.
- Forward model 기반 검증과 결합하여 물리적으로 유효한 설계만 추출.
- 기존 최적화 기반 접근법(evolutionary algorithm 등) 대비 계산 비용 대폭 절감.
- High aspect ratio 조건에서의 설계 자유도와 구속 특성 간의 trade-off를 MDN이 효과적으로 학습.
- 한계: NAE 모델의 근사 범위에 한정. Full MHD 시뮬레이션과의 괴리 가능.

## Code

공식 코드 미공개. 아래는 MDN 기반 역설계 파이프라인 재현 구현.

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
import numpy as np
from torch.distributions import Normal, Categorical, MixtureSameFamily, Independent


class MixtureDensityNetwork(nn.Module):
    """MDN for inverse design: maps target properties to design parameter distributions."""
    def __init__(self, target_dim, design_dim, n_components=8, hidden_dim=256):
        super().__init__()
        self.design_dim = design_dim
        self.n_components = n_components

        self.shared = nn.Sequential(
            nn.Linear(target_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
        )
        # Mixture weights
        self.pi_head = nn.Linear(hidden_dim, n_components)
        # Means
        self.mu_head = nn.Linear(hidden_dim, n_components * design_dim)
        # Log standard deviations
        self.log_sigma_head = nn.Linear(hidden_dim, n_components * design_dim)

    def forward(self, target):
        h = self.shared(target)
        pi = F.softmax(self.pi_head(h), dim=-1)
        mu = self.mu_head(h).view(-1, self.n_components, self.design_dim)
        log_sigma = self.log_sigma_head(h).view(-1, self.n_components, self.design_dim)
        sigma = torch.exp(log_sigma).clamp(min=1e-4, max=5.0)
        return pi, mu, sigma

    def get_distribution(self, target):
        pi, mu, sigma = self.forward(target)
        mix = Categorical(probs=pi)
        comp = Independent(Normal(mu, sigma), 1)
        return MixtureSameFamily(mix, comp)

    def log_prob(self, target, design):
        dist = self.get_distribution(target)
        return dist.log_prob(design)

    def sample(self, target, n_samples=100):
        dist = self.get_distribution(target)
        return dist.sample((n_samples,)).transpose(0, 1)

    def sample_per_mode(self, target, n_per_mode=10):
        """Sample from each mixture component separately."""
        pi, mu, sigma = self.forward(target)
        all_samples = []
        for k in range(self.n_components):
            comp_dist = Normal(mu[:, k, :], sigma[:, k, :])
            samples = comp_dist.sample((n_per_mode,)).transpose(0, 1)
            weights = pi[:, k].unsqueeze(-1).unsqueeze(-1).expand_as(samples)
            all_samples.append((samples, weights))
        return all_samples


class ForwardSurrogate(nn.Module):
    """Surrogate for NAE-based stellarator physics."""
    def __init__(self, design_dim, property_dim):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(design_dim, 256),
            nn.ReLU(),
            nn.Linear(256, 256),
            nn.ReLU(),
            nn.Linear(256, property_dim),
        )

    def forward(self, design):
        return self.net(design)


def train_mdn(mdn, forward_model, dataset, epochs=500, lr=1e-3):
    """Train MDN using negative log-likelihood on (target, design) pairs."""
    optimizer = torch.optim.Adam(mdn.parameters(), lr=lr)
    scheduler = torch.optim.lr_scheduler.CosineAnnealingLR(optimizer, epochs)

    for epoch in range(epochs):
        total_loss = 0
        for designs, targets in dataset:
            optimizer.zero_grad()
            nll = -mdn.log_prob(targets, designs).mean()
            nll.backward()
            torch.nn.utils.clip_grad_norm_(mdn.parameters(), 1.0)
            optimizer.step()
            total_loss += nll.item()
        scheduler.step()
    return mdn


def inverse_design_pipeline(mdn, forward_model, target_properties, n_candidates=200,
                            feasibility_threshold=0.05):
    """
    Full inverse design: MDN sampling + forward model validation.
    Handles one-to-many ambiguity by sampling multiple modes.
    """
    target = torch.FloatTensor(target_properties).unsqueeze(0)

    # Sample candidates from MDN
    candidates = mdn.sample(target, n_samples=n_candidates).squeeze(0)

    # Validate via forward model
    with torch.no_grad():
        predicted_props = forward_model(candidates)
    target_expanded = target.expand_as(predicted_props)
    errors = (predicted_props - target_expanded).abs().mean(dim=-1)

    # Filter feasible designs
    feasible_mask = errors < feasibility_threshold
    feasible_designs = candidates[feasible_mask]
    feasible_errors = errors[feasible_mask]

    # Rank by reconstruction error
    if len(feasible_designs) > 0:
        ranked_indices = feasible_errors.argsort()
        return feasible_designs[ranked_indices], feasible_errors[ranked_indices]
    else:
        # Relax threshold and return best candidates
        ranked_indices = errors.argsort()[:10]
        return candidates[ranked_indices], errors[ranked_indices]


def analyze_mode_diversity(mdn, target_properties):
    """Analyze diversity of solutions across MDN mixture components."""
    target = torch.FloatTensor(target_properties).unsqueeze(0)
    pi, mu, sigma = mdn(target)

    # Mode statistics
    mode_info = []
    for k in range(mdn.n_components):
        mode_info.append({
            'weight': pi[0, k].item(),
            'mean': mu[0, k].detach().numpy(),
            'std': sigma[0, k].detach().numpy(),
        })

    # Inter-mode distance (diversity measure)
    distances = []
    for i in range(len(mode_info)):
        for j in range(i + 1, len(mode_info)):
            d = np.linalg.norm(mode_info[i]['mean'] - mode_info[j]['mean'])
            distances.append(d)

    return mode_info, np.mean(distances) if distances else 0.0
```
