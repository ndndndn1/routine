## Why this paper fits the topic "sequential variation propagation"

역방향 one-to-many 역설계에서 deterministic inverse network는 여러 해 사이의 비물리적 평균으로 수렴하는 고질적 ambiguity 문제를 갖는다. Tandem Network(forward + inverse cascade)는 forward 모델의 gradient를 통해 inverse network의 예측을 자기 검증(self-validation)함으로써 이 ambiguity를 완화한다. AutoTandemML은 여기에 **active learning**을 결합하여 (i) surrogate의 불확실성이 큰 영역을 우선 샘플링하고, (ii) 결과적으로 학습 데이터 효율성을 높이면서 탐색 공간 폭발을 억제한다. 즉, *데이터 수집 단계에서부터 분산 제어를 수행*하는 sequential variation propagation 전략이다.

## Methods

### 1. Tandem Neural Network (TNN) 구조

두 개의 DNN을 직렬로 연결한 구조:

1. **Inverse DNN (IDNN)**: 목표 응답 `y → x̂` (design parameter 예측)
2. **Forward DNN (FDNN)**: 예측된 설계 변수를 순방향 재평가 `x̂ → ŷ`
3. **Training loss**: `L = MSE(ŷ, y)` — forward 모델을 통한 자기 검증

이 구조는 one-to-many mapping을 forward 모델의 many-to-one 방향으로 "정규화"하여, deterministic inverse model이 빠지기 쉬운 multimodal average 해를 방지한다.

### 2. Active Learning 데이터 생성

학습 데이터를 **능동적으로 선택**하여 surrogate 품질을 극대화:

```
while budget remains:
    1. Train current TNN on D_train
    2. Compute uncertainty/error over candidate pool
    3. Select most informative candidates → evaluate with HF simulator
    4. D_train ← D_train ∪ new_samples
```

Active learning은 기존의 Random, Latin Hypercube, Best Candidate, GreedyFP 샘플링 대비 동일 예산에서 더 낮은 forward prediction error를 달성한다.

### 3. 벤치마크

세 가지 역설계 문제에서 검증:
- **Airfoil Inverse Design (AID)**: 공력 형상 → 압력 분포의 역변환
- **Photonic Surfaces Inverse Design (PSID)**: 반사율 스펙트럼 → 나노구조 파라미터
- **Scalar Boundary Reconstruction (SBR)**: 확산 PDE의 경계 조건 역추정

## Conclusion

- Active learning + TNN 조합이 세 가지 벤치마크 중 두 개에서 최고 성능, 나머지 하나에서도 경쟁적 성능을 달성.
- 반복 실험에서 **분산이 낮아** 안정적인 결과를 제공 — 역설계의 실무 활용에 중요한 특성.
- TNN의 자기 검증(forward re-evaluation)이 one-to-many ambiguity를 억제하고, active learning이 탐색 공간의 효율적 축소를 담당.
