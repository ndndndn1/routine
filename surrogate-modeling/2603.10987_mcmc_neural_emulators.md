# MCMC Informed Neural Emulators for Uncertainty Quantification in Dynamical Systems

- **일자(발표):** 2026-03-11
- **저자:** Heikki Haario, Zhi-Song Liu, Martin Simon, Hendrik Weichel
- **링크:** https://hf.co/papers/2603.10987  (arXiv id: 2603.10987)
- **search 기준일:** 2026-04-15 (±1 month window, 경계 근접 포함)

## 매칭된 키워드 (2개)

- `surrogate modeling` — neural emulator가 물리 모델의 surrogate
- `bayesian optimization` / `bayesian adaptive design` 계열 — **MCMC 기반
  파라메트릭 UQ** (가중치 샘플링이 아닌 **모델 파라미터**의 posterior
  sampling)
  - Bayesian adaptive design의 핵심 장치인 MCMC posterior inference을
    neural emulator 위에서 수행한다는 점에서 매칭.

## 주제 적합성 (variation propagation)

물리/역학 모델 **파라미터의 불확실성(변동)을 관측 예측값으로 전파**하는 것이
핵심. 고비용 physical simulator 대신 neural emulator로 대체하면 MCMC가
실용적 시간 내에 가능해져, 대규모 파라미터 변동 전파를 가능하게 함.

## Methods

1. 기존 simulator의 surrogate로서 3가지 emulator 구조 비교:
   - **Quantile emulator** — 분포 quantile을 직접 회귀.
   - **ODE network emulator** — ODE 구조를 반영한 신경망.
   - **Autoencoder-based ODE network** — 잠재 공간에서 ODE 역학을 학습.
2. UQ는 **신경망 가중치**가 아니라 **물리 모델 파라미터 θ**의 MCMC
   sampling으로 수행 → posterior p(θ | data) 획득.
3. emulator의 저비용 forward pass로 MCMC를 가속화하여 고차원/고비용
   파라미터 공간의 variation propagation을 실시간급으로 처리.

## Key results / Conclusion

- Full physical simulator를 쓴 MCMC 대비 **큰 속도 향상**을 얻으면서
  posterior 추정 정확도를 유지.
- 가중치 기반 Bayesian NN에 비해, 물리 파라미터를 직접 MCMC로 샘플링하는
  방식이 **물리적으로 해석 가능한 variation 전파**를 제공.
- Autoencoder-based ODE network가 동역학 모델에서 가장 안정적인 trade-off.
