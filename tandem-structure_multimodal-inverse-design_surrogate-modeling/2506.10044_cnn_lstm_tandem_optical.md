## Why this paper fits the topic "sequential variation propagation"

다층 박막(multilayer thin film) 광학 역설계에서, 하나의 목표 스펙트럼에 대해 multiple 구조 해가 존재하는 전형적인 one-to-many 문제다. 직접 역매핑을 학습하면 다중해의 평균으로 수렴하여 어느 해도 정확하지 않은 문제가 발생한다. CNN-LSTM Tandem 구조는 forward model(순방향 surrogate)을 먼저 학습한 뒤, inverse network의 출력을 forward surrogate에 통과시켜 목표 스펙트럼과의 일치도로 학습함으로써 one-to-many 다중성을 우회한다. CNN이 공간적 특징을, LSTM이 스펙트럼의 순차적 의존성을 포착하여 기존 MLP tandem 대비 성능을 향상시킨다.

## Methods

### 1. Tandem Architecture

- **Forward Network** (surrogate): 구조 파라미터 → 스펙트럼 예측
  - CNN layers로 층간 상호작용 포착 + LSTM으로 파장별 순차 의존성 모델링
- **Inverse Network**: 스펙트럼 → 구조 파라미터 예측
  - 대칭적 CNN-LSTM 아키텍처
- **Tandem Training**: inverse output → pretrained forward network → 스펙트럼 재구성 loss
  - `L = ||S_target - F(I(S_target))||²`
  - Forward network 가중치 고정, inverse network만 학습

### 2. One-to-Many Problem Handling

- 직접 inverse loss `||θ_true - I(S)||²` 대신 tandem loss 사용
- 다중해 중 하나를 선택하되 forward consistency를 보장
- Tandem 구조가 multiple valid solutions 중 forward model과 일치하는 해를 자연스럽게 선택

### 3. CNN-LSTM Hybrid

- **CNN**: 1D convolution으로 인접 층(layer) 간 물리적 상호작용 포착
  - Kernel size = 3-5, multiple channels
- **LSTM**: 스펙트럼의 파장 축을 시계열로 취급, long-range spectral correlation 학습
  - Bidirectional LSTM으로 양방향 의존성 포착

### 4. Validation

- 다층 박막 광학 필터 역설계 (SiO₂/TiO₂ alternating layers)
- 층 수 및 두께 동시 예측
- MLP tandem, pure CNN tandem, pure LSTM tandem 대비 MSE 15-30% 감소
- Transfer matrix method (TMM) 기반 ground truth와 비교

## Conclusion

- CNN-LSTM Tandem 구조가 **multilayer thin film 광학 역설계**의 one-to-many 다중성을 효과적으로 처리.
- Forward surrogate의 물리적 일관성을 활용하여 다중해 중 유효한 해를 자연스럽게 선택.
- CNN의 공간적 특징 추출과 LSTM의 순차적 의존성 모델링의 시너지가 기존 tandem 구조를 능가.
