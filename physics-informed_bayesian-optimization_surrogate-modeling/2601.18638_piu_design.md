# Physics-Informed Uncertainty Enables Reliable AI-driven Design

- **arXiv:** [2601.18638](https://arxiv.org/abs/2601.18638)
- **저자:** Tingkai Xue, Chin Chun Ooi, Yang Jiang, Luu Trung Pham Duong, Pao-Hsiung Chiu, Weijiang Zhao, Nagarajan Raghavan, My Ha Dao
- **발표일:** 2026-01-26
- **키워드:** physics-informed, bayesian optimization, surrogate modeling
- **공식 코드:** 없음

## 배경

주파수 선택 표면(FSS) 등 전자기 메타물질의 역설계에서 딥러닝 서로게이트가 설계 최적화를 가속하지만, 데이터 희소 영역에서의 잘못된 예측이 최적화 실패의 주원인이다. 기존 불확실성 정량화(UQ) 방법(앙상블, MC-dropout 등)은 추가 계산 비용이 크고 물리적 의미가 부족하다. 본 논문은 **물리 법칙 위반 정도** 자체를 불확실성의 대리 지표로 사용하는 새로운 패러다임을 제안한다.

## Methods

1. **Physics-Informed Uncertainty (PIU)**
   - 서로게이트 모델의 예측이 기본 물리 법칙(Maxwell 방정식 등)을 얼마나 위반하는지 계산
   - PIU = ||F(ŷ)||² (F: 물리 법칙 연산자, ŷ: 서로게이트 예측)
   - 물리 위반이 클수록 예측 불확실성이 높다고 판단 → 추가 훈련 데이터 없이 UQ 가능
   - 기존 UQ(앙상블 등) 대비 계산 비용이 수십 배 저렴

2. **다중 충실도 불확실성 인지 최적화 (Multi-Fidelity Uncertainty-Aware Optimization)**
   - 저충실도 서로게이트(DNN)로 빠른 탐색 → PIU가 임계값 이하인 후보만 선별
   - 선별된 후보를 고충실도 시뮬레이터(CST 등)로 검증
   - PIU 기반 필터링이 고충실도 시뮬레이션 호출을 대폭 절감

3. **BO 프레임워크 통합**
   - GP 또는 DNN 서로게이트 + PIU를 acquisition function에 결합
   - UCB 변형: α(x) = μ(x) + β·σ_PIU(x) 형태로 PIU를 탐색-활용 균형에 반영
   - 물리적으로 신뢰할 수 없는 영역을 자동 회피

4. **실험**
   - 20–30 GHz 대역 FSS 역설계 (12개 설계 변수, 복잡한 기하)
   - 기존 DNN-only 최적화: 성공률 < 10%
   - PIU 통합 최적화: 성공률 > 50%, 고충실도 시뮬레이션 비용 10배 절감
   - 앙상블 UQ, MC-dropout UQ 대비 PIU의 계산 효율 + 상관관계 비교

## Conclusion

- 물리 법칙 위반을 UQ 대리 지표로 사용하는 Physics-Informed Uncertainty 패러다임 최초 제안·검증
- 추가 모델 학습 없이 단일 forward pass + 물리 잔차 계산으로 UQ 가능
- 다중 충실도 최적화에서 성공률 5배 이상 향상, 계산 비용 10배 절감
- 고차원 역설계에서 서로게이트 불확실성 관리의 실용적 경로를 제시

## 주제 연관성

서로게이트 기반 역설계에서 물리 위반도를 불확실성(분산)의 척도로 재정의하여, 탐색 공간 중 물리적으로 불가능한 영역을 자동 배제한다. BO의 acquisition에 PIU를 통합하여 해의 다중성 중 물리적으로 유효한 해만 탐색하는 전략으로, variation propagation 억제에 직접 기여한다.
