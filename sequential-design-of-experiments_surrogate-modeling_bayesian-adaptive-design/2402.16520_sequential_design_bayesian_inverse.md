- Submitted: 2024-02-26 (v1), revised 2025-01-20 (v2) (within routine window 2024-04-20 ~ 2026-04-20)

- Keywords matched (>=2): **sequential design of experiments**, **surrogate modeling**, **bayesian adaptive design**

## Why this paper fits the topic "sequential variation propagation"

역문제에서 일대다(one-to-many) 해의 다중성 때문에 탐색 공간이 폭발하는 근본 원인은, 전방 모델 평가 비용이 높아 posterior landscape를 충분히 탐색하지 못하기 때문이다. 이 논문은 **GP surrogate를 Bayesian inverse problem의 전방 모델 대리로 사용**하면서, **어디에 다음 전방 모델을 평가할지를 순차적(sequential)으로 최적 설계**하여 posterior 수렴을 가속한다. 즉, 제한된 시뮬레이션 예산 하에서 inverse problem의 불확실성을 체계적으로 줄이는 adaptive design 전략이다.

## Methods

### 1. Problem Setting: Bayesian Inverse Problem with GP Surrogate

관측 데이터 `y_obs`로부터 파라미터 `θ`의 posterior를 추정:

```
π(θ | y_obs) ∝ L(y_obs | θ) · π_0(θ)
```

전방 모델 `G(θ)`이 비용이 크므로 GP surrogate `Ĝ(θ)`로 대체:

```
Ĝ(θ) ~ GP(m(θ), k(θ, θ'))
```

Surrogate를 사용한 approximate posterior:

```
π̂_n(θ | y_obs) ∝ L̂_n(y_obs | θ) · π_0(θ)
```

여기서 `n`은 현재까지의 설계 포인트 수.

### 2. Uncertainty Metric: Weighted Integrated MSPE

Surrogate의 예측 불확실성이 posterior 추정에 미치는 영향을 정량화:

```
H_n = ∫ w_n(θ) · σ²_n(θ) dθ
```

- `σ²_n(θ)`: GP posterior variance at θ
- `w_n(θ)`: posterior-informed weight, `w_n(θ) ∝ π̂_n(θ | y_obs)`

핵심 아이디어: posterior가 집중된 영역의 surrogate 정확도를 우선 개선.

### 3. Sequential Design Strategies

#### IP-SUR (Inverse Problem Stepwise Uncertainty Reduction)

각 단계에서 `H_n`의 기대 감소량을 최대화하는 다음 평가점 선택:

```
θ_{n+1} = argmax_θ  E[ H_n - H_{n+1} | θ_{n+1} = θ ]
```

이는 one-step lookahead 최적화이며, GP의 해석적 성질을 활용하여 closed-form으로 계산 가능:

```
θ_{n+1} = argmax_θ  ∫ w_n(θ') · Δσ²(θ'; θ) dθ'
```

여기서 `Δσ²(θ'; θ)`는 `θ`에서 관측 시 `θ'`에서의 variance 감소량.

#### CSQ (Constraint Set Query)

D-optimal design을 Bayesian inverse problem에 적용. MAP 추정치 주변의 Mahalanobis 거리 ball 내에서 정보 행렬을 최대화:

```
θ_{n+1} = argmax_{θ ∈ B_M(θ_MAP, r)}  det(I_n + k(θ,θ) · vv^T)
```

### 4. Theoretical Guarantees

- IP-SUR의 불확실성 메트릭 `H_n`의 **almost-sure convergence to zero** 증명
- Scalar 및 multi-output GP surrogate 모두에 적용 가능
- Continuous sample path 조건 하에서 수렴 보장

### 5. Validation

- 1D/2D synthetic inverse problems
- Darcy flow PDE-based inverse problem
- IP-SUR vs. CSQ vs. random design vs. space-filling design 비교
- IP-SUR이 동일 예산에서 posterior approximation 오차를 유의하게 줄임

## Conclusion

- **Posterior-aware sequential design**이 random/space-filling 대비 surrogate 기반 Bayesian 역문제의 수렴 속도를 크게 향상.
- Weight function `w_n(θ)`을 통해 **posterior가 집중된 영역에 평가 예산을 집중**하므로, 해의 다중성이 있는 역문제에서도 효율적으로 불확실성을 억제.
- 이론적 수렴 보장(almost-sure)이 있어 실무 적용의 신뢰성 확보.
- Multi-output GP로의 확장이 자연스러워 벡터 출력 역문제에도 적용 가능.
