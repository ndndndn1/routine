## Why this paper fits the topic "sequential variation propagation"

One-to-many 역문제(inverse problem)에서 해의 다중성은 결국 "후보 공간을 어느 순서로 질의할 것인가"의 문제로 귀결된다. ALMAB-DC는 GP surrogate의 **posterior variance**를 1차 자원 삼아 (i) 불확실성이 큰 후보를 active learning으로 정렬하고, (ii) 동시에 평가 예산(parallel worker)을 multi-armed bandit(UCB / Thompson)으로 분배하며, (iii) 각 평가가 끝날 때마다 비동기적으로 surrogate를 갱신해 **분산 기반 탐색 공간 폭발**을 억제한다. 즉, 순방향 many-to-one을 역방향 one-to-many로 풀 때 발생하는 ambiguity를 *분산 제어로 수렴시키는* 대표적인 최신 스케일러블 프레임워크다.

## Methods

### 1. 통합 루프

세 가지 구성요소가 하나의 이벤트 기반 루프로 묶인다.

1. **GP surrogate** `f(x) ~ GP(μ(x), k(x, x'))` — 비용 큰 블랙박스 관측에 대한 확률적 대리 모델.
2. **Active Learner (AL)** — acquisition `α(x)`로 다음 후보를 선정. 논문은 다음 4종을 통합한다.
   - UCB:  `α_UCB(x) = μ(x) + β σ(x)`
   - EI:   `α_EI(x) = E[max(0, f* - f(x))]`
   - Max-Variance: `α_MV(x) = σ²(x)` (pure exploration — 역문제 ambiguity 완화에 직결)
   - Thompson Sampling: posterior sample `g ~ GP`에서 argmax
3. **Multi-Armed Bandit (MAB)** — candidate region(arm)에 평가 예산을 분배.
   Asynchronous UCB1:  `I_t = argmax_i  x̄_i + √(2 log t / n_i)`
   누적 regret `R_T = O(√(K T log T))` (stale observation 보정 포함).
4. **Distributed Computing (DC)** — 동기 장벽 없이 evaluation 완료 시 surrogate 갱신 & 다음 후보 디스패치. Amdahl's law로 parallel speedup 해석.

### 2. 이벤트 기반 비동기 스케줄링

```
while budget > 0:
    worker_id, (x, y) = wait_any_completed(workers)
    GP.condition(x, y)                   # O((n+1)^3) rank-1 업데이트
    arm = MAB.select_arm()               # UCB1 or Thompson
    x_next = argmax_x α(x; GP) ∧ region(arm)
    workers[worker_id].dispatch(x_next)
    MAB.update(arm, reward=α(x_next))
```

### 3. 이론적 보장

- GP-UCB/GP-TS regret: `O(√(T γ_T))` (γ_T = maximum information gain).
- Asynchronous staleness penalty는 worker 수 `P`에 대해 가산적(additive).
- Max-Variance pure-exploration은 post-hoc 엔트로피 감소율에 비례.

### 4. 검증 벤치마크

- Response surface optimization (synthetic Branin/Hartmann)
- Bayesian dose–response adaptive design
- Adaptive spatial sampling (geostatistical)
- Transfer 실험: pharmacogenomic & geospatial real datasets

## Conclusion

- **단일 확률적 surrogate + bandit + async DC**를 한 루프에 통합해, 기존 batch BO/AL보다 wall-clock 관점에서 선형에 가까운 parallel speedup을 얻는다.
- Max-Variance / UCB 같은 variance-centric acquisition이 one-to-many 역설계의 탐색 공간 폭발을 효과적으로 억제함을 경험적으로 보였다.
- Theoretical regret은 synchronous 한계와 동일 차수를 유지하면서도 distributed환경에서 실용성을 획득.
