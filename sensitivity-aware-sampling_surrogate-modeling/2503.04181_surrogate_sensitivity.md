## Why this paper fits the topic "sequential variation propagation"

Offline optimization에서 surrogate model은 블랙박스 함수의 대리 모델 역할을 한다. 그런데 surrogate가 **입력 변동(variation)에 과도하게 민감**하면, 역설계 시 작은 입력 변화에 출력이 급변하여 비물리적 해나 out-of-distribution 영역으로 최적화가 발산한다. 이 논문은 **surrogate의 sensitivity를 정량화하고 이를 정규화(regularize)함으로써**, 역문제 탐색 공간에서의 분산 폭발을 직접 억제한다. sensitivity-aware한 surrogate 학습은 variation propagation을 제어하는 직접적인 방법이다.

## Methods

### 1. 문제 정의: Offline Model-Based Optimization

오프라인 데이터셋 `D = {(x_i, y_i)}` 만으로 surrogate `f̂(x) ≈ f(x)`를 학습하고, `f̂`를 최대화하는 `x*`를 찾는 문제:

```
x* = argmax_x f̂(x)
```

핵심 리스크: surrogate가 학습 데이터 밖에서 과도하게 높은 값을 예측(overestimation) → 역설계 실패

### 2. Surrogate Sensitivity 정량화

Surrogate의 입력 변동에 대한 민감도를 측정:

```
S(x) = E_δ[|f̂(x + δ) - f̂(x)|²]    where δ ~ N(0, σ²I)
```

이를 미분 가능한 형태로 근사:

```
S(x) ≈ ||∇_x f̂(x)||² · σ²    (1차 Taylor 근사)
```

높은 sensitivity → surrogate가 해당 영역에서 불안정 → 최적화 결과가 신뢰 불가

### 3. Sensitivity-Informed Regularizer (SIR)

Surrogate 학습 시 sensitivity를 직접 패널티로 부과:

```
L_total = L_fit(f̂, D) + λ · E_x[S(x)]
        = MSE(f̂(x), y) + λ · E_x[||∇_x f̂(x)||²]
```

- `λ`는 적합도와 안정성의 trade-off 조절
- Gradient penalty는 surrogate의 Lipschitz 상수를 간접적으로 제한

### 4. 기존 optimizer와의 통합

SIR은 다양한 offline optimizer에 plug-in으로 적용 가능:
- **Gradient Ascent**: surrogate 위에서 직접 gradient ascent
- **CbAS (Conditioning by Adaptive Sampling)**: 생성 모델 기반
- **COMs (Conservative Objective Models)**: pessimistic surrogate
- **ROMA**: robust model-based approach

각 optimizer의 surrogate 학습 단계에 SIR을 추가하면 성능 향상.

### 5. 검증

Design-Bench (offline optimization benchmark):
- Superconductor, Ant Morphology, D'Kitty, TF-Bind 등 7개 태스크
- SIR 적용 시 대부분의 optimizer에서 일관된 성능 향상

## Conclusion

- Surrogate sensitivity를 **정량화 가능한 메트릭으로 정의**하고, 이를 regularizer로 활용하여 offline optimization의 robustness를 향상.
- 기존 optimizer에 **plug-in 방식**으로 적용 가능한 범용성을 보유.
- 역문제 관점에서, surrogate의 민감도 제어는 곧 **입력 variation이 출력에 전파되는 경로(variation propagation)를 안정화**하는 것이며, 이로써 탐색 공간 폭발을 억제.
