## Why this paper fits the topic "sequential variation propagation"

동역학 시스템의 시뮬레이션/최적화에서 surrogate가 사용될 때, **어떤 입력 영역에서 surrogate 오차가 최종 해(trajectory, 최적 제어)에 가장 크게 전파되는지**를 sensitivity 정보로 정량화할 수 있다. 이 논문은 **solution sensitivity**와 **pointwise surrogate error**를 결합한 acquisition function으로 surrogate를 적응적(adaptive)으로 정제(refine)한다. 즉, variation이 결과에 가장 크게 전파되는 영역을 우선 정밀화하여, 전체 탐색 공간에서의 불확실성 전파를 효율적으로 억제하는 전략.

## Methods

### 1. Problem Setting

동역학 시스템 `ẋ(t) = g(x(t), u(t), p)` 여기서:
- `x(t)`: state trajectory
- `u(t)`: control input
- `p`: uncertain parameters / design variables

`g`에 포함된 구성 함수(component function)가 비용이 크므로 (예: CFD 공력 계수) surrogate `ĝ`로 대체.

### 2. Sensitivity-Error Product Acquisition

핵심 acquisition function:

```
α(p) = |S(p)| · |ε(p)|
```

- `S(p)`: **Solution sensitivity** — `p`에서의 구성 함수 값 변화가 최종 trajectory/objective에 미치는 영향
  ```
  S(p) = ∂J/∂g(p)    (adjoint-based sensitivity)
  ```
- `ε(p)`: **Pointwise surrogate error estimate** — surrogate와 true function의 차이 추정
  ```
  ε(p) = |g(p) - ĝ(p)|   (or GP posterior std)
  ```

이 곱이 큰 영역은 **surrogate 오차가 크면서 동시에 최종 결과에 민감한** 곳 → 해당 영역에서 true function을 평가하여 surrogate를 정제.

### 3. Adaptive Refinement Loop

```
ĝ_0 = initial surrogate (kernel interpolation)
for k = 0, 1, ...:
    Solve ODE/optimization with ĝ_k → trajectory x_k, objective J_k
    Compute sensitivity S_k via adjoint method
    Compute error estimate ε_k
    p_new = argmax |S_k(p)| · |ε_k(p)|       # acquisition
    g_new = expensive_eval(p_new)              # true evaluation
    ĝ_{k+1} = refine(ĝ_k, p_new, g_new)      # surrogate update
    if convergence_criterion: break
```

### 4. Surrogate Model: Kernel Interpolation

Radial basis function(RBF) 기반 interpolation:

```
ĝ(p) = Σ_i w_i · φ(||p - p_i||)
```

Error bound를 power function으로 추정:

```
|g(p) - ĝ(p)| ≤ ||g||_{H_φ} · P_X(p)
```

여기서 `P_X(p)`는 현재 데이터셋 `X`에 대한 kernel interpolation의 power function.

### 5. Validation

- **Hypersonic vehicle trajectory optimization**: 공력 계수 `C_D(M, α), C_L(M, α)`를 CFD 대신 surrogate로 대체
- 6-DOF 비행 동역학 ODE
- Sensitivity-driven refinement vs. uniform refinement vs. error-only refinement 비교
- Sensitivity-driven 방식이 **동일 true evaluation 횟수에서 최적 제어 해의 정확도를 크게 향상**

## Conclusion

- **Solution sensitivity × surrogate error**를 결합한 acquisition function이, 각각을 단독으로 사용하는 것보다 우수.
- Adjoint 기반 sensitivity 계산이 추가 비용이 적으므로, 전체 refinement 루프의 overhead가 작다.
- 역문제 관점: variation이 최종 결과에 전파되는 **critical path**를 sensitivity가 식별하고, 그 경로 위에서만 surrogate를 정밀화하여 탐색 효율 극대화.
- Kernel interpolation 외에 GP surrogate로의 확장이 자연스러움 (GP posterior variance = error estimate).
