## Why this paper fits the topic "sequential variation propagation"

역문제의 one-to-many 다중성을 다룰 때, 입력/출력 공간이 모두 고차원이면 탐색 공간이 기하급수적으로 증가한다. 이 논문은 **입력과 출력 공간을 동시에(coupled) 차원 축소**하는 프레임워크를 제시한다. Goal-oriented sensitivity analysis를 통해 **출력 변동에 가장 크게 기여하는 입력 방향**을 식별하고, 동시에 **가장 정보가 풍부한 출력 관측 위치(sensor placement)**를 선택한다. 이로써 역문제의 분산 전파 경로를 저차원으로 압축하여 탐색 효율을 대폭 향상시킨다.

## Methods

### 1. Problem Setting

고차원 함수 `f: R^{d_x} -> R^{d_y}`에서 입력 `x`와 출력 `y = f(x)`를 모두 저차원으로 축소:

```
x ≈ P_r · z_r    (input reduction:  d_x → r)
y ≈ Q_s · w_s    (output reduction: d_y → s)
```

핵심: `P_r`과 `Q_s`의 선택은 **상호 의존적**이다. 출력 관심 방향이 바뀌면 입력 중요 방향도 달라지고, 그 역도 성립.

### 2. Coupled Dimension Reduction Objective

입력-출력 결합 차원 축소를 다음 최적화로 정의:

```
(P_r*, Q_s*) = argmin_{P_r, Q_s} E[ || Q_s^T f(x) - Q_s^T f(P_r P_r^T x) ||² ]
```

이를 해석하면: 출력 부분공간 `Q_s` 위에 사영된 응답의 오차를 최소화하는 입력 부분공간 `P_r`을 동시에 찾는 것.

### 3. Gradient-based Characterization

함수 `f`의 Jacobian `J(x) = ∇_x f(x)`를 이용하여 결합 축소를 gradient 기반으로 특성화:

```
C(Q) = E_x[ J(x)^T Q Q^T J(x) ]    (input diagnostic matrix)
D(P) = E_x[ J(x) P P^T J(x)^T ]    (output diagnostic matrix)
```

고유값 분해를 교대로 수행(alternating eigenvalue decomposition):
1. `Q` 고정 → `C(Q)`의 상위 `r` 고유벡터로 `P_r` 결정
2. `P` 고정 → `D(P)`의 상위 `s` 고유벡터로 `Q_s` 결정
3. 수렴할 때까지 반복

### 4. Applications

#### Goal-oriented Bayesian Experimental Design (Sensor Placement)

관측 위치(sensor)를 선택하는 문제를 출력 차원 축소로 재해석:

```
Q_s* = argmax_{Q_s} E[ D_KL( π(θ|Q_s^T y) || π_0(θ) ) ]
```

Expected Information Gain(EIG)을 최대화하는 관측 부분공간을 선택 → 효율적 sensor placement.

#### Goal-oriented Global Sensitivity Analysis

특정 출력 quantity of interest `g(y) = Q^T y`에 대한 Sobol' index를 계산:

```
S_i^{(g)} = Var[ E[g(f(x)) | x_i] ] / Var[ g(f(x)) ]
```

출력 관심 방향에 따라 sensitivity index가 달라지므로, 결합 축소가 자연스럽게 goal-oriented GSA를 지원.

### 5. Validation

- Elliptic PDE inverse problem (Darcy flow)
- Heat equation with spatially-varying conductivity
- Coupled reduction이 독립 축소 대비 posterior approximation 정확도 향상
- Sensor placement 최적화에서 EIG 향상

## Conclusion

- **입출력 결합 차원 축소**가 독립 축소 대비 역문제의 정보 효율을 크게 개선.
- Goal-oriented sensitivity analysis를 통해 **출력 변동에 기여하는 핵심 입력 방향을 선택적으로 추적** 가능.
- Bayesian experimental design에서 sensor placement를 출력 차원 축소로 자연스럽게 통합.
- 역문제의 분산 전파(variation propagation)를 저차원 부분공간 위에서 효율적으로 관리하는 체계적 프레임워크 제공.
