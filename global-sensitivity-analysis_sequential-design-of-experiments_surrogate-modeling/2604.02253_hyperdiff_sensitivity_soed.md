# Hyper-differential Sensitivity Analysis with Respect to Model Discrepancy: Sequential Optimal Experimental Design

- **arXiv**: [2604.02253](https://arxiv.org/abs/2604.02253)
- **Authors**: Madhusudan Madhavan, Joseph Hart, Bart van Bloemen Waanders
- **Submitted**: 2026-04-02
- **Keywords**: global sensitivity analysis, sequential design of experiments, surrogate modeling

## Methods

This paper combines hyper-differential sensitivity analysis with sequential optimal experimental design to address optimization under model discrepancy — the gap between a computational model and reality.

1. **Hyper-differential Sensitivity Analysis (HDSA)**: HDSA quantifies how the optimal solution of an optimization problem changes with respect to perturbations in model parameters. This goes beyond standard sensitivity analysis by computing sensitivities of the optimum itself, not just the objective function. The result is a sensitivity field that identifies which model discrepancies most affect the design outcome.

2. **Multi-Fidelity Surrogate Framework**: A low-fidelity (cheap but inaccurate) model is used for initial optimization, and a high-fidelity (expensive but accurate) model provides correction data. The HDSA framework determines which corrections are most valuable, guiding efficient allocation of the limited high-fidelity evaluation budget.

3. **Sequential Experimental Design**: High-fidelity experiments are selected sequentially to maximally reduce the impact of model discrepancy on the optimality of the design. At each step, the HDSA sensitivity field identifies the parameter regions where model discrepancy has the greatest influence on the optimum, and the next experiment is placed in that region.

4. **Connection to Global Sensitivity Analysis**: The hyper-differential sensitivities provide a global picture of how model parameters affect the optimization landscape. This is equivalent to a GSA focused on the optimization outcome rather than the raw model output, making it directly relevant to design-oriented sensitivity analysis.

5. **Iterative Refinement Loop**: The sequential process alternates between (a) optimizing the design with the current surrogate, (b) computing HDSA sensitivities of the optimum, (c) selecting the next high-fidelity experiment, and (d) updating the surrogate. Convergence is reached when the sensitivities indicate that remaining model discrepancies have negligible impact on the optimum.

## Conclusion

The hyper-differential sensitivity analysis framework provides a principled approach to sequential experimental design when model discrepancy is the dominant source of uncertainty. By computing sensitivities of the optimization outcome (not just the model output) with respect to model parameters, the framework directs experimental resources to the most design-relevant regions of the parameter space. This is particularly valuable in engineering design where the computational model is an approximation, and limited physical experiments must be used to calibrate the most impactful model components. The sequential approach achieves near-optimal designs with significantly fewer high-fidelity evaluations than uniform sampling or standard space-filling designs.

```python
import numpy as np
from scipy.optimize import minimize

class HyperDiffSensitivity:
    def __init__(self, low_fi_model, high_fi_model, design_bounds, param_bounds):
        self.low_fi = low_fi_model
        self.high_fi = high_fi_model
        self.design_bounds = design_bounds
        self.param_bounds = param_bounds
        self.corrections = {}

    def corrected_model(self, design, params):
        low_val = self.low_fi(design, params)
        correction = 0.0
        for p_key, (p_val, corr_val) in self.corrections.items():
            dist = np.linalg.norm(params - p_val)
            weight = np.exp(-dist**2 / 0.1)
            correction += weight * corr_val
        return low_val + correction

    def optimize_design(self, params):
        def objective(d):
            return -self.corrected_model(d, params)
        bounds = [(b[0], b[1]) for b in self.design_bounds]
        x0 = np.mean(self.design_bounds, axis=1)
        result = minimize(objective, x0, bounds=bounds, method='L-BFGS-B')
        return result.x, -result.fun

    def hdsa_sensitivity(self, params_nominal, eps=1e-4):
        d_star, _ = self.optimize_design(params_nominal)
        sensitivities = np.zeros(len(params_nominal))
        for i in range(len(params_nominal)):
            params_p = params_nominal.copy()
            params_p[i] += eps
            d_p, _ = self.optimize_design(params_p)
            sensitivities[i] = np.linalg.norm(d_p - d_star) / eps
        return sensitivities

    def select_next_experiment(self, params_nominal, n_candidates=100):
        sensitivities = self.hdsa_sensitivity(params_nominal)
        most_sensitive_dim = np.argmax(np.abs(sensitivities))
        candidates = np.random.uniform(
            self.param_bounds[most_sensitive_dim][0],
            self.param_bounds[most_sensitive_dim][1],
            size=n_candidates
        )
        best_param = params_nominal.copy()
        best_score = -np.inf
        for c in candidates:
            test_param = params_nominal.copy()
            test_param[most_sensitive_dim] = c
            score = np.abs(sensitivities[most_sensitive_dim])
            if score > best_score:
                best_score = score
                best_param = test_param.copy()
        return best_param

    def add_correction(self, params):
        low_val = self.low_fi(None, params)
        high_val = self.high_fi(None, params)
        self.corrections[len(self.corrections)] = (params, high_val - low_val)
```
