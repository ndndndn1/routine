# Multi-modal Bayesian Neural Network Surrogates with Conjugate Last-Layer Estimation

- **arXiv**: [2509.21711](https://arxiv.org/abs/2509.21711)
- **Authors**: Ian Taylor, Juliane Mueller, Julie Bessac
- **Submitted**: 2025-09-26
- **Keywords**: surrogate modeling, bayesian optimization, global sensitivity analysis, multimodal inverse design

## Methods

1. **Multi-modal BNN architecture**: Two neural network surrogate architectures that fuse data from multiple auxiliary modalities (e.g., different sensor types, simulation fidelities) into a unified predictive model.

2. **Conjugate last-layer estimation**: Conditionally conjugate distributions in the output layer enable closed-form Bayesian parameter updates, avoiding expensive MCMC or deep-ensemble training.

3. **Stochastic Variational Inference (SVI)**: Model parameters are estimated via SVI, scaling to large datasets while maintaining well-calibrated uncertainty estimates.

4. **Missing-data handling**: A novel method performs conjugate SVI with partially observed multi-modal inputs, enabling practical deployment when not all data modalities are available for every sample.

5. **Scalar and time-series outputs**: The framework generalises to both point-valued and functional (time-series) quantities of interest.

6. **Target applications**: Designed for expensive outer-loop tasks including optimisation, sensitivity analysis, and inverse problems—the abstract explicitly lists all three.

## Conclusion

The multi-modal BNN surrogates with conjugate last-layer estimation achieve improved prediction accuracy and better-calibrated uncertainty compared to uni-modal counterparts, while remaining computationally tractable through SVI. The missing-data extension and support for both scalar and time-series outputs make the framework broadly applicable to engineering and scientific modelling pipelines.
