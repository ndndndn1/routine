# An ILUES-based Adaptive Gaussian Process Method for Multimodal Bayesian Inverse Problems

- arXiv: [2409.15307](https://arxiv.org/abs/2409.15307)
- HTML: https://arxiv.org/html/2409.15307
- Submitted: 2024-09 (within routine window 2024-05-02 ~ 2026-05-02, base date 2026-05-02)

## Why this paper fits the topic "sequential variation propagation"

Bayesian 역문제에서 순방향 모델이 many-to-one일 때 사후분포(posterior)는 자연스럽게 multimodal이 된다. 기존 GP surrogate 방법은 단봉(unimodal) 가정에 기반하여 다중해를 제대로 포착하지 못한다. 이 논문은 ILUES (Iterative Local Updating Ensemble Smoother)를 GP surrogate와 결합하여, 보조 밀도(auxiliary density)를 반복적으로 사후분포에 수렴시키면서 GP를 적응적으로 정교화하는 접근법을 제시한다. 이를 통해 one-to-many 역문제의 모든 해 모드를 효율적으로 탐색할 수 있다.

## Methods

### 1. Problem Setting

- Forward model `G(θ) = y + ε`, `ε ~ N(0, Σ)`
- Posterior: `π(θ|y) ∝ L(y|θ) × π₀(θ)` — computationally expensive G(θ)로 인해 직접 MCMC 불가
- Posterior가 multimodal → 다중해 모드를 모두 포착해야 함

### 2. GP Surrogate for Likelihood

- Forward model G(θ)를 GP로 대체: `G(θ) ≈ GP(μ(θ), k(θ, θ'))`
- Unnormalized posterior를 `π̃(θ) = q(θ) × exp(GP surrogate)` 형태로 분해
- q(θ): auxiliary density (반복적으로 갱신)

### 3. ILUES-based Adaptive Refinement

- **Iterative Local Updating Ensemble Smoother (ILUES)**:
  1. 현재 보조 밀도 q(θ)에서 앙상블 {θ₁, ..., θ_N} 샘플링
  2. Local ensemble update로 likelihood 정보 반영 → 갱신된 앙상블
  3. 갱신된 앙상블 위치에서 GP training point 추가 → surrogate 정교화
  4. q(θ) 갱신: 갱신된 앙상블의 KDE 또는 mixture model
- 반복할수록 q(θ)가 posterior에 수렴 → GP가 high-posterior 영역에 집중 학습

### 4. Multimodal Handling

- ILUES의 local update 특성으로 각 모드 주변의 앙상블이 독립적으로 진화
- 모드 간 앙상블 분포가 유지 → mode collapse 방지
- GP surrogate가 각 모드 영역에서 독립적으로 정교화

### 5. Validation

- Bimodal Gaussian mixture posterior (2D) — 두 모드 모두 정확히 복원
- Contamination source identification (groundwater) — 4-modal posterior
- Hydraulic tomography — 고차원(O(100)) multimodal inverse problem
- 기존 adaptive GP 방법 대비 mode coverage 향상, forward model 호출 50-70% 절감

## Conclusion

- ILUES + adaptive GP가 **multimodal Bayesian 역문제**에서 모든 해 모드를 포착하면서 forward model 호출을 대폭 절감.
- 보조 밀도의 반복 수렴이 GP training point를 high-posterior 영역에 집중시켜 surrogate 효율 극대화.
- cs.LG and physics.comp-ph 분류로, 계산물리학의 역문제에 직접 적용 가능.
