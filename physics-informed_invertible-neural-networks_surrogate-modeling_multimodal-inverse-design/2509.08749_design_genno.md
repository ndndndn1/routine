# Design-GenNO: A Physics-Informed Generative Model with Neural Operators for Inverse Microstructure Design

- **arXiv**: https://arxiv.org/abs/2509.08749
- **Authors**: Yaohua Zang, Phaedon-Stelios Koutsourelakis
- **Published**: 2025-09
- **Categories**: cs.LG, physics.comp-ph
- **Keywords**: physics-informed, invertible neural networks (normalizing flow), surrogate modeling, multimodal inverse design

## Methods

Design-GenNO는 물리 기반 생성 모델과 neural operator를 결합하여 microstructure 역설계의 다중 해 문제를 해결한다.

핵심 구성:
1. **Variational Autoencoder + Normalizing Flow Prior**: 미세구조를 저차원 잠재 공간(latent space)으로 인코딩. Normalizing flow가 잠재 공간의 prior를 정규화하여 invertible한 생성이 가능.
2. **MultiONet (Multi-output Neural Operator)**: DeepONet의 일반화로, 잠재 변수로부터 미세구조와 PDE 해 필드 모두를 매핑하는 연산자 학습. 하나의 잠재 변수가 설계(microstructure)와 물성(field solution)을 동시에 결정.
3. **Physics-Informed Training**: PDE 잔차를 손실 함수에 직접 포함. 라벨 데이터(시뮬레이션 결과) 없이도 자기지도 방식으로 학습 가능. 물리적으로 유효한 설계만 생성하도록 제약.
4. **Gradient-based Inverse Optimization**: 잠재 공간에서의 기울기 기반 최적화로 타겟 물성을 달성하는 미세구조 생성. Normalizing flow의 invertibility를 활용.
5. **Diversity through Latent Space Sampling**: 하나의 타겟 물성에 대해 잠재 공간의 여러 모드를 샘플링하여 다양한 유효 설계 생성. 일대다 매핑의 다중성을 자연스럽게 포착.

탐색 공간 억제 전략:
- PDE 잔차가 높은 잠재 영역 배제 → 물리적 무효 해 제거.
- Normalizing flow prior가 저확률 영역을 억제 → 비현실적 설계 필터링.
- 유효 물성 범위 외삽(extrapolation) 시에도 물리 제약으로 해의 타당성 유지.

## Conclusion

- Two-phase materials 역설계에서 SOTA 대비 높은 정확도와 다양성 달성.
- 유효 물성(effective property) 매칭, 희소 필드 측정으로부터의 구조 복원, 전도율비 최대화 등 다양한 역설계 과제에서 검증.
- 학습 분포 외 물성(training distribution 초과)을 가진 미세구조도 성공적으로 생성 (extrapolation capability).
- Self-supervised 학습 가능: 라벨 데이터 최소화.
- 한계: 2D 미세구조에 한정된 검증. 3D 확장 및 대규모 시스템에 대한 확장성 미검증.

## Code

공식 코드 미공개. 아래는 Design-GenNO의 핵심 구조 재현.

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
from torch.distributions import Normal


class NormalizingFlowPrior(nn.Module):
    """Normalizing flow for structured latent prior."""
    def __init__(self, latent_dim, n_flows=6):
        super().__init__()
        self.flows = nn.ModuleList()
        for _ in range(n_flows):
            self.flows.append(AffineCouplingLayer(latent_dim))

    def forward(self, z):
        log_det = 0
        for flow in self.flows:
            z, ld = flow(z)
            log_det += ld
        return z, log_det

    def inverse(self, x):
        for flow in reversed(self.flows):
            x = flow.inverse(x)
        return x

    def log_prob(self, z):
        x, log_det = self.forward(z)
        base_log_prob = Normal(0, 1).log_prob(x).sum(dim=-1)
        return base_log_prob + log_det


class AffineCouplingLayer(nn.Module):
    def __init__(self, dim):
        super().__init__()
        self.split_dim = dim // 2
        self.net = nn.Sequential(
            nn.Linear(self.split_dim, 128),
            nn.ReLU(),
            nn.Linear(128, 128),
            nn.ReLU(),
            nn.Linear(128, (dim - self.split_dim) * 2),
        )

    def forward(self, z):
        z1, z2 = z[:, :self.split_dim], z[:, self.split_dim:]
        params = self.net(z1)
        s, t = params.chunk(2, dim=-1)
        s = torch.tanh(s)
        z2_transformed = z2 * torch.exp(s) + t
        log_det = s.sum(dim=-1)
        return torch.cat([z1, z2_transformed], dim=-1), log_det

    def inverse(self, x):
        x1, x2 = x[:, :self.split_dim], x[:, self.split_dim:]
        params = self.net(x1)
        s, t = params.chunk(2, dim=-1)
        s = torch.tanh(s)
        x2_inv = (x2 - t) * torch.exp(-s)
        return torch.cat([x1, x2_inv], dim=-1)


class MultiONet(nn.Module):
    """Multi-output Neural Operator: maps latent z to microstructure + field."""
    def __init__(self, latent_dim, grid_size=64, field_channels=1):
        super().__init__()
        self.grid_size = grid_size
        # Branch net (latent -> coefficients)
        self.branch = nn.Sequential(
            nn.Linear(latent_dim, 256),
            nn.ReLU(),
            nn.Linear(256, 256),
            nn.ReLU(),
            nn.Linear(256, 128),
        )
        # Trunk net (spatial coordinates -> basis)
        self.trunk_micro = nn.Sequential(
            nn.Linear(2, 128),
            nn.ReLU(),
            nn.Linear(128, 128),
            nn.ReLU(),
            nn.Linear(128, 128),
        )
        self.trunk_field = nn.Sequential(
            nn.Linear(2, 128),
            nn.ReLU(),
            nn.Linear(128, 128),
            nn.ReLU(),
            nn.Linear(128, 128),
        )

    def forward(self, z, coords):
        branch_out = self.branch(z)  # (batch, 128)
        trunk_m = self.trunk_micro(coords)  # (n_points, 128)
        trunk_f = self.trunk_field(coords)

        # DeepONet inner product
        microstructure = torch.einsum('bi,pi->bp', branch_out, trunk_m)
        field = torch.einsum('bi,pi->bp', branch_out, trunk_f)
        return torch.sigmoid(microstructure), field


class DesignGenNO(nn.Module):
    """Full Design-GenNO framework."""
    def __init__(self, latent_dim=32, grid_size=64):
        super().__init__()
        self.latent_dim = latent_dim
        self.encoder = nn.Sequential(
            nn.Linear(grid_size * grid_size, 512),
            nn.ReLU(),
            nn.Linear(512, 256),
            nn.ReLU(),
            nn.Linear(256, latent_dim * 2),  # mean and log_var
        )
        self.flow_prior = NormalizingFlowPrior(latent_dim)
        self.multionet = MultiONet(latent_dim, grid_size)

    def encode(self, microstructure):
        flat = microstructure.flatten(1)
        params = self.encoder(flat)
        mu, log_var = params.chunk(2, dim=-1)
        return mu, log_var

    def reparameterize(self, mu, log_var):
        std = torch.exp(0.5 * log_var)
        eps = torch.randn_like(std)
        return mu + eps * std

    def physics_residual(self, field, microstructure, coords):
        """Compute PDE residual (e.g., steady-state heat conduction)."""
        # -div(k(x) * grad(T)) = f
        # Approximated via finite differences on grid
        dx = 1.0 / field.shape[-1]
        # Conductivity from microstructure (phase 1: k1, phase 2: k2)
        k = 1.0 + 9.0 * microstructure  # k ranges from 1 to 10
        # Laplacian approximation
        field_2d = field.view(-1, int(field.shape[-1]**0.5), int(field.shape[-1]**0.5))
        lap = (torch.roll(field_2d, 1, -1) + torch.roll(field_2d, -1, -1)
               + torch.roll(field_2d, 1, -2) + torch.roll(field_2d, -1, -2)
               - 4 * field_2d) / (dx**2)
        residual = (k.view_as(lap) * lap).abs().mean()
        return residual

    def inverse_design(self, target_property, coords, n_solutions=10, n_steps=500, lr=0.01):
        """Gradient-based inverse design in latent space."""
        solutions = []
        for i in range(n_solutions):
            z = torch.randn(1, self.latent_dim, requires_grad=True)
            optimizer = torch.optim.Adam([z], lr=lr)

            for step in range(n_steps):
                optimizer.zero_grad()
                micro, field = self.multionet(z, coords)

                # Effective property (e.g., volume-averaged conductivity)
                effective_prop = micro.mean(dim=-1)
                prop_loss = F.mse_loss(effective_prop, target_property)

                # Physics constraint
                phys_loss = self.physics_residual(field, micro, coords)

                # Prior regularization
                prior_loss = -self.flow_prior.log_prob(z).mean() * 0.01

                loss = prop_loss + 0.1 * phys_loss + prior_loss
                loss.backward()
                optimizer.step()

            with torch.no_grad():
                final_micro, _ = self.multionet(z, coords)
            solutions.append((z.detach(), final_micro))

        return solutions
```
