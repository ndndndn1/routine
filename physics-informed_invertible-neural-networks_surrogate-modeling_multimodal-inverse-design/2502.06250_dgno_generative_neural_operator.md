# DGNO: A Novel Physics-aware Neural Operator for Solving Forward and Inverse PDE Problems based on Deep, Generative Probabilistic Modeling

- **arXiv**: https://arxiv.org/abs/2502.06250
- **Authors**: Yaohua Zang, Phaedon-Stelios Koutsourelakis
- **Published**: 2025-02
- **Categories**: cs.LG, physics.comp-ph
- **Keywords**: physics-informed, invertible neural networks (generative), surrogate modeling, multimodal inverse design

## Methods

DGNO는 deep generative probabilistic model을 기반으로 PDE 입력과 출력을 동시에 인코딩하는 저차원 잠재 변수를 활용하여, 순방향 및 역방향 문제를 통합적으로 해결한다.

핵심 구성:
1. **Joint Latent Variable Model**: PDE 입력(경계조건, 물성 분포 등)과 PDE 출력(해 필드)을 공유 잠재 변수로 인코딩. 이 잠재 표현이 순방향(입력→출력)과 역방향(출력→입력)을 모두 지원.
2. **MultiONet Architecture**: DeepONet의 일반화로, branch-trunk 구조를 확장하여 더 높은 표현력 확보. 잠재 변수로부터 함수 공간으로의 매핑을 학습.
3. **Physics-Informed Training (Unlabeled Data 활용)**:
   - Compactly Supported Radial Basis Functions (CSRBFs) 기반 weak-form residual.
   - 정규성(regularity) 제약 완화 및 고차 도함수 제거로 학습 안정성 향상.
   - 라벨 없는 데이터(unlabeled, simulations 없이)로도 물리 제약만으로 학습 가능.
4. **Probabilistic Inverse Solving**: 관측 데이터가 주어지면, 잠재 공간에서의 posterior를 추론하여 가능한 입력 분포를 생성. 역문제의 비유일성(non-uniqueness)을 확률적으로 표현.
5. **Discontinuous Input Handling**: 다상(multi-phase) 매질처럼 불연속 입력 함수도 처리 가능. 기존 neural operator들이 어려워하는 영역.

탐색 공간 억제:
- 잠재 공간의 차원 축소가 역문제의 해 공간을 제한 → 탐색 효율 향상.
- 물리 잔차 기반 제약이 비물리적 해를 자동 배제.
- Probabilistic formulation이 불확실성을 정량화하여 유효 해 영역 식별.

## Conclusion

- 다중 벤치마크에서 기존 neural operator 대비 높은 정확도. 노이즈에 대한 로버스트성.
- Out-of-distribution 일반화 능력 우수.
- 라벨 데이터 없이 물리 제약만으로 학습 가능 → 데이터 효율적.
- Multi-phase media(불연속/이산 입력) 역문제에서 특히 강점.
- 확률적 추정치(probabilistic estimates)를 제공하여 의사결정 신뢰도 확보.
- 순방향/역방향 통합 프레임워크로 별도의 inverse model 학습 불필요.
- 한계: 대규모 3D 문제에 대한 확장성 미검증. 잠재 차원 선택에 대한 이론적 가이드 부족.

## Code

공식 코드 미공개. 아래는 DGNO의 핵심 구조 재현.

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
from torch.distributions import Normal


class BranchNet(nn.Module):
    """Branch network: encodes latent variables to coefficient space."""
    def __init__(self, latent_dim, output_dim=128, hidden_dim=256):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(latent_dim, hidden_dim),
            nn.GELU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.GELU(),
            nn.Linear(hidden_dim, output_dim),
        )

    def forward(self, z):
        return self.net(z)


class TrunkNet(nn.Module):
    """Trunk network: maps spatial coordinates to basis functions."""
    def __init__(self, coord_dim=2, output_dim=128, hidden_dim=128):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(coord_dim, hidden_dim),
            nn.GELU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.GELU(),
            nn.Linear(hidden_dim, output_dim),
        )

    def forward(self, coords):
        return self.net(coords)


class MultiONet(nn.Module):
    """Generalized DeepONet with multiple output heads."""
    def __init__(self, latent_dim, coord_dim=2, basis_dim=128):
        super().__init__()
        self.branch = BranchNet(latent_dim, basis_dim)
        self.trunk_input = TrunkNet(coord_dim, basis_dim)
        self.trunk_solution = TrunkNet(coord_dim, basis_dim)
        self.bias_input = nn.Parameter(torch.zeros(1))
        self.bias_solution = nn.Parameter(torch.zeros(1))

    def forward(self, z, coords):
        b = self.branch(z)
        t_input = self.trunk_input(coords)
        t_sol = self.trunk_solution(coords)
        input_field = torch.einsum('bi,pi->bp', b, t_input) + self.bias_input
        solution_field = torch.einsum('bi,pi->bp', b, t_sol) + self.bias_solution
        return input_field, solution_field


class CSRBFWeakForm(nn.Module):
    """Compactly Supported RBF for weak-form PDE residual computation."""
    def __init__(self, n_test_functions=50, domain_size=1.0, support_radius=0.2):
        super().__init__()
        centers = torch.rand(n_test_functions, 2) * domain_size
        self.register_buffer('centers', centers)
        self.support_radius = support_radius

    def wendland_c2(self, r):
        """Wendland C2 compactly supported RBF."""
        r_norm = r / self.support_radius
        return torch.clamp(1 - r_norm, min=0)**4 * (4 * r_norm + 1)

    def compute_weights(self, coords):
        """Compute test function values at given coordinates."""
        diffs = coords.unsqueeze(1) - self.centers.unsqueeze(0)
        distances = diffs.norm(dim=-1)
        return self.wendland_c2(distances)


class DGNO(nn.Module):
    """Deep Generative Neural Operator for forward and inverse PDE problems."""
    def __init__(self, latent_dim=16, coord_dim=2, n_grid_points=1024):
        super().__init__()
        self.latent_dim = latent_dim
        self.n_grid_points = n_grid_points

        # Encoder: observations -> latent posterior
        self.encoder = nn.Sequential(
            nn.Linear(n_grid_points, 512),
            nn.GELU(),
            nn.Linear(512, 256),
            nn.GELU(),
            nn.Linear(256, latent_dim * 2),  # mu, log_var
        )

        # Decoder: latent -> input field + solution field
        self.multionet = MultiONet(latent_dim, coord_dim)

        # Weak-form PDE residual
        self.weak_form = CSRBFWeakForm()

    def encode(self, observations):
        params = self.encoder(observations.flatten(1))
        mu, log_var = params.chunk(2, dim=-1)
        return mu, log_var

    def reparameterize(self, mu, log_var):
        std = torch.exp(0.5 * log_var)
        eps = torch.randn_like(std)
        return mu + eps * std

    def physics_residual(self, input_field, solution_field, coords):
        """
        Weak-form PDE residual using CSRBFs.
        Example: -div(k(x) * grad(u)) = f  (steady-state diffusion)
        """
        # Compute test function weights
        weights = self.weak_form.compute_weights(coords)

        # Approximate grad(u) via finite differences on grid
        n = int(self.n_grid_points ** 0.5)
        u_grid = solution_field.view(-1, n, n)
        dx = 1.0 / n

        grad_u_x = (torch.roll(u_grid, -1, -1) - torch.roll(u_grid, 1, -1)) / (2 * dx)
        grad_u_y = (torch.roll(u_grid, -1, -2) - torch.roll(u_grid, 1, -2)) / (2 * dx)

        # Conductivity from input field
        k = F.softplus(input_field.view(-1, n, n))

        # Flux
        flux_x = k * grad_u_x
        flux_y = k * grad_u_y

        # Divergence
        div_flux = ((torch.roll(flux_x, -1, -1) - torch.roll(flux_x, 1, -1)) / (2 * dx)
                    + (torch.roll(flux_y, -1, -2) - torch.roll(flux_y, 1, -2)) / (2 * dx))

        # Weighted residual
        residual = (div_flux.flatten(1) * weights[:div_flux.shape[0]]).mean()
        return residual.abs()

    def loss(self, observations, coords, beta=0.01, physics_weight=1.0):
        """ELBO loss with physics-informed regularization."""
        mu, log_var = self.encode(observations)
        z = self.reparameterize(mu, log_var)
        input_field, solution_field = self.multionet(z, coords)

        # Reconstruction loss
        recon_loss = F.mse_loss(solution_field, observations.flatten(1))

        # KL divergence
        kl = -0.5 * (1 + log_var - mu.pow(2) - log_var.exp()).sum(dim=-1).mean()

        # Physics residual (enables self-supervised learning)
        phys_loss = self.physics_residual(input_field, solution_field, coords)

        return recon_loss + beta * kl + physics_weight * phys_loss

    @torch.no_grad()
    def solve_inverse(self, observed_solution, coords, n_samples=100):
        """
        Inverse problem: given partial/full solution observations,
        infer the posterior over input fields.
        """
        mu, log_var = self.encode(observed_solution)

        # Sample from posterior
        solutions = []
        for _ in range(n_samples):
            z = self.reparameterize(mu, log_var)
            input_field, sol_field = self.multionet(z, coords)
            solutions.append(input_field)

        solutions = torch.stack(solutions)
        mean_input = solutions.mean(dim=0)
        std_input = solutions.std(dim=0)
        return mean_input, std_input, solutions
```
