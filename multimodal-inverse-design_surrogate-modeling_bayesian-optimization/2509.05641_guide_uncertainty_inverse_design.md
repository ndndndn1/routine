# GUIDe: Generative and Uncertainty-Informed Inverse Design for On-Demand Nonlinear Functional Responses

- **arXiv**: https://arxiv.org/abs/2509.05641
- **Authors**: Haoxuan Dylan Mu, Mingjian Tang, Wei Gao, Wei "Wayne" Chen
- **Published**: 2025-09
- **Keywords**: multimodal inverse design, surrogate modeling, bayesian optimization (MCMC)

## Methods

GUIDe는 다대일(Many-to-One) 순방향 문제를 일대다(One-to-Many) 역방향으로 풀 때 발생하는 해의 다중성(non-uniqueness)을 정면으로 다루는 프레임워크이다.

핵심 구성:
1. **Forward Surrogate Model**: LSTM 기반 아키텍처로 설계 파라미터 → 비선형 기능 응답(stress-strain 곡선 등)을 예측. MC Dropout으로 epistemic uncertainty 정량화.
2. **MCMC 기반 역설계**: inverse mapping을 학습하지 않고, forward model의 likelihood를 이용해 설계 공간에서 직접 MCMC 샘플링. Particle Swarm Optimization(PSO)로 초기 샘플을 생성하고, MCMC kernel로 posterior를 탐색.
3. **Uncertainty-Aware Filtering**: forward model의 예측 신뢰도(MC Dropout 기반 분산)가 user-specified tolerance 이내인 샘플만 유효한 설계로 채택.
4. **Abstention Mechanism**: out-of-distribution 타겟에 대해서는 설계 불가 판정을 내려 hallucination 방지.

이 접근법은 inverse mapping 방식(cGAN, cVAE, conditional diffusion)이 가지는 one-to-many 모호성과 OOD hallucination 문제를 우회한다.

## Conclusion

- GUIDe와 conditional diffusion model의 평균 feasibility rate: 63.9% vs 60.8%. GUIDe가 더 신뢰성 높은 설계 생성.
- Inverse mapping 방식 대비 학습 데이터 요구량이 적고, 학습 과정이 단순(forward model만 학습).
- 비선형 기능 응답(응력-변형 곡선, 스펙트럼 등) 전체를 타겟으로 설정 가능.
- ML 모델 및 MCMC 커널 선택에 agnostic한 범용 프레임워크.
- 한계: MCMC 샘플링 비용이 높은 차원에서 증가하며, forward model 정확도에 전체 성능이 의존.

## Code

공식 코드 미공개. 아래는 GUIDe 핵심 파이프라인의 재현 구현.

```python
import numpy as np
import torch
import torch.nn as nn
from torch.distributions import Normal

class ForwardSurrogate(nn.Module):
    """LSTM-based forward model with MC Dropout for uncertainty."""
    def __init__(self, design_dim, hidden_dim=128, output_steps=50, dropout=0.1):
        super().__init__()
        self.encoder = nn.Sequential(
            nn.Linear(design_dim, hidden_dim),
            nn.ReLU(),
            nn.Dropout(dropout),
            nn.Linear(hidden_dim, hidden_dim),
        )
        self.lstm = nn.LSTM(hidden_dim, hidden_dim, batch_first=True, num_layers=2, dropout=dropout)
        self.decoder = nn.Sequential(
            nn.Dropout(dropout),
            nn.Linear(hidden_dim, 1),
        )
        self.output_steps = output_steps

    def forward(self, design_params):
        h = self.encoder(design_params).unsqueeze(1).repeat(1, self.output_steps, 1)
        out, _ = self.lstm(h)
        return self.decoder(out).squeeze(-1)

    def predict_with_uncertainty(self, design_params, n_samples=50):
        self.train()  # enable dropout
        preds = torch.stack([self.forward(design_params) for _ in range(n_samples)])
        return preds.mean(0), preds.std(0)


def log_likelihood(predicted_response, target_response, sigma=0.05):
    """Gaussian log-likelihood between predicted and target functional response."""
    dist = Normal(predicted_response, sigma)
    return dist.log_prob(target_response).sum(dim=-1)


def pso_initialize(forward_model, target_response, design_dim, n_particles=100, n_iters=200, bounds=(-1, 1)):
    """Particle Swarm Optimization to find initial high-likelihood designs."""
    positions = torch.FloatTensor(n_particles, design_dim).uniform_(*bounds)
    velocities = torch.zeros_like(positions)
    personal_best_pos = positions.clone()
    personal_best_scores = torch.full((n_particles,), float('-inf'))
    global_best_pos = positions[0].clone()
    global_best_score = float('-inf')
    w, c1, c2 = 0.7, 1.5, 1.5

    for _ in range(n_iters):
        with torch.no_grad():
            preds = forward_model(positions)
        scores = log_likelihood(preds, target_response.unsqueeze(0).expand_as(preds))

        improved = scores > personal_best_scores
        personal_best_pos[improved] = positions[improved]
        personal_best_scores[improved] = scores[improved]

        best_idx = scores.argmax()
        if scores[best_idx] > global_best_score:
            global_best_score = scores[best_idx].item()
            global_best_pos = positions[best_idx].clone()

        r1, r2 = torch.rand_like(positions), torch.rand_like(positions)
        velocities = (w * velocities
                      + c1 * r1 * (personal_best_pos - positions)
                      + c2 * r2 * (global_best_pos.unsqueeze(0) - positions))
        positions = (positions + velocities).clamp(*bounds)

    return global_best_pos


def mcmc_sample(forward_model, target_response, init_design, n_samples=1000,
                step_size=0.02, sigma=0.05, uncertainty_threshold=0.1):
    """MCMC sampling in design space using forward model likelihood."""
    current = init_design.clone().requires_grad_(False)
    with torch.no_grad():
        current_pred = forward_model(current.unsqueeze(0)).squeeze(0)
    current_ll = log_likelihood(current_pred, target_response).item()

    samples = []
    accepted = 0

    for i in range(n_samples):
        proposal = current + torch.randn_like(current) * step_size
        proposal = proposal.clamp(-1, 1)

        with torch.no_grad():
            pred_mean, pred_std = forward_model.predict_with_uncertainty(
                proposal.unsqueeze(0), n_samples=20
            )
        pred_mean = pred_mean.squeeze(0)
        pred_std = pred_std.squeeze(0)

        # Reject if uncertainty too high (abstention)
        if pred_std.mean().item() > uncertainty_threshold:
            continue

        proposal_ll = log_likelihood(pred_mean, target_response).item()
        log_alpha = proposal_ll - current_ll

        if np.log(np.random.rand()) < log_alpha:
            current = proposal
            current_ll = proposal_ll
            accepted += 1

        samples.append(current.clone())

    acceptance_rate = accepted / n_samples
    return torch.stack(samples), acceptance_rate


def guide_pipeline(forward_model, target_response, design_dim,
                   n_pso_particles=100, n_mcmc_samples=2000):
    """Full GUIDe pipeline: PSO initialization -> MCMC sampling -> uncertainty filtering."""
    # Step 1: PSO initialization
    init_design = pso_initialize(forward_model, target_response, design_dim, n_pso_particles)

    # Step 2: MCMC sampling with uncertainty-aware acceptance
    samples, acc_rate = mcmc_sample(forward_model, target_response, init_design, n_mcmc_samples)

    # Step 3: Final uncertainty-based filtering
    valid_designs = []
    with torch.no_grad():
        for s in samples:
            pred_mean, pred_std = forward_model.predict_with_uncertainty(s.unsqueeze(0), n_samples=30)
            if pred_std.mean().item() < 0.08:
                error = (pred_mean.squeeze(0) - target_response).abs().mean().item()
                if error < 0.1:
                    valid_designs.append(s)

    return valid_designs, acc_rate
```
