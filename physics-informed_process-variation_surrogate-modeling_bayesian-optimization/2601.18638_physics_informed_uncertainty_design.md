# Physics-Informed Uncertainty Enables Reliable AI-driven Design

- **arXiv**: https://arxiv.org/abs/2601.18638
- **Authors**: Tingkai Xue, Chin Chun Ooi, Yang Jiang, Luu Trung Pham Duong, Pao-Hsiung Chiu, Weijiang Zhao, Nagarajan Raghavan, My Ha Dao
- **Published**: 2026-01
- **Categories**: cs.LG, physics.comp-ph
- **Keywords**: physics-informed, process variation, surrogate modeling, bayesian optimization

## Methods

본 논문은 역설계(inverse design)에서 서로게이트 모델의 예측 신뢰성 문제를 "Physics-Informed Uncertainty"라는 새로운 패러다임으로 해결한다.

핵심 아이디어:
1. **Physics-Informed Uncertainty (PIU)**: 모델 예측이 기본 물리 법칙(Maxwell 방정식 등)을 위반하는 정도를 불확실성의 대리 지표(proxy)로 사용. 별도의 ensemble이나 MC Dropout 없이 물리적 일관성만으로 예측 신뢰도를 판단.
2. **Multi-Fidelity Surrogate**: 저비용 물리 시뮬레이션(low-fidelity)과 고비용 full-wave 시뮬레이션(high-fidelity)을 결합하여 서로게이트 모델 학습.
3. **Uncertainty-Aware Bayesian Optimization**: PIU를 acquisition function에 통합하여, 물리적으로 일관된 영역에서만 탐색. 불확실성이 높은(물리 법칙 위반 심한) 영역은 자동으로 배제.
4. **Application Domain**: 20-30 GHz 주파수 대역의 frequency-selective surfaces (FSS) 설계. 고차원 파라미터 공간에서 다대일 매핑 문제 존재.

프로세스 변동(process variation) 관점에서:
- 제조 공정에서의 기하학적 변이가 성능에 미치는 영향을 물리 기반 불확실성으로 포착.
- 물리 법칙 위반 정도가 높은 설계 영역은 공정 변동에도 취약한 경향.
- PIU가 높은 영역을 회피함으로써 공정 로버스트한 설계 유도.

## Conclusion

- 성공률 향상: PIU 기반 최적화로 유효 설계 발견 성공률이 <10%에서 >50%로 5배 이상 증가.
- 계산 효율: 별도의 uncertainty quantification 모델 불필요. 물리 잔차(residual) 계산만으로 충분.
- 범용성: 지배 방정식이 존재하는 모든 물리 시스템에 적용 가능.
- 역설계의 다중성 억제: 불확실성이 높은 해 후보를 배제함으로써 탐색 공간을 효과적으로 축소.
- 한계: 지배 방정식의 명시적 형태가 필요. Black-box 시스템에는 직접 적용 불가.

## Code

공식 코드 미공개. 아래는 PIU 기반 Bayesian Optimization 파이프라인의 재현 구현.

```python
import numpy as np
import torch
import torch.nn as nn
from scipy.optimize import differential_evolution


class PhysicsInformedSurrogate(nn.Module):
    """DNN surrogate for frequency-selective surface response prediction."""
    def __init__(self, input_dim, output_dim=100, hidden_dim=256):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(input_dim, hidden_dim),
            nn.SiLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.SiLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.SiLU(),
            nn.Linear(hidden_dim, output_dim),
        )

    def forward(self, x):
        return self.net(x)


def compute_physics_residual(design_params, predicted_response, freq_range):
    """
    Compute physics-informed uncertainty as residual of Maxwell's equations.
    For FSS: energy conservation, Kramers-Kronig consistency, causality.
    """
    # Energy conservation: |S11|^2 + |S21|^2 <= 1
    s11 = predicted_response[:, :len(freq_range)]
    s21 = predicted_response[:, len(freq_range):]
    energy_violation = torch.relu(s11**2 + s21**2 - 1.0)

    # Smoothness prior: large abrupt changes violate physical continuity
    spectral_gradient = torch.diff(predicted_response, dim=-1)
    smoothness_violation = torch.relu(spectral_gradient.abs() - 0.3)

    # Reciprocity check (symmetric structure)
    # For symmetric FSS: S11(f) should equal S22(f)
    reciprocity_violation = torch.zeros_like(energy_violation)

    total_residual = (
        energy_violation.mean(dim=-1)
        + 0.5 * smoothness_violation.mean(dim=-1)
        + reciprocity_violation.mean(dim=-1)
    )
    return total_residual


def physics_informed_uncertainty(model, design_params, freq_range):
    """Compute PIU score for a batch of designs."""
    with torch.no_grad():
        predicted = model(design_params)
    residual = compute_physics_residual(design_params, predicted, freq_range)
    return residual


class PIUBayesianOptimizer:
    """Bayesian Optimization with Physics-Informed Uncertainty acquisition."""
    def __init__(self, surrogate, target_response, freq_range, design_bounds,
                 piu_threshold=0.05, alpha=0.3):
        self.surrogate = surrogate
        self.target = target_response
        self.freq_range = freq_range
        self.bounds = design_bounds
        self.piu_threshold = piu_threshold
        self.alpha = alpha  # trade-off between performance and uncertainty
        self.evaluated_designs = []
        self.evaluated_scores = []

    def acquisition_function(self, design_params):
        """Combined acquisition: performance match - alpha * PIU."""
        x = torch.FloatTensor(design_params).unsqueeze(0)
        with torch.no_grad():
            pred = self.surrogate(x).squeeze(0)

        # Performance score: negative MSE to target
        performance = -((pred - self.target) ** 2).mean().item()

        # Physics-informed uncertainty penalty
        piu = physics_informed_uncertainty(
            self.surrogate, x, self.freq_range
        ).item()

        # Reject if PIU exceeds threshold
        if piu > self.piu_threshold:
            return -1e6

        return performance - self.alpha * piu

    def optimize(self, n_iterations=100, n_candidates=50):
        """Run PIU-aware optimization loop."""
        best_design = None
        best_score = -np.inf

        for iteration in range(n_iterations):
            # Generate candidates via differential evolution
            result = differential_evolution(
                lambda x: -self.acquisition_function(x),
                bounds=self.bounds,
                maxiter=50,
                seed=iteration,
            )
            candidate = result.x
            score = -result.fun

            if score > best_score:
                best_score = score
                best_design = candidate

            self.evaluated_designs.append(candidate)
            self.evaluated_scores.append(score)

        return best_design, best_score

    def filter_by_piu(self, designs, threshold=None):
        """Filter design candidates by physics-informed uncertainty."""
        if threshold is None:
            threshold = self.piu_threshold
        valid = []
        for d in designs:
            x = torch.FloatTensor(d).unsqueeze(0)
            piu = physics_informed_uncertainty(self.surrogate, x, self.freq_range).item()
            if piu < threshold:
                valid.append(d)
        return valid
```
