## Why this paper fits the topic "sequential variation propagation"

전기 기계 설계에서 slot filling factor(SFF) 최적화는 전형적인 역문제이다 — 목표 성능(출력 토크, 효율)을 달성하는 기하학적 설계 파라미터를 찾아야 한다. 다수의 설계 변수가 전자기적 성능에 비선형적으로 영향을 미치므로 해의 다중성이 존재한다. 이 논문은 **물리 기반 사전 지식(Maxwell 방정식, 자기회로)을 GP surrogate에 주입**하여 탐색 공간을 물리적으로 유효한 영역으로 제한하고, **Maximum Entropy Sampling Algorithm (MESA)로 초기 탐색을 다양화**한 후 **Bayesian Optimization으로 순차 최적화**한다. Physics-informed prior가 variation propagation을 물리적 경계 내로 억제하는 역할을 수행.

## Methods

### 1. Problem: Slot Filling Factor Optimization

전기 기계의 SFF는 슬롯 내 도체 단면적 비율:

```
SFF = A_copper / A_slot
```

SFF를 최대화하면 저항 감소 → 효율 향상, 토크 밀도 증가. 그러나 SFF는 도체 형상, 절연 두께, 슬롯 기하 등 다수 파라미터의 복잡한 함수.

### 2. Physics-Informed GP Surrogate (PIBO)

Standard GP에 물리 prior를 주입:

```
f(x) ~ GP(m_phys(x), k(x, x'))
```

- **Mean function `m_phys(x)`**: 자기회로(magnetic circuit) 해석 모델에서 유도된 해석적 근사. 전자기 시뮬레이션 없이 물리적 추세를 포착.
- **Kernel `k(x, x')`**: Matérn 5/2 kernel. Physics prior가 mean을 담당하므로 kernel은 잔차(residual) 학습에 집중.

Physics-informed mean의 효과:
- GP가 물리적으로 불가능한 영역에서 과도한 예측을 하지 않음
- 초기 few-shot 단계에서도 합리적인 surrogate 형성
- Variation propagation을 물리 법칙이 허용하는 범위로 자연스럽게 제한

### 3. Maximum Entropy Sampling Algorithm (MESA)

초기 설계를 정보 이론적으로 최적화:

```
X_init = argmax_{X} H[f(X)]  (entropy maximization)
       = argmax_{X} log det(K(X, X) + σ²I)
```

MESA는 GP prior 하에서 **가장 정보량이 높은(informative) 초기 설계 포인트**를 선택하여, 이후 BO의 수렴 속도를 가속.

### 4. Sequential Bayesian Optimization

```
for t = 1, ..., T:
    GP_phys.fit(D_{t-1})            # physics-informed GP update
    x_t = argmax EI(x; GP_phys)    # Expected Improvement
    y_t = FEM_simulation(x_t)       # expensive FEM evaluation
    D_t = D_{t-1} ∪ {(x_t, y_t)}
```

Expected Improvement (EI):

```
EI(x) = E[max(f(x) - f_best, 0)]
      = (μ(x) - f_best) Φ(z) + σ(x) φ(z)
where z = (μ(x) - f_best) / σ(x)
```

### 5. Validation

- SFF 최적화: 12개 설계 변수 (슬롯 너비, 깊이, tooth 형상 등)
- Baseline: standard BO (non-physics-informed), random search, genetic algorithm
- PIBO가 standard BO 대비 **40% 적은 FEM 평가**로 동일 최적값 도달
- MESA 초기화가 LHS 대비 수렴 3-5회 가속

## Conclusion

- **Physics-informed mean function**이 GP surrogate의 few-shot 성능을 크게 향상시켜, 비용이 큰 FEM 시뮬레이션 호출 횟수를 줄인다.
- **MESA 초기화**가 탐색 공간의 효율적 커버리지를 보장하여 BO의 early-stage 성능을 개선.
- 역문제 관점: physics prior가 surrogate의 variation propagation을 물리적 범위 내로 제한 → 비물리적 해의 탐색을 원천 차단.
- 전기 기계 설계 외에도 **물리 모델이 존재하는 모든 역설계 문제**에 일반화 가능한 프레임워크.
