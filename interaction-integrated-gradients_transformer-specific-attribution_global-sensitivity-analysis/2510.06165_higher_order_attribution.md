## Why this paper fits the topic "sequential variation propagation"

Many-to-one forward 문제에서 복수의 입력 변수가 **개별 효과뿐 아니라 상호작용(interaction)을 통해** 출력 분산에 기여한다. 이 논문은 Integrated Gradients를 고차(higher-order)로 확장하여 **ANOVA 분해와의 이론적 등가성**을 증명하고, 입력 변수 간 비선형 상호작용이 출력 변동에 미치는 기여도를 정량적으로 분리한다. 역문제(one-to-many inverse) 관점에서, 고차 상호작용 attribution은 어떤 입력 조합이 출력 모호성을 유발하는지를 식별하여 탐색 공간의 차원 간 결합 구조를 파악하고 분산을 제어하는 데 직접 활용 가능하다.

## Methods

### 1. Standard Integrated Gradients (IG) 복습

Sundararajan et al. (2017)의 IG는 baseline `x'`에서 입력 `x`까지의 경로 적분으로 attribution을 계산:

```
IG_i(x) = (x_i - x'_i) * ∫₀¹ (∂F/∂x_i)(x' + α(x - x')) dα
```

이는 1차(first-order) 기여도만 포착하며, 변수 간 상호작용 효과를 분리하지 못한다.

### 2. Higher-Order Integrated Gradients (HO-IG)

본 논문은 Integrated Hessians를 일반화하여 k차 상호작용까지 포착하는 Higher-Order IG를 정의:

**2차 상호작용 (Integrated Hessians):**
```
IH_{i,j}(x) = (x_i - x'_i)(x_j - x'_j) * ∫₀¹ (∂²F / ∂x_i ∂x_j)(x' + α(x - x')) dα
```

**일반 k차:**
```
IG^(k)_{i₁,...,iₖ}(x) = ∏ₘ(x_{iₘ} - x'_{iₘ}) * ∫₀¹ (∂ᵏF / ∂x_{i₁}...∂x_{iₖ})(x' + α(x - x')) dα
```

### 3. ANOVA 분해와의 연결

ANOVA (Analysis of Variance) 함수 분해:
```
f(x) = f₀ + Σᵢ fᵢ(xᵢ) + Σᵢ<ⱼ fᵢⱼ(xᵢ,xⱼ) + ... + f₁₂...ₐ(x₁,...,xₐ)
```

여기서 각 항은 직교 조건을 만족:
```
∫ fₛ(xₛ) dxₖ = 0,  ∀k ∈ S
```

본 논문의 핵심 정리:

**정리 (HO-IG ↔ ANOVA):** baseline `x'`를 입력 공간의 marginal 기대값으로 설정하면, k차 HO-IG가 ANOVA 분해의 k차 항에 대응:
```
IG^(k)_{S}(x) ∝ fₛ(xₛ)  where S = {i₁, ..., iₖ}
```

이를 통해 **총 분산을 각 차수별 상호작용 기여도로 분해**할 수 있으며, Sobol' sensitivity index와 직접 연결:
```
S_S = Var[fₛ] / Var[f]     (Sobol' index for subset S)
```

### 4. 전체 분산 분해

```
Var[f(X)] = Σ_{S⊆{1,...,d}, |S|≥1} Var[fₛ(Xₛ)]

equivalently:
Var[f(X)] = Σᵢ Var[fᵢ] + Σᵢ<ⱼ Var[fᵢⱼ] + ... + Var[f₁₂...ₐ]
           = [1차 효과]  + [2차 상호작용]  + ... + [전체 상호작용]
```

### 5. Topological Signal Processing (TSP)과의 연결

Feature 간의 상호작용 구조를 **simplicial complex**로 표현:
- 0-simplex (vertex): 개별 feature의 1차 attribution
- 1-simplex (edge): 2개 feature 간의 2차 상호작용
- k-simplex: (k+1)개 feature 간의 (k+1)차 상호작용

**Hodge decomposition**을 적용하여 상호작용 신호를 세 성분으로 분해:
```
f = f_gradient + f_curl + f_harmonic
```

이를 통해 attribution 흐름의 방향성(gradient), 순환 구조(curl), 전역 패턴(harmonic)을 분리.

### 6. 수치 계산

경로 적분을 Riemann sum으로 근사:
```
IG^(k)_{i₁,...,iₖ}(x) ≈ ∏ₘ(x_{iₘ} - x'_{iₘ}) * (1/M) Σₘ₌₁ᴹ (∂ᵏF / ∂x_{i₁}...∂x_{iₖ})(x' + (m/M)(x - x'))
```

고차 편미분은 유한 차분(finite differences)으로 근사:
```
∂²F/∂xᵢ∂xⱼ ≈ [F(x+hᵢ+hⱼ) - F(x+hᵢ) - F(x+hⱼ) + F(x)] / h²
```

## Conclusion

- **Higher-Order IG가 ANOVA 분해와 이론적으로 등가**임을 증명하여, XAI와 통계적 sensitivity analysis를 통합하는 프레임워크를 제시.
- 2차 이상의 feature 상호작용을 경로 적분 기반으로 정량적으로 분리하여, 기존 1차 IG가 놓치는 **비선형 결합 효과**를 포착.
- Topological Signal Processing과의 연결을 통해, 고차 상호작용 구조를 simplicial complex 위의 신호로 해석하는 새로운 관점 제공.
- 역문제에서 입력 변수 간 결합 구조를 파악하여 탐색 공간의 **차원 간 의존성을 명시적으로 모델링**하는 데 활용 가능.
