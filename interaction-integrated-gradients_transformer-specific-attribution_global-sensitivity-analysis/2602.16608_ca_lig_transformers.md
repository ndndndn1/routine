## Why this paper fits the topic "sequential variation propagation"

Transformer 모델에서 입력 토큰의 변동(variation)이 multi-head attention과 feed-forward 레이어를 거치며 **순차적으로 전파**되는 과정을 추적하는 것이 핵심이다. 기존 IG는 모델을 black-box로 취급하여 이 **레이어별 분산 전파 구조**를 포착하지 못한다. CA-LIG는 각 Transformer 블록 내부에서 layer-wise IG를 수행하고, class-specific attention gradient로 가중하여, many-to-one forward mapping에서 **어떤 토큰 조합이 어떤 레이어에서 출력 분산에 기여하는지**를 계층적으로 분해한다. 이는 역문제에서 입력 공간의 어떤 영역이 모호성을 유발하는지 레이어 단위로 진단하는 데 활용 가능하다.

## Methods

### 1. 기존 Integrated Gradients의 한계

Standard IG는 모델 전체를 하나의 함수 `F: R^d → R`로 취급:
```
IG_i(x) = (x_i - x'_i) * ∫₀¹ (∂F/∂x_i)(x' + α(x - x')) dα
```

Transformer의 계층적 구조(embedding → attention → FFN → ... → classifier)를 반영하지 못하며, 중간 레이어에서의 정보 흐름을 추적할 수 없다.

### 2. Layer-Wise Integrated Gradients (LIG)

Transformer를 L개 블록의 합성으로 분해:
```
F = f_cls ∘ f_L ∘ ... ∘ f_2 ∘ f_1 ∘ f_emb
```

각 레이어 `l`에서의 intermediate representation `h^(l)`에 대해 IG를 독립적으로 수행:
```
LIG_i^(l) = (h_i^(l) - h_i'^(l)) * ∫₀¹ (∂f_{l+1:L}/∂h_i^(l))(h'^(l) + α(h^(l) - h'^(l))) dα
```

여기서 `h'^(l)`은 baseline 입력의 l번째 레이어 활성화, `f_{l+1:L}`은 l+1번째부터 출력까지의 부분 네트워크.

### 3. Context-Aware Attention Weighting

Self-attention에서 class-specific gradient를 추출하여 토큰별 중요도 가중치를 계산:

**Attention gradient 계산:**
```
G_A^(l) = ∂y_c / ∂A^(l)    (A^(l): l번째 레이어의 attention weight matrix)
```

**Class-specific attention weight:**
```
w_t^(l) = (1/H) Σ_h Σ_j ReLU(G_{A,h,t,j}^(l)) * A_{h,t,j}^(l)
```

여기서 `H`는 attention head 수, `t`는 토큰 인덱스, `j`는 attended 토큰 인덱스. ReLU는 양의 기여만 선택.

### 4. CA-LIG: 최종 attribution 결합

Layer-wise IG와 context-aware attention weight를 결합:
```
CA-LIG_t = Σ_l w_t^(l) * ||LIG_t^(l)||₂
```

여기서 `||LIG_t^(l)||₂`는 토큰 `t`의 l번째 레이어에서의 LIG 벡터의 L2 norm.

**정규화된 최종 attribution:**
```
â_t = CA-LIG_t / Σ_{t'} CA-LIG_{t'}
```

### 5. 수치 계산 세부사항

경로 적분의 Riemann 근사:
```
LIG_i^(l) ≈ (h_i^(l) - h_i'^(l)) * (1/M) Σ_{m=1}^{M} (∂f_{l+1:L}/∂h_i^(l))(h'^(l) + (m/M)(h^(l) - h'^(l)))
```

전체 알고리즘:
```
Input: model F, input x, baseline x', target class c, steps M
1. Forward pass: compute h^(l), A^(l) for l = 1,...,L
2. For each layer l:
   a. Compute attention gradients G_A^(l) = ∂y_c/∂A^(l)
   b. Compute context-aware weights w_t^(l) via Grad-CAM-like aggregation
   c. Compute LIG^(l) via M-step Riemann sum on intermediate activations
3. Aggregate: CA-LIG_t = Σ_l w_t^(l) * ||LIG_t^(l)||₂
4. Normalize: â_t = CA-LIG_t / Σ_{t'} CA-LIG_{t'}
Output: token-level attribution â
```

### 6. Layer-wise Sensitivity Decomposition

전체 attribution을 레이어별로 분해하여 **각 레이어의 분산 기여도**를 분석:
```
Layer contribution ratio: R^(l) = Σ_t w_t^(l) * ||LIG_t^(l)||₂ / Σ_{l'} Σ_t w_t^(l') * ||LIG_t^(l')||₂
```

이를 통해 어떤 레이어가 최종 예측에 가장 큰 영향을 미치는지 정량화.

## Conclusion

- **CA-LIG는 Transformer의 계층적 구조를 반영한 attribution** 방법으로, 기존 IG/Attention rollout 대비 더 정밀한 토큰별 기여도를 제공.
- Class-specific attention gradient를 결합하여 **context-aware한 attribution**을 생성하며, 단순 attention weight 시각화의 한계를 극복.
- Layer-wise 분해를 통해 **각 Transformer 블록이 최종 예측에 기여하는 정도**를 정량적으로 분석 가능.
- 다양한 NLP 벤치마크(sentiment analysis, NER, question answering)에서 faithfulness metric 기준으로 기존 방법 대비 우수한 성능.
- 역문제 관점에서, 레이어별 분산 기여도 분석을 통해 **모델의 어떤 계층이 입출력 모호성에 가장 큰 영향을 미치는지** 진단 가능.
