- **Keywords**: bayesian adaptive design, physics-informed, sequential design of experiments, surrogate modeling

## Methods

SBD-LAS proposes a sequential Bayesian design strategy for constructing locally accurate surrogate models focused on high-probability regions of the true likelihood in PDE-governed inverse problems.

1. **Locally Accurate Surrogate (LAS) Concept**: Instead of building a globally accurate surrogate across the entire parameter space (which demands excessive data and model capacity), the framework concentrates surrogate accuracy on regions that matter for Bayesian inference — the high-probability regions of the posterior. This dramatically reduces the computational budget required for surrogate construction.

2. **Sequential Bayesian Design (SBD)**: Training data points for the surrogate are acquired sequentially using Bayesian design principles. At each iteration, the next simulation parameter is chosen to maximally reduce the surrogate's uncertainty in regions relevant to the posterior. This creates a feedback loop: the improving surrogate refines the posterior estimate, which in turn guides data acquisition.

3. **Gaussian Process Surrogate with Posterior Guidance**: The surrogate is a Gaussian process that provides both predictions and calibrated uncertainty. The posterior distribution over PDE parameters (computed via MCMC with the current surrogate) defines the importance weights for the acquisition function, ensuring that computational budget is directed to the most inferentially relevant regions.

4. **Application to Darcy Flow Inversion**: The method is validated on the inversion of Darcy flow equations, a canonical PDE-constrained inverse problem. The permeability field is inferred from sparse pressure observations, requiring efficient surrogate construction for the pressure-permeability forward map.

5. **Algorithmic Acceleration via GP Process**: The posterior evolution process is modeled as a Gaussian process, enabling analytical approximations of the sequential design criterion that avoid expensive nested Monte Carlo estimation.

## Conclusion

SBD-LAS achieves accurate Bayesian inference in PDE-governed inverse problems with significantly fewer expensive PDE simulations than global surrogate construction approaches. The locally accurate surrogate strategy, guided by posterior-weighted acquisition, concentrates computational resources where they matter most for inference. On Darcy flow inversion benchmarks, the method achieves comparable posterior accuracy to full-evaluation MCMC with only a fraction of the simulation budget. The Gaussian process-based acceleration of the sequential design criterion further reduces overhead, making the approach practical for problems where each PDE simulation is computationally expensive.

import numpy as np
from sklearn.gaussian_process import GaussianProcessRegressor
from sklearn.gaussian_process.kernels import Matern

class SBD_LAS:
    def __init__(self, forward_model, param_bounds, obs_data, obs_noise_std):
        self.forward_model = forward_model
        self.bounds = param_bounds
        self.obs_data = obs_data
        self.obs_noise = obs_noise_std
        self.gp = GaussianProcessRegressor(
            kernel=Matern(nu=2.5), n_restarts_optimizer=5,
            normalize_y=True, alpha=1e-6
        )
        self.X_train = []
        self.Y_train = []

    def initial_design(self, n_init=5):
        dim = len(self.bounds)
        X = np.random.uniform(
            [b[0] for b in self.bounds],
            [b[1] for b in self.bounds],
            size=(n_init, dim)
        )
        Y = np.array([self.forward_model(x) for x in X])
        self.X_train = list(X)
        self.Y_train = list(Y)
        self._fit_gp()

    def _fit_gp(self):
        X = np.array(self.X_train)
        Y = np.array(self.Y_train)
        self.gp.fit(X, Y)

    def log_likelihood(self, params):
        pred, std = self.gp.predict(params.reshape(1, -1), return_std=True)
        residual = pred.flatten() - self.obs_data
        total_var = std.flatten()**2 + self.obs_noise**2
        ll = -0.5 * np.sum(residual**2 / total_var + np.log(total_var))
        return ll

    def posterior_samples_mcmc(self, n_samples=500, burn_in=200):
        dim = len(self.bounds)
        current = np.mean(self.bounds, axis=1)
        current_ll = self.log_likelihood(current)
        samples = []
        step_size = 0.05 * np.array([b[1] - b[0] for b in self.bounds])
        for i in range(n_samples + burn_in):
            proposal = current + step_size * np.random.randn(dim)
            proposal = np.clip(proposal, [b[0] for b in self.bounds],
                              [b[1] for b in self.bounds])
            proposal_ll = self.log_likelihood(proposal)
            if np.log(np.random.rand()) < proposal_ll - current_ll:
                current = proposal
                current_ll = proposal_ll
            if i >= burn_in:
                samples.append(current.copy())
        return np.array(samples)

    def acquisition(self, candidate, posterior_samples):
        _, pred_std = self.gp.predict(candidate.reshape(1, -1), return_std=True)

        posterior_weight = np.mean(weights)
        return pred_std[0] * posterior_weight

        posterior_samples = self.posterior_samples_mcmc()
        dim = len(self.bounds)
        candidates = np.random.uniform(
            [b[0] for b in self.bounds],
            [b[1] for b in self.bounds],
            size=(n_candidates, dim)
        )
        scores = [self.acquisition(c, posterior_samples) for c in candidates]
        best_idx = np.argmax(scores)
        new_x = candidates[best_idx]
        new_y = self.forward_model(new_x)
        self.X_train.append(new_x)
        self.Y_train.append(new_y)
        self._fit_gp()
        return new_x
