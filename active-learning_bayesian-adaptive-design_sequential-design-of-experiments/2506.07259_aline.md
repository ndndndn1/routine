# ALINE: Joint Amortization for Bayesian Inference and Active Data Acquisition

- **arXiv**: [2506.07259](https://arxiv.org/abs/2506.07259)
- **Authors**: Daolang Huang, Xinyi Wen, Ayush Bharti, Samuel Kaski, Luigi Acerbi
- **Submitted**: 2025-06-09 (revised 2025-10-21)
- **Keywords**: bayesian adaptive design, active learning, sequential design of experiments

## Methods

1. **Unified transformer architecture**: A single transformer model performs both amortised Bayesian inference (posterior estimation) and active data acquisition (experiment selection) in an end-to-end fashion.

2. **Reinforcement learning training**: The model is trained via RL with self-estimated information gain as the reward signal. No pre-computed optimal designs are needed.

3. **Selective targeting**: The querying strategy can be steered toward specific parameter subsets or predictive tasks, enabling flexible experimental design objectives beyond full-posterior estimation.

4. **Instantaneous inference**: Once trained, the model provides immediate posterior estimates given any dataset—no MCMC or variational optimisation at test time.

5. **Benchmarks**: Evaluated on regression-based active learning, classical Bayesian experimental design (e.g., source location, pharmacokinetics), and a psychometric model with selective parameter targeting.

## Conclusion

ALINE unifies amortised Bayesian inference and active data acquisition into a single transformer-based framework, enabling both strategic data collection and instant posterior estimation. It matches or outperforms prior specialised methods on standard BED benchmarks while supporting flexible, targeted querying strategies applicable to complex scientific tasks.
