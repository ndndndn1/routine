## Why this paper fits the topic "sequential variation propagation"

이 논문은 고차원 입력 공간에서 출력의 변동성(variance)에 기여하는 핵심 차원을 Sobol 민감도 분석으로 식별하고, 축소된 부분공간에서 GP 서로게이트 기반 능동 샘플링을 수행합니다. 다수의 입력 파라미터가 하나의 회로 성능 지표로 매핑되는 many-to-one 순방향 문제에서, 민감도 기반 차원 축소를 통해 역방향 모호성을 효과적으로 제어합니다. 능동 학습 기반 순차적 샘플링은 서로게이트 모델의 예측 분산을 최소화하며, 이는 순차적 변동 전파(sequential variation propagation) 관점에서 불확실성의 체계적 감소 전략에 해당합니다.

## Methods

### 1. Sobol Sensitivity Analysis for Dimension Reduction

Global sensitivity analysis via Sobol indices decomposes total output variance into contributions from each input dimension:

```
V(Y) = sum_i V_i + sum_{i<j} V_{ij} + ...

S_i = V_i / V(Y)          (first-order Sobol index)
S_Ti = 1 - V(X_~i) / V(Y) (total-order Sobol index)
```

Dimensions with negligible total-order indices (`S_Ti < threshold`) are screened out. The remaining `d_eff` dimensions form the active input subspace.

### 2. Gaussian Process Surrogate in Reduced Space

A GP is trained on the reduced `d_eff`-dimensional inputs:

```
f(x) ~ GP(m(x), k(x, x'))

k(x, x') = sigma_f^2 * exp(-0.5 * sum_j ((x_j - x'_j) / l_j)^2)

Posterior mean:    mu(x*) = k(x*, X) [K + sigma_n^2 I]^{-1} y
Posterior var:     s^2(x*) = k(x*, x*) - k(x*, X) [K + sigma_n^2 I]^{-1} k(X, x*)
```

where `K` is the kernel matrix over training points, `sigma_n^2` is noise variance, and `l_j` are per-dimension lengthscales (ARD kernel).

### 3. Active Sampling via Variance Reduction

At each iteration, the next sample point is chosen to maximize posterior variance (uncertainty sampling):

```
x_next = argmax_{x in D} s^2(x)

Acquisition function: alpha(x) = s^2(x)
```

This greedy strategy targets regions of maximum predictive uncertainty, ensuring efficient coverage of the reduced input space.

### 4. Full Algorithm

```
1. Generate initial space-filling design X_0 (e.g., Latin Hypercube)
2. Evaluate expensive simulator f at X_0 to get y_0
3. Compute Sobol total-order indices S_Ti from (X_0, y_0)
4. Select active dimensions: A = {i : S_Ti > tau}
5. Project inputs: X_0^A = X_0[:, A]
6. For t = 1, 2, ..., T:
   a. Fit GP on (X_{t-1}^A, y_{t-1})
   b. x_next^A = argmax s^2(x) over candidate set
   c. Augment inactive dimensions randomly
   d. Evaluate simulator: y_new = f(x_next)
   e. Update dataset: X_t^A = X_{t-1}^A ∪ {x_next^A}, y_t = y_{t-1} ∪ {y_new}
7. Return final GP surrogate
```

### 5. Application to Analog Circuit Simulation

The method is applied to analog circuit simulation where:
- Input dimensions: process variation parameters, design parameters (10-100+ dimensions)
- Output: circuit performance metrics (gain, bandwidth, etc.)
- Sensitivity screening typically reduces effective dimensionality by 50-90%

## Conclusion

- Sobol-based sensitivity screening effectively identifies a low-dimensional active subspace in high-dimensional analog circuit design spaces, often reducing dimensionality by an order of magnitude.
- GP-based active sampling in the reduced space achieves equivalent surrogate accuracy with 3-5x fewer simulator evaluations compared to space-filling designs in the full space.
- The combination of global sensitivity analysis and active learning provides a principled, automated pipeline for efficient circuit simulation under process variation.
- The method generalizes beyond analog circuits to any expensive black-box simulation with high-dimensional inputs where only a subset of dimensions significantly affects output variability.
- Variance-based acquisition outperforms random sampling and fixed experimental designs, especially in moderate-to-high dimensions after screening.
