## Why this paper fits the topic "sequential variation propagation"

이 논문은 PDE 기반 역문제에서 무한 차원 파라미터 공간의 관측 설계를 순차적으로 최적화하며, 파라미터-관측 간 many-to-one 매핑에서 발생하는 역방향 모호성을 Expected Information Gain(EIG) 최대화로 해소합니다. Derivative-informed 차원 축소는 파라미터 공간의 민감한 방향을 포착하여 분산 전파의 핵심 축을 식별하고, 신경 연산자 서로게이트를 통해 순차적 실험에서 사후 분포의 불확실성을 단계적으로 감소시킵니다. 이는 순차적 변동 전파에서 각 실험 단계가 이전 관측 정보를 기반으로 다음 설계를 적응적으로 결정하는 구조와 직접적으로 대응됩니다.

## Methods

### 1. Sequential Bayesian Optimal Experimental Design (sOED)

The goal is to sequentially select designs `d_1, d_2, ..., d_T` that maximize cumulative expected information gain (EIG) about parameters `theta`:

```
d_t* = argmax_{d_t} EIG(d_t | y_{1:t-1}, d_{1:t-1})

EIG(d) = E_{y|d}[ KL( p(theta|y,d) || p(theta) ) ]
       = E_{y|d}[ E_{theta|y,d}[ log p(y|theta,d) ] ] - E_y[ log p(y|d) ]
```

At each stage, the posterior from previous observations becomes the prior for the next stage:

```
p(theta | y_{1:t}, d_{1:t}) ∝ p(y_t | theta, d_t) * p(theta | y_{1:t-1}, d_{1:t-1})
```

### 2. Derivative-Informed Dimension Reduction (DIDR)

For PDE-governed inverse problems, the parameter-to-observable (PtO) map `G(theta, d)` is high- or infinite-dimensional. The key insight is to use derivative (Jacobian) information to find low-rank structure.

```
Generalized eigenvalue problem:
    H_misfit * v_i = lambda_i * Gamma_prior^{-1} * v_i

where H_misfit = J^T * Gamma_noise^{-1} * J   (Gauss-Newton Hessian)
      J = dG/d(theta)                          (Jacobian of PtO map)
```

Retain eigenvectors corresponding to the `r` largest eigenvalues:

```
V_r = [v_1, ..., v_r]    (informed subspace basis)
theta_r = V_r^T * theta   (reduced parameter, dim r << dim(theta))
```

### 3. Latent Attention Neural Operator (LANO) Surrogate

To avoid repeated PDE solves, a neural operator `G_nn` approximates the PtO map:

```
G_nn(theta_r, d) ≈ G(theta, d)

Architecture:
  - Encoder:  theta_r -> latent embedding z (via attention layers)
  - Decoder:  (z, d)  -> predicted observable y_pred
  - Training loss: ||G_nn(theta_r, d) - G(theta, d)||^2
                   + lambda * ||J_nn - J||^2   (derivative matching)
```

The derivative-matching regularization ensures the surrogate preserves sensitivity information:

```
J_nn = d(G_nn)/d(theta_r)   must approximate   V_r^T * J
```

### 4. EIG Estimation via Nested Monte Carlo

```
EIG(d) ≈ (1/N) sum_{i=1}^{N} [ log p(y_i | theta_i, d)
         - log( (1/M) sum_{j=1}^{M} p(y_i | theta_j, d) ) ]

where theta_i ~ p(theta), y_i ~ p(y | theta_i, d), theta_j ~ p(theta)
```

With the LANO surrogate, each likelihood evaluation `p(y|theta,d)` uses `G_nn` instead of solving the PDE, reducing cost from O(PDE_solve) to O(neural_net_forward).

### 5. Full Sequential Algorithm

```
1. Offline: Train LANO surrogate G_nn on prior samples
2. For t = 1, ..., T:
   a. Optimize: d_t* = argmax_d EIG(d | history) using G_nn
   b. Conduct experiment at d_t*, observe y_t
   c. Update posterior: p(theta | y_{1:t}, d_{1:t})
      via MCMC or Laplace approximation in reduced space
   d. Optionally retrain / fine-tune G_nn with posterior samples
3. Return final posterior p(theta | y_{1:T}, d_{1:T})
```

### 6. Computational Complexity

```
Without LANO: O(T * N_opt * N_MC * C_PDE)    per sequential stage
With LANO:    O(C_train) + O(T * N_opt * N_MC * C_nn)

where C_PDE >> C_nn, making sequential OED tractable
```

## Conclusion

- DILANO (Derivative-Informed Latent Attention Neural Operator) enables tractable sequential Bayesian OED in infinite-dimensional PDE-governed settings by providing a fast, derivative-accurate surrogate for the parameter-to-observable map.
- Derivative-informed dimension reduction identifies the subspace of parameters most informed by observations, reducing the effective dimensionality from thousands (discretized PDE parameters) to O(10-50).
- The surrogate preserves Jacobian accuracy through derivative-matching regularization, which is critical for reliable EIG estimation and posterior inference.
- Sequential designs found by maximizing EIG with the DILANO surrogate outperform static (non-adaptive) designs and heuristic placement strategies, yielding faster posterior contraction.
- The framework is demonstrated on diffusion and reaction-diffusion PDE inverse problems, showing that 3-5 sequential experiments can recover spatial parameter fields with substantially lower posterior uncertainty than non-sequential baselines.
