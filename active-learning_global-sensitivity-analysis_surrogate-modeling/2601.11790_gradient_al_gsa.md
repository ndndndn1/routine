## Why this paper fits the topic "sequential variation propagation"

역방향 one-to-many 문제에서 탐색 공간 폭발을 억제하려면 **어떤 입력 변수가 출력 분산에 가장 크게 기여하는지**를 파악(sensitivity analysis)해야 한다. 이 논문은 GP surrogate 위에서 **gradient 정보를 활용한 active learning**으로 Sobol' index 및 DGSM(Derivative-based Global Sensitivity Measures)을 효율적으로 추정한다. 즉, 한정된 시뮬레이션 예산으로 *분산 기여도*를 순차적으로 정밀하게 파악하여 역문제의 탐색 공간을 차원별로 가지치기(pruning)하는 전략이다.

## Methods

### 1. GP surrogate 기반 sensitivity 추정

복잡한 수치 시뮬레이터 `f(x)`에 대해 GP surrogate를 구축하고, GP의 해석적 성질을 이용하여 sensitivity index를 추정:

- **Sobol' indices**: `S_i = Var[E[Y|X_i]] / Var[Y]` — 각 입력 변수의 분산 기여도
- **DGSM**: `ν_i = E[(∂f/∂x_i)²]` — gradient 기반 sensitivity, Sobol' index의 상한

GP의 posterior에서 gradient의 joint distribution이 해석적으로 계산 가능하므로, DGSM과 Sobol' index 모두 closed-form posterior를 갖는다.

### 2. Gradient-based acquisition function

기존 AL은 GP variance `σ²(x)`를 최대화하는 IMSE(Integrated Mean Squared Error) 기반이 주류. 이 논문은 **sensitivity 추정 정확도를 직접 최적화**하는 acquisition을 제안:

```
α_GSA(x_new) = reduction in posterior variance of sensitivity indices
             = ΔVar[S_i | x_new]
```

핵심 기술:
- GP gradient의 joint posterior로부터 partial derivative의 상관관계(correlation)를 활용
- 단일 observation `(x_new, f(x_new))`가 전체 sensitivity landscape에 미치는 영향을 예측
- 기존 IMSE 대비 sensitivity 추정에 특화된 budget 배분

### 3. Sequential design loop

```
D_0 = initial small design (e.g., LHS)
for t = 1, ..., T:
    GP.fit(D_{t-1})
    x_t = argmax α_GSA(x; GP)       # gradient-informed acquisition
    y_t = simulator(x_t)            # expensive evaluation
    D_t = D_{t-1} ∪ {(x_t, y_t)}
    estimate S_i, ν_i from GP posterior
```

### 4. 검증

- Standard benchmark functions (Ishigami, Sobol' g-function)
- 실제 환경 모델: 농약 이동(pesticide transfer) 시뮬레이터
- 비교 대상: random design, IMSE, space-filling, existing AL for GSA

## Conclusion

- Gradient 기반 acquisition이 기존 IMSE/space-filling 대비 **동일 예산에서 sensitivity index 추정 오차를 유의하게 줄인다**.
- Partial derivative의 상관 구조를 활용함으로써, 고차원 입력에서도 효율적인 budget 배분이 가능.
- 역문제 관점에서, 중요하지 않은 입력 차원을 빠르게 식별하여 탐색 공간을 효과적으로 축소하는 데 활용 가능.
