- Published: NeurIPS 2024

- Keywords matched (>=2): **active learning**, **global sensitivity analysis**, **surrogate modeling**

## Why this paper fits the topic "sequential variation propagation"

역문제에서 입력 variation이 출력에 어떻게 전파되는지 파악하는 것이 탐색 공간 축소의 핵심이다. **Derivative-based Global Sensitivity Measures (DGSMs)**는 `E[(∂f/∂x_i)²]`으로 각 입력의 변동 전파 강도를 직접 측정한다. 이 논문은 **active learning으로 DGSM 추정을 위한 최적 실험 설계**를 수행하여, 한정된 예산으로 어떤 입력 변수가 출력 분산에 가장 크게 기여하는지를 효율적으로 식별한다. 기존 AL-for-GSA (Sobol' index 기반)와 달리 gradient 기반 sensitivity에 직접 최적화된 acquisition function을 제안한 최초의 연구.

## Methods

### 1. Derivative-Based Global Sensitivity Measures (DGSMs)

입력 `x_i`의 sensitivity를 gradient의 기대 제곱으로 정의:

```
ν_i = E_x[ (∂f/∂x_i)² ]
```

DGSM은 Sobol' total-effect index의 상한을 제공하며, GP에서 해석적으로 posterior 분포를 유도할 수 있는 장점이 있다.

GP surrogate `f ~ GP(m, k)` 하에서 DGSM의 posterior:

```
E[ν_i | D_n] = ∫ E_GP[(∂f/∂x_i)²] dx
Var[ν_i | D_n] = posterior uncertainty of the integral
```

### 2. Acquisition Functions for DGSM

두 가지 새로운 acquisition function 제안:

#### (a) DGSM Uncertainty Reduction (DGSM-UR)

다음 관측이 DGSM posterior variance를 최대로 줄이는 점을 선택:

```
α_UR(x) = E[ Var[ν_i | D_n] - Var[ν_i | D_n ∪ {(x, f(x))}] ]
```

GP의 해석적 성질을 이용하여 closed-form 계산:

```
α_UR(x) = Σ_i ∫ [Var reduction of (∂f/∂x_i)² at x' given observation at x] dx'
```

#### (b) DGSM Information Gain (DGSM-IG)

DGSM에 대한 mutual information을 최대화:

```
α_IG(x) = I(ν; f(x) | D_n) = H[ν | D_n] - E_{f(x)}[H[ν | D_n, (x, f(x))]]
```

### 3. Tractable Computation

GP의 gradient에 대한 closed-form posterior를 활용:

```
∂f/∂x_i | D_n ~ GP(∂m_n/∂x_i, ∂²k_n/∂x_i∂x_i')
```

이를 이용하여 DGSM의 posterior mean과 variance를 해석적으로 계산. Acquisition function 평가가 O(n²) 수준으로 tractable.

### 4. Sequential Design Loop

```
D_0 = initial design (LHS or Sobol' sequence)
for t = 1, ..., T:
    GP.fit(D_{t-1})
    x_t = argmax α(x; GP)     # DGSM-UR or DGSM-IG
    y_t = f(x_t)              # expensive evaluation
    D_t = D_{t-1} ∪ {(x_t, y_t)}
    estimate ν_i from GP posterior
```

### 5. Validation

- Benchmark: Ishigami, Sobol' g-function, Morris, Borehole (8D), Wing weight (10D)
- Real-world: vehicle safety crash simulation
- Baselines: random, IMSE, AL for Sobol' indices, space-filling
- DGSM-UR/IG가 동일 예산에서 DGSM 추정 RMSE를 크게 감소
- 특히 고차원(8D, 10D)에서 우위가 두드러짐

## Conclusion

- **DGSM에 직접 최적화된 active learning**이 기존 범용 AL 및 Sobol' index AL 대비 유의한 성능 향상.
- GP gradient의 해석적 posterior를 활용하여 **tractable한 acquisition function** 도출.
- 역문제 관점에서 중요하지 않은 입력 차원을 빠르게 식별 → **variation propagation 경로의 차원 축소**에 직접 활용 가능.
- NeurIPS 2024 발표로 방법론의 검증 수준이 높음.
