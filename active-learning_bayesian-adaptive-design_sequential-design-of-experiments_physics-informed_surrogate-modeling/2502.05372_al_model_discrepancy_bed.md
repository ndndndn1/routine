# Active Learning of Model Discrepancy with Bayesian Experimental Design

- **arXiv:** [2502.05372](https://arxiv.org/abs/2502.05372)
- **Authors:** Huchen Yang, Chuanqi Chen, Jin-Long Wu (University of Wisconsin-Madison)
- **Submitted:** 2025-02-07
- **Published in:** Computer Methods in Applied Mechanics and Engineering, Vol. 446, 2025, Art. 118198
- **Keywords:** active learning, bayesian adaptive design, sequential design of experiments, physics-informed, surrogate modeling

## Methods

1. **Model Discrepancy Learning**
   - 디지털 트윈의 물리 모델(numerical solver)과 실제 시스템 간의 모델 불일치(model discrepancy)를 데이터로 학습
   - Neural ODE 기반 보정 항(correction term)이 물리 솔버 출력에 추가되어 불일치를 포착
   - 물리 기반 solver를 교체하지 않고, 사후적으로 보정

2. **Sequential Bayesian Experimental Design (BED)**
   - 각 단계에서 Expected Information Gain(EIG)을 최대화하는 최적 실험 조건을 선택
   - 순차적으로 데이터를 수집하며, 모델 불일치 학습에 가장 정보량이 큰 영역을 능동적으로 탐색
   - Random 또는 grid-based 실험 대비 훨씬 적은 실험 횟수로 동일 정확도 달성

3. **Ensemble Kalman Method**
   - 고차원 매개변수 공간에서 효율적 Bayesian 추론을 위해 Ensemble Kalman Inversion(EKI) 사용
   - Gradient-free이므로 auto-differentiable solver뿐 아니라 기존 numerical solver(블랙박스)와도 호환

4. **Compatibility**
   - Classical numerical solvers (FEM, FDM 등) — gradient-free path via EKI
   - Modern auto-differentiable solvers (JAX, PyTorch) — gradient-based path
   - 두 경로 모두 지원하는 유연한 프레임워크

5. **Experiments**
   - Lorenz 96 시스템, Burgers 방정식 등에서 모델 불일치의 능동적 학습 검증
   - 순차 BED가 random sampling 대비 2~5배 적은 실험으로 동등한 불일치 복원 정확도 달성

## Conclusion

- 순차 BED + 능동 학습이 모델 불일치 학습의 데이터 효율성을 크게 향상
- Gradient-free(EKI)와 gradient-based 추론 경로를 모두 지원하여 실용성이 높음
- 물리 모델의 구조적 오류를 능동적으로 보정하여, 디지털 트윈의 예측 신뢰성을 높임
- Sequential variation propagation 관점에서, 모델 불일치에 의한 역문제 해의 불확실성 전파를 능동적 실험 설계로 억제
