# GUIDe: Generative and Uncertainty-Informed Inverse Design for On-Demand Nonlinear Functional Responses

- arXiv: [2509.05641](https://arxiv.org/abs/2509.05641)
- Submitted: 2025-09-08 (within routine window 2024-05-09 ~ 2026-05-09)
- Authors: Wei "Wayne" Chen, Doksoo Lee, Rachel Sun, Carlos M. Portela, Wei Chen
- Categories: cs.LG, cs.CE, cond-mat.mtrl-sci
- Keywords matched (>=3): **bayesian optimization**, **surrogate modeling**, **process variation**

## Why this paper fits the topic "sequential variation propagation"

GUIDe는 비선형 기능 응답의 역설계에서 발생하는 일대다(one-to-many) 모호성 문제를 불확실성 정보를 활용하여 해결한다. 동일한 목표 응답을 만족하는 다수의 설계 해가 존재하는 상황에서, 순방향 서로게이트 모델의 예측 불확실성을 MCMC 샘플링에 통합함으로써 설계 공간의 다양한 영역을 탐색하고 신뢰도 높은 역설계 솔루션을 생성한다. 이 접근법은 공정 변동(process variation)에 의한 응답 분산을 설계 단계에서 사전적으로 고려하여, 제조 불확실성에 강건한 설계를 가능하게 한다.

## Methods

1. **Problem setting**: 설계 변수 `x in R^d`에서 비선형 기능 응답 곡선 `y(t) in R^T` (T 시점)으로의 매핑
   ```
   Forward: x -> y(t),  t = 1, ..., T
   Inverse: y*(t) -> {x : f(x) approx y*(t)}  (one-to-many)
   ```

2. **Forward surrogate model**: 랜덤 포레스트(RF) 기반 설계->응답 순방향 모델
   ```
   f_RF(x) = (1/B) * sum_{b=1}^{B} T_b(x)
   ```
   - `B`개의 결정 트리 `T_b`의 앙상블 평균
   - 예측 불확실성: 트리별 예측의 분산
     ```
     sigma^2(x) = (1/B) * sum_{b=1}^{B} (T_b(x) - f_RF(x))^2
     ```

3. **Likelihood function**: 목표 응답 `y*`에 대한 설계 `x`의 적합도
   ```
   L(x | y*) = prod_{t=1}^{T} N(y*(t) | f_RF(x)_t, sigma^2(x)_t + sigma_n^2)
   ```
   - 서로게이트 모델의 예측 불확실성 `sigma^2(x)_t`를 likelihood에 직접 반영
   - 불확실성이 큰 영역에서는 likelihood가 넓어져 탐색을 유도

4. **MCMC-based inverse sampling**: Metropolis-Hastings 알고리즘으로 사후 분포에서 샘플링
   ```
   p(x | y*) propto L(x | y*) * p(x)
   
   Acceptance ratio:
   alpha = min(1, L(x') * p(x') / (L(x) * p(x)))
   ```
   - Proposal distribution: `x' ~ N(x, Sigma_prop)`
   - 다수의 독립 체인을 병렬 실행하여 다봉 분포(multimodal posterior) 탐색

5. **Uncertainty-informed design selection**: 샘플링된 후보 설계들 중 선택 기준
   ```
   x_best = argmin_{x in samples} [w_1 * MSE(f(x), y*) + w_2 * sigma_mean(x)]
   ```
   - MSE: 예측 응답과 목표 응답 간 오차
   - `sigma_mean`: 평균 예측 불확실성
   - 가중치 `w_1, w_2`로 정확도와 신뢰도 간 트레이드오프 조절

6. **Diversity metric**: 생성된 설계 솔루션의 다양성 평가
   ```
   Diversity = (1/N^2) * sum_{i,j} ||x_i - x_j||_2
   ```
   - 설계 공간에서 솔루션들의 평균 쌍별 거리

## Conclusion

- 비선형 기능 응답의 역설계에서 일대다 모호성을 불확실성 정보 기반 MCMC로 효과적으로 해결
- 랜덤 포레스트 서로게이트의 해석 가능성을 활용하여 설계 변수의 중요도를 직접 파악 가능
- 250개 미만의 학습 데이터로도 높은 역설계 성능 달성 (소량 데이터 환경에 적합)
- 음향 메타물질 및 광학 메타물질 설계에서 유전 알고리즘 대비 더 넓은 설계 공간 탐색
- 불확실성 정보를 통합함으로써 공정 변동에 강건한 설계 후보를 선별 가능
- 목표 기능 응답 만족과 함께 추가 성능 지표(figures of merit)도 고려하는 다기준 선택 지원
