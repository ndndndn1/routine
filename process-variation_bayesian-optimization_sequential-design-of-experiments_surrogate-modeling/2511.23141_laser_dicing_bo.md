# Automated Discovery of Laser Dicing Processes with Bayesian Optimization for Semiconductor Manufacturing

- arXiv: [2511.23141](https://arxiv.org/abs/2511.23141)
- Submitted: 2025-11-28 (within routine window 2024-05-09 ~ 2026-05-09)
- Authors: Lukas Frahm, Sebastian Pineda Arango, Josif Grabocka
- Categories: cs.LG, cs.AI, stat.ML
- Keywords matched (>=4): **bayesian optimization**, **surrogate modeling**, **process variation**, **sequential design of experiments**

## Why this paper fits the topic "sequential variation propagation"

본 논문은 반도체 레이저 다이싱 공정에서 11개 공정 파라미터가 6개 품질 목표에 미치는 영향을 순차적 실험 설계(sequential DoE)를 통해 탐색한다. 레이저 공정의 특성상 동일 파라미터 설정에서도 품질 변동(process variation)이 발생하며, 이는 다대일 매핑의 전형적인 예시이다. 베이지안 최적화(BO)와 가우시안 프로세스(GP) 서로게이트 모델을 결합하여 이러한 공정 변동 하에서도 다목적 제약 조건을 만족하는 최적 공정 조건을 효율적으로 발견하며, 불확실성 기반 탐색-활용 균형을 통해 분산을 고려한 순차적 의사결정을 수행한다.

## Methods

1. **Problem formulation**: 다목적 제약 최적화 문제로 정의
   ```
   min  f_1(x), f_2(x), ..., f_K(x)
   s.t. g_j(x) <= 0,  j = 1, ..., J
        x in X subset R^11
   ```
   여기서 `x`는 11차원 공정 파라미터 (레이저 출력, 반복률, 스캔 속도, 초점 위치 등), `f_k`는 6개 품질 목표 (다이싱 폭, 깊이, 열영향구역, 치핑 크기 등)

2. **Gaussian Process surrogate**: 각 목적함수 및 제약함수에 대해 독립적 GP 서로게이트 모델 학습
   ```
   f_k(x) ~ GP(m_k(x), k_k(x, x'))
   k(x, x') = sigma^2 * exp(-0.5 * sum_d ((x_d - x'_d) / l_d)^2)
   ```
   - ARD (Automatic Relevance Determination) 커널로 파라미터별 중요도 자동 학습
   - 하이퍼파라미터는 marginal likelihood 최대화로 학습

3. **Constrained multi-objective acquisition function**: Expected Hypervolume Improvement (EHVI)를 제약 조건과 결합
   ```
   alpha(x) = EHVI(x) * prod_j Pr(g_j(x) <= 0)
   ```
   - EHVI: 현재 Pareto front 대비 hypervolume 개선 기대값
   - 실현 가능성 확률을 곱하여 제약 만족을 유도

4. **Sequential experimental design loop**:
   ```
   for t = 1, 2, ..., T:
       1. GP 서로게이트 모델 업데이트 with D_t = {(x_i, y_i)}_{i=1}^{t-1}
       2. Acquisition function alpha(x) 최적화: x_t = argmax alpha(x)
       3. 실제 레이저 다이싱 실험 수행: y_t = f(x_t) + epsilon
       4. 데이터셋 업데이트: D_{t+1} = D_t union {(x_t, y_t)}
   ```

5. **Noise handling for process variation**: 관측 노이즈 `epsilon ~ N(0, sigma_n^2)`를 GP 모델에 명시적으로 포함
   ```
   K_noisy = K + sigma_n^2 * I
   ```

6. **Initial design**: Latin Hypercube Sampling (LHS)으로 11차원 공간을 효율적으로 커버하는 초기 실험점 생성

## Conclusion

- 반도체 레이저 다이싱 공정에 베이지안 최적화를 적용한 최초의 자동화 공정 발견 사례
- 11개 공정 파라미터, 6개 품질 목표를 동시에 최적화하는 제약 다목적 BO 프레임워크 구현
- 기존 수동 공정 개발 대비 실험 횟수를 대폭 절감 (수백 회 -> 수십 회)
- GP 서로게이트의 ARD 커널을 통해 각 파라미터의 상대적 중요도를 자동으로 파악
- 발견된 공정 조건이 실제 생산 라인에 적용 가능한 수준의 품질을 달성
- 순차적 실험 설계가 공정 변동 하에서도 안정적인 최적해 탐색을 가능하게 함
