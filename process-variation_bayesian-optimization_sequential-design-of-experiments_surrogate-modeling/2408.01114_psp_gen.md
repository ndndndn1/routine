# PSP-GEN: Stochastic Inversion of the Process-Structure-Property Chain in Materials Design through Deep, Generative Probabilistic Modeling

- arXiv: [2408.01114](https://arxiv.org/abs/2408.01114)
- Submitted: 2024-08-02 (within routine window 2024-05-09 ~ 2026-05-09)
- Authors: Yian Wang, Yiming Chen, Wing Kam Liu
- Categories: cs.LG, cond-mat.mtrl-sci, cs.CE
- Keywords matched (>=3): **process variation**, **surrogate modeling**, **bayesian optimization**

## Why this paper fits the topic "sequential variation propagation"

본 논문은 재료 설계에서 공정(Process)-미세구조(Structure)-물성(Property)의 전방향 체인 전체에 걸친 확률적 역설계(stochastic inversion) 문제를 다룬다. 공정 파라미터에서 미세구조로의 매핑은 확률적 변동(process variation)을 내포하며, 미세구조에서 물성으로의 매핑 역시 다대일(many-to-one) 관계를 가지므로 역방향 설계 시 일대다(one-to-many) 모호성이 발생한다. PSP-GEN은 조건부 생성 모델과 잠재 변수를 활용하여 이러한 확률적 변동을 명시적으로 포착하고, 목표 물성을 만족하는 공정 조건의 분포를 생성함으로써 분산 제어(variance control)를 가능하게 한다.

## Methods

PSP-GEN은 PSP 체인의 각 단계를 조건부 생성 모델로 분해한다:

1. **Forward chain decomposition**: PSP 체인을 두 단계로 분해
   - Process -> Structure: `p(S | X_proc)` where `X_proc` denotes process parameters
   - Structure -> Property: `p(Y | S)` where `Y` denotes target properties

2. **Stochastic latent variable model**: 각 단계에서 잠재 변수 `z`를 도입하여 확률적 변동을 포착
   ```
   p(S | X_proc) = integral p(S | z, X_proc) p(z) dz
   ```
   여기서 `z ~ N(0, I)`는 공정 변동으로 인한 미세구조의 확률적 변동을 인코딩

3. **Conditional Variational Autoencoder (CVAE)** 기반 생성 모델:
   - Encoder: `q_phi(z | S, X_proc)` -- 미세구조와 공정 파라미터로부터 잠재 변수 추론
   - Decoder: `p_theta(S | z, X_proc)` -- 잠재 변수와 공정 파라미터로부터 미세구조 생성
   - 학습 목표 (ELBO):
     ```
     L = E_{q_phi(z|S,X)}[log p_theta(S|z,X)] - KL(q_phi(z|S,X) || p(z))
     ```

4. **Inverse design via posterior sampling**: 목표 물성 `Y*`가 주어지면 역방향으로:
   ```
   p(X_proc | Y*) = integral p(X_proc | S) p(S | Y*) dS
   ```
   - Structure-to-Property surrogate `f: S -> Y`를 학습하여 `p(S | Y*)`를 근사
   - MCMC 또는 importance sampling을 통해 역방향 분포에서 샘플링

5. **Surrogate model for forward prediction**: GP 또는 neural network 기반 서로게이트 모델이 Structure -> Property 매핑을 근사하여 빠른 평가를 가능하게 함

6. **Uncertainty quantification**: 생성된 역설계 솔루션의 불확실성을 잠재 변수의 사전 분포로부터 전파
   ```
   Var(Y) = E_z[Var(Y|z)] + Var_z[E(Y|z)]
   ```

## Conclusion

- PSP-GEN은 PSP 체인 전체를 동시에 역전시키는 최초의 심층 생성 확률 모델 프레임워크를 제시
- 공정 변동으로 인한 미세구조의 확률적 변동을 잠재 변수로 명시적으로 모델링
- 역설계 문제의 ill-posedness (일대다 모호성)를 확률적 프레임워크로 자연스럽게 해결
- 합성 및 실제 재료 데이터셋에서 결정론적 방법 대비 우수한 역설계 성능 입증
- 생성된 공정 조건이 목표 물성을 만족하면서도 제조 가능성을 유지하는 분포를 산출
