# Bayesian Inverse Problems Meet Flow Matching: Efficient and Flexible Inference via Transformers

- **arXiv:** [2503.01375](https://arxiv.org/abs/2503.01375)
- **Authors:** Daniil Sherki, Ivan Oseledets, Ekaterina Muravleva (Skolkovo Institute of Science and Technology)
- **Submitted:** 2025-03-03 (revised 2025-05-16)
- **Keywords:** Invertible Neural Networks, physics-informed, surrogate modeling

## Methods

1. **Conditional Flow Matching (CFM) for Posterior Sampling**
   - Bayesian 역문제의 사후 분포 p(theta | y)를 Conditional Flow Matching으로 직접 학습
   - 데이터로부터 조건부 확률 경로(conditional probability trajectory)를 학습하여, iterative simulation 없이 단일 forward pass로 사후 샘플 생성
   - 비가우시안(non-Gaussian) 및 다봉(multimodal) 사후 분포 모두 포착 가능

2. **Transformer Architecture**
   - 관측 데이터 수가 가변적인(arbitrary number of observations) 문제에 대응하기 위해 Transformer 채택
   - Self-attention이 관측 간 상호 정보를 집약하여 사후 분포 추정의 품질을 향상
   - Amortized inference: 학습 후 새로운 관측 데이터에 대해 재학습 없이 즉시 추론

3. **Physics-Informed Applications**
   - Nonlinear model, disease dynamics framework, 2D Darcy flow PDE에서 검증
   - PDE의 물리 구조가 반영된 사후 분포를 정확히 복원

4. **Performance**
   - 매개변수 복원 상대 오차 약 1.5%
   - 전통적 MCMC 대비 추론 시간 **CPU에서 최대 2000배** 단축
   - GPU 환경에서는 추가 가속

## Conclusion

- CFM + Transformer가 Bayesian 역문제의 사후 샘플링을 대폭 가속하면서 정확도를 유지
- 관측 수에 무관한 유연한 구조로, 실험 설계에서 관측 조건이 변할 때에도 재학습 불필요
- 비가우시안·다봉 사후 분포를 자연스럽게 학습하여, one-to-many 역문제의 해 다중성을 정확히 표현
- Sequential variation propagation에서 역방향 불확실성 전파를 실시간으로 추정하는 surrogate로 활용 가능
