# Flow Matching Meets PDEs: A Unified Framework for Physics-Constrained Generation (PBFM)

- **arXiv**: [2506.08604](https://arxiv.org/abs/2506.08604)
- **Authors**: Giacomo Baldan, Qiang Liu, Alberto Guardone, Nils Thuerey
- **Submitted**: 2025-06-10
- **Keywords**: invertible neural networks, physics-informed, surrogate modeling

## Methods

PBFM embeds physical constraints (PDE residuals and algebraic relations) directly into the flow matching objective, creating a physics-constrained generative model for surrogate modeling and uncertainty quantification.

1. **Flow Matching Generative Framework**: The base model uses flow matching to learn a continuous normalizing flow (an invertible neural network) that transforms noise into physically valid solution fields. Flow matching provides stable training and flexible architecture choices compared to diffusion models.

2. **Physics-Based Residual Loss**: PDE residuals (e.g., continuity equation, momentum conservation) and algebraic constraints are computed on generated samples and minimized alongside the flow matching loss. This embeds physics directly into the generative process without requiring hyperparameter tuning of relative loss weights.

3. **Temporal Unrolling**: At training time, the model unrolls the ODE integration to improve the accuracy of the final (noise-free) sample prediction. This addresses a systematic error in standard flow matching where the training loss on intermediate noisy states does not guarantee accuracy of the clean output.

4. **Minimum Noise Level Analysis**: The paper analyzes the role of the minimum noise level sigma_min in the context of physical constraints. Too-small sigma_min can amplify physics residuals in the final generation step, while too-large sigma_min blurs physical features. An optimal regime is identified.

5. **Stochastic Sampling Strategy**: A stochastic variant of the ODE solver is introduced during sampling to reduce physical residuals. The added noise acts as regularization during generation, preventing the accumulation of physics-violating artifacts.

## Conclusion

PBFM achieves up to 8x more accurate physical residuals compared to standard flow matching while outperforming existing methods in distributional accuracy across three representative PDE problems. The framework provides a principled approach to physics-constrained generative modeling for surrogate applications: it generates diverse, physically valid samples that can be used for uncertainty quantification, ensemble-based inference, and accelerated simulation. The temporal unrolling and stochastic sampling innovations address practical challenges in deploying flow-based models for physics applications. PBFM establishes flow matching as a competitive framework for physics-informed surrogate modeling alongside diffusion-based alternatives.

```python
import torch
import torch.nn as nn

class PhysicsBasedFlowMatching(nn.Module):
    def __init__(self, field_channels, hidden=64, cond_dim=0):
        super().__init__()
        in_ch = field_channels + 1 + cond_dim
        self.net = nn.Sequential(
            nn.Conv2d(in_ch, hidden, 3, padding=1), nn.SiLU(),
            nn.Conv2d(hidden, hidden, 3, padding=1), nn.SiLU(),
            nn.Conv2d(hidden, hidden, 3, padding=1), nn.SiLU(),
            nn.Conv2d(hidden, field_channels, 3, padding=1),
        )
        self.field_channels = field_channels

    def velocity(self, x, t, cond=None):
        b, c, h, w = x.shape
        t_map = t.view(b, 1, 1, 1).expand(b, 1, h, w)
        if cond is not None:
            inp = torch.cat([x, t_map, cond], dim=1)
        else:
            inp = torch.cat([x, t_map], dim=1)
        return self.net(inp)

    def flow_matching_loss(self, x0, x1, cond=None):
        b = x0.shape[0]
        t = torch.rand(b, device=x0.device)
        t_expand = t.view(b, 1, 1, 1)
        xt = (1 - t_expand) * x0 + t_expand * x1
        target_v = x1 - x0
        pred_v = self.velocity(xt, t, cond)
        return torch.mean((pred_v - target_v) ** 2)

    def physics_residual(self, field, dx=1.0):
        u = field[:, 0:1]
        v = field[:, 1:2] if self.field_channels > 1 else torch.zeros_like(u)
        du_dx = (torch.roll(u, -1, -1) - torch.roll(u, 1, -1)) / (2 * dx)
        dv_dy = (torch.roll(v, -1, -2) - torch.roll(v, 1, -2)) / (2 * dx)
        continuity = du_dx + dv_dy
        return torch.mean(continuity ** 2)

    def combined_loss(self, x0, x1, cond=None, physics_weight=0.1):
        fm_loss = self.flow_matching_loss(x0, x1, cond)
        with torch.no_grad():
            t = torch.ones(x1.shape[0], device=x1.device)
        generated = self.generate(x1.shape[0], x1.shape[-2:], cond, n_steps=10)
        phys_loss = self.physics_residual(generated)
        return fm_loss + physics_weight * phys_loss

    @torch.no_grad()
    def generate(self, batch_size, spatial_size, cond=None, n_steps=50,
                 sigma_min=0.01, stochastic=False):
        h, w = spatial_size
        x = torch.randn(batch_size, self.field_channels, h, w,
                        device=next(self.parameters()).device)
        dt = 1.0 / n_steps
        for step in range(n_steps):
            t = torch.full((batch_size,), step * dt, device=x.device)
            v = self.velocity(x, t, cond)
            x = x + v * dt
            if stochastic and step < n_steps - 1:
                noise_scale = sigma_min * (1 - (step + 1) * dt)
                x = x + noise_scale * torch.randn_like(x)
        return x
```
