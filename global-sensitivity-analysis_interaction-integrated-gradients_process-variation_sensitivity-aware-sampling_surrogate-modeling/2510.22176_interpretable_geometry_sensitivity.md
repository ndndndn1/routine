# Interpretable Geometry Sensitivity for Inverse Design of Integrated Photonics

- **arXiv**: [2510.22176](https://arxiv.org/abs/2510.22176)
- **Authors**: Junho Park, Taehan Kim, Mohammad Ali, Di Liang
- **Submitted**: 2025-10-25 (revised 2026-02-28)
- **Keywords**: process variation, global sensitivity analysis, sensitivity-aware sampling, surrogate modeling, Interaction-Integrated Gradients (I-IG)

## Methods

This paper presents an interpretability workflow for inverse-designed photonic devices that reveals how fabrication-induced process variations affect device performance at the pixel level.

1. **Lightweight Convolutional Surrogate**: A CNN-based surrogate model is trained to regress figures of merit (insertion loss, crosstalk) from the binary mask representation of inverse-designed wavelength-division demultiplexers (WDMs). The surrogate replaces expensive electromagnetic simulations for rapid evaluation.

2. **Integrated Gradients (IG) Attribution**: The Integrated Gradients method is applied to the trained surrogate to produce pixel-level attribution maps. Each pixel in the device's binary mask receives a score indicating its contribution to the predicted transmission. The IG path integral runs from a baseline (uniform slab) to the actual design, ensuring axiom compliance (sensitivity + implementation invariance).

3. **Sensitivity Map Generation**: High-attribution pixels are identified as fabrication-sensitive hotspots. These correspond to physically meaningful substructures: splitter hubs, high-curvature edges, and narrow waveguide gaps where small geometric perturbations have disproportionate impact on optical performance.

4. **Experimental Validation**: Controlled perturbations in high-sensitivity regions produce up to 11x higher excess insertion loss compared to perturbations in non-sensitive regions, experimentally confirming the attribution maps' physical validity. This bridges the gap between computational attribution and real fabrication variability.

5. **Fabrication-Aware Design Rule Checking**: The sensitivity maps enable foundry-compatible constraint allocation: fabrication tolerances can be tightened in high-sensitivity regions and relaxed elsewhere, optimizing the trade-off between manufacturing cost and device performance without modifying the electromagnetic solver.

## Conclusion

The Integrated Gradients-based interpretability workflow provides a practical explainability layer for inverse-designed photonic devices. The pixel-level sensitivity maps correctly identify physically meaningful substructures that dominate device performance under fabrication variability. The experimental validation (11x higher loss from perturbations in high-sensitivity regions vs. low-sensitivity regions) demonstrates that the computational attribution maps are physically accurate predictors of process variation impact. The approach is solver-agnostic and can be applied to any existing inverse design pipeline without modification, offering a pathway for fabrication-aware design optimization in integrated photonics.

import torch
import torch.nn as nn
import numpy as np

class PhotonicSurrogate(nn.Module):
    def __init__(self, mask_size=64, n_outputs=4):
        super().__init__()
        self.conv = nn.Sequential(
            nn.Conv2d(1, 32, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2),
            nn.Conv2d(32, 64, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2),
            nn.Conv2d(64, 128, 3, padding=1), nn.ReLU(), nn.AdaptiveAvgPool2d(4),
        )
        self.fc = nn.Sequential(
            nn.Linear(128 * 16, 256), nn.ReLU(),
            nn.Linear(256, n_outputs),
        )

    def forward(self, x):
        h = self.conv(x)
        h = h.view(h.size(0), -1)
        return self.fc(h)

def integrated_gradients(model, design_mask, baseline=None, steps=100):
    if baseline is None:
        baseline = torch.zeros_like(design_mask)
    alphas = torch.linspace(0, 1, steps).view(-1, 1, 1, 1)
    interpolated = baseline + alphas * (design_mask - baseline)
    interpolated.requires_grad_(True)
    outputs = model(interpolated)
    target_output = outputs.sum(dim=0)
    grads = torch.autograd.grad(
        target_output.sum(), interpolated, create_graph=False
    )[0]
    avg_grads = grads.mean(dim=0)
    attributions = (design_mask - baseline) * avg_grads
    return attributions

def sensitivity_map(model, design_mask, baseline=None, steps=200):
    attr = integrated_gradients(model, design_mask, baseline, steps)
    sensitivity = torch.abs(attr).squeeze()
    sensitivity = sensitivity / (sensitivity.max() + 1e-8)
    return sensitivity

def identify_hotspots(sensitivity, threshold=0.7):
    hotspot_mask = sensitivity > threshold
    hotspot_coords = torch.nonzero(hotspot_mask, as_tuple=False)
    return hotspot_mask, hotspot_coords

def fabrication_aware_tolerance(sensitivity, base_tol=50e-9, tight_tol=10e-9):
    tolerance_map = base_tol * torch.ones_like(sensitivity)
    high_sens = sensitivity > 0.7
    tolerance_map[high_sens] = tight_tol
    return tolerance_map
