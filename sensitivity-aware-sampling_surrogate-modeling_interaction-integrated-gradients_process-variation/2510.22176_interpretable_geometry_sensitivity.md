## Why this paper fits the topic "sequential variation propagation"

역설계된 포토닉 디바이스는 자유형(free-form) 레이아웃이 직관적이지 않아, 제조 변동(process variation)이 성능에 미치는 영향을 진단하기 어렵다. 이 논문은 **Integrated Gradients(IG)** 를 경량 합성곱 서로게이트에 적용하여 **픽셀 수준 감도 맵**을 생성한다. 고감도 영역의 제어된 섭동이 비감도 영역 대비 ~11배 높은 삽입손실 초과를 유발함을 실험적으로 검증하여, 제조 변동이 성능으로 전파되는 경로를 직접적으로 시각화한다. 이는 variation propagation의 해석 가능한 귀인(attribution) 관점 구현이다.

## Methods

### 1. Lightweight Convolutional Surrogate

역설계된 디바이스의 이진 마스크(binary mask)를 입력으로 받아 성능 지표(FoM)를 예측하는 경량 CNN:

```
Binary mask (NxN pixels) → CNN surrogate → FoM (transmission)
```

- Full-wave 시뮬레이션(FDTD) 대비 수천 배 빠른 추론
- 서로게이트 정확도가 IG 귀인의 신뢰성을 좌우하므로, 고정확도 학습 필수

### 2. Integrated Gradients (IG) Attribution

각 픽셀이 예측 전송 값에 기여하는 정도를 귀인:

```
IG_i(x) = (x_i - x'_i) · ∫₀¹ (∂F/∂x_i)(x' + α(x - x')) dα
```

- `x`: 실제 디바이스 마스크, `x'`: 기준선(baseline, 보통 빈 영역)
- gradient × path integration으로 포화(saturation) 문제 회피
- **기하 구조 보존**: 픽셀 수준에서 원본 마스크 위에 직접 오버레이 가능

### 3. Sensitivity Map Generation

IG 값의 절대값으로 감도 맵 생성:

```
Sensitivity(i) = |IG_i(x)|
```

- 고감도 픽셀: 해당 영역의 제조 오차가 성능에 큰 영향
- 저감도 픽셀: 제조 공차를 완화해도 성능 저하 미미
- **설계 공차 할당(tolerance allocation)** 에 직접 활용 가능

### 4. Experimental Validation

1310/1550 nm 파장 분할 다중화기(WDM)에서 검증:

- 고감도 영역에 제어된 섭동 → **~11배 높은 초과 삽입손실**
- 비감도 영역 섭동 → 성능 변화 미미
- Full-wave 시뮬레이션 및 실측 결과와 IG 귀인 경향이 일치

## Conclusion

- Integrated Gradients + 경량 서로게이트 조합이 역설계 포토닉 디바이스의 **제조 변동 감도를 픽셀 수준으로 정량화**한다.
- 고감도 영역의 선별적 보호(또는 재설계)로 공정 변동에 대한 robustness 향상 가능.
- 기존 adjoint 기반 감도 분석과 달리, **학습된 서로게이트 위에서 작동**하므로 추가 시뮬레이션 불필요.
- 감도 맵은 설계자가 자유형 레이아웃의 성능 병목을 직관적으로 파악할 수 있게 해 준다.
- IG 기법은 transformer 기반 서로게이트에도 동일하게 적용 가능하여 확장성이 높다.
