# PIED: Physics-Informed Experimental Design for Inverse Problems

- **arXiv:** [2503.07070](https://arxiv.org/abs/2503.07070)
- **저자:** Apivich Hemachandra, Gregory Kang Ruey Lau, See-Kiong Ng, Bryan Kian Hsiang Low
- **발표일:** 2025-03-10 (ICLR 2025)
- **키워드:** physics-informed, sequential design of experiments, active learning
- **공식 코드:** https://github.com/apivich-h/pied

## 배경

과학·공학에서 PDE로 기술되는 시스템의 역문제를 풀기 위해서는 실험 설계(어디서 관측할 것인가)가 핵심이다. 기존 실험 설계 방법은 (1) 복잡한 수치 시뮬레이션 비용이 병목이 되고, (2) PINN(Physics-Informed Neural Network)의 장점(mesh-free, 미분 가능, 상각 학습)을 활용하지 못한다. PIED는 PINN을 실험 설계에 최초로 통합한 프레임워크이다.

## Methods

1. **PINN 기반 완전 미분 가능 아키텍처**
   - PINN이 PDE 해를 mesh-free로 근사하며, 설계 파라미터에 대해 end-to-end 미분 가능
   - 설계 변수(관측 위치) 최적화를 연속 공간에서 gradient-based로 수행
   - 수치 시뮬레이터 없이 PDE 물리를 직접 학습에 활용

2. **병렬화 + 메타 학습**
   - 다수의 PINN을 서로 다른 θ(미지 매개변수) 샘플에 대해 병렬 학습
   - MAML 스타일 메타 학습으로 PINN 초기화를 최적화 → 새로운 θ에 대한 빠른 적응
   - 계산 병목(각 θ별 PINN 재학습)을 메타 학습으로 해소

3. **PINN 학습 역학을 고려한 설계 최적화**
   - PINN 학습 중 발생하는 근사 오차가 설계 품질에 미치는 영향을 모델링
   - 설계 최적화 시 PINN의 수렴 상태를 함께 고려하여 과적합/미적합 영역을 구분
   - One-shot 배포: 한 번의 실험 설계로 최대 정보를 획득하는 시나리오에 특화

4. **순차적 확장**
   - 초기 설계 → 관측 수집 → PINN 업데이트 → 다음 설계 최적화 루프 가능
   - 각 단계에서 PINN의 현재 불확실성(PDE 잔차)을 설계 기준으로 활용
   - 능동 학습 관점: 정보 이득이 큰 관측 위치를 우선 선택

5. **실험**
   - 열 방정식, 반응-확산, Navier-Stokes 역문제
   - 시뮬레이션 기반 합성 데이터 + 실제 실험 데이터(열전도 측정)
   - 기존 D-optimal, Bayesian OED, 균등 배치 설계 대비 유의미한 역문제 정확도 향상

## Conclusion

- PINN + 실험 설계의 최초 통합으로, 수치 시뮬레이터 없이 PDE 역문제의 관측 설계 최적화
- 메타 학습이 PINN 재학습 비용을 대폭 절감하여 실용적 확장성 확보
- PINN 학습 역학 반영이 설계 품질을 추가로 향상
- 실제 실험 데이터에서도 기존 방법 대비 우수한 역추정 정확도 달성 (ICLR 2025)

## 주제 연관성

PDE 기반 순방향 모델의 역문제에서 PINN의 물리 잔차를 불확실성 신호로 활용한 능동적 실험 설계. 관측 위치를 순차적으로 최적화하여 해의 다중성을 정보 이론적으로 억제하며, 물리 법칙이 탐색 공간을 제약하는 역할을 한다.
