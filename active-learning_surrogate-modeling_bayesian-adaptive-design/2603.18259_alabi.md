- arXiv: [2603.18259](https://arxiv.org/abs/2603.18259)
- Authors: Jessica Birky, Rory K. Barnes
- Submitted: 2026-03 (within routine window 2026-03-16 ~ 2026-05-16, base date 2026-04-16)

## Why this paper fits the topic "sequential variation propagation"

관측→모델 파라미터 복원(inverse) 문제에서 likelihood가 수 초~수 분씩 걸릴 때, 전형적인 MCMC/nested sampling은 수만 번 평가가 필요해 실질적으로 불가능하다. ALABI는 GP surrogate가 log-posterior를 학습하도록 두고, **surrogate posterior variance가 큰 high-likelihood 영역에 다음 질의를 집중**시키는 sequential design 루프를 제안한다. 즉 one-to-many 역추론 문제에서 발생하는 다봉/모호한 posterior를 GP 분산(=불확실성)을 직접 최적화의 신호로 삼아 탐색 공간의 폭발을 억제한다. 순전파 관점에서 입력 파라미터의 variation이 likelihood에 어떻게 전파되는지를 surrogate가 흡수하고, 역방향에서는 그 전파된 variance를 이용해 질의 순서를 결정한다는 점에서 *sequential variation propagation*의 실용적 구현체다.

## Methods

### 1. 대리 모델

- GP surrogate `ŝ(θ) ≈ log p(D|θ) + log p(θ)` (unnormalized log-posterior)
- RBF/Matern kernel, hyperparameter는 marginal-likelihood로 재학습.

### 2. Active Learning Acquisition — BAPE 계열

- BAPE (Bayesian Active Posterior Estimation): `α(θ) = exp(2 μ(θ) + σ²(θ)) · (exp(σ²(θ)) - 1)`
  → high-posterior + high-variance 영역에 가중치, 다봉 posterior의 모드를 모두 훑는다.
- AGP, naive-variance 등 ablation 포함.

### 3. Sequential Design Loop

```
θ_train ← LHS initial design
for t = 1 … T:
    fit GP on (θ_train, log_post_train)
    θ_next = argmax_θ α_BAPE(θ; GP)
    y_next = log_posterior(θ_next)        # 비싼 forward model 1회
    θ_train += θ_next ; log_post_train += y_next
```

- Convergence criterion: GP 예측 posterior와 직전 posterior 사이 KL 또는 marginal parameter CDF 차이.

### 4. 하위 MCMC/Nested Sampler 인터페이스

- 학습이 끝난 GP를 black-box log-posterior로 래핑해 `emcee`, `dynesty`, `multinest`, `ultranest` 중 선택 가능.
- 이로써 sampler-agnostic adaptive Bayesian design을 구현.

### 5. 실험

- 최대 64차원까지 확장 가능.
- likelihood evaluation 시간 ≥1s인 문제에서 **10–1000×** 속도 향상.
- 천체물리 파라미터 추정(궤도, 항성 진화) 사례에서 thousand-fold 평가 절감.

## Conclusion

- GP 분산을 직접 이용한 BAPE acquisition이 one-to-many 역추론의 **posterior ambiguity**를 효율적으로 탐색한다.
- Sampler-agnostic 래퍼 덕분에 sequential Bayesian adaptive design을 기존 Bayesian 생태계에 끼워 넣을 수 있다.
- 재현 가능한 open-source Python 패키지로 배포 → 실제 엔지니어링/천문학 inverse 문제에 즉시 적용 가능.
