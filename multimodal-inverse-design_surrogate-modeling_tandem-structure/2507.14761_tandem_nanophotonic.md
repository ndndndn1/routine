# On-Demand Inverse Design for Narrowband Nanophotonic Structures Based on Generative Model and Tandem Network

- **arXiv**: [2507.14761](https://arxiv.org/abs/2507.14761)
- **Authors**: Yuxiao Li, Taeyoon Kim, Allen Zhang, Zengbo Wang, Yongmin Liu
- **Submitted**: 2025-07-19
- **Keywords**: tandem structure, multimodal inverse design, surrogate modeling, physics-informed

## Methods

This paper combines a Conditional Variational Autoencoder (CVAE) with a tandem neural network for inverse design of narrowband nanophotonic structures, addressing both the ill-posedness and input sensitivity of the inverse problem.

1. **Two-Stage Pipeline**: The framework operates in two stages. First, a CVAE adjusts idealized target spectra to physically realizable ones by learning the manifold of achievable spectral responses. Second, a tandem network maps the adjusted spectrum to structural parameters.

2. **CVAE for Spectrum Conditioning**: The CVAE is trained on simulated spectra from valid photonic structures. Given an arbitrary target spectrum (which may be physically unrealizable), it projects the target onto the nearest achievable spectrum. This prevents the inverse network from attempting impossible targets, a common failure mode in direct inverse approaches.

3. **Tandem Network Architecture**: The tandem network consists of an inverse network followed by a pre-trained forward network. The inverse network maps spectra to structural parameters; the forward network evaluates the predicted parameters' spectral response. During training, the inverse network is optimized to minimize the discrepancy between the input spectrum and the spectrum predicted by the forward network, rather than matching ground-truth parameters directly. This resolves the one-to-many ambiguity by focusing on functional equivalence rather than parameter-level matching.

4. **Narrowband Design Focus**: The method is specifically designed for narrowband spectral responses (e.g., sharp resonances), where the inverse problem is particularly ill-conditioned because small parameter changes can cause large spectral shifts.

5. **Robustness to Input Inaccuracies**: The CVAE pre-processing stage provides robustness against imprecise or noisy target specifications, which is critical for practical deployment where users may specify approximate rather than exact target responses.

## Conclusion

The CVAE + tandem network combination addresses two fundamental challenges in nanophotonic inverse design: the ill-posed nature of the one-to-many mapping and the sensitivity to input specification inaccuracies. The CVAE effectively constrains the target space to physically achievable spectra, while the tandem network resolves the ambiguity of the inverse mapping by optimizing for functional equivalence. The framework demonstrates accurate inverse design for narrowband photonic structures where conventional approaches struggle with the sharp spectral features. The approach is generalizable to other photonic design problems where the forward mapping is many-to-one.

import torch
import torch.nn as nn
import torch.nn.functional as F

class SpectrumCVAE(nn.Module):
    def __init__(self, spectrum_dim, latent_dim=32, hidden=256):
        super().__init__()
        self.encoder = nn.Sequential(
            nn.Linear(spectrum_dim * 2, hidden), nn.ReLU(),
            nn.Linear(hidden, hidden), nn.ReLU(),
        )
        self.fc_mu = nn.Linear(hidden, latent_dim)
        self.fc_logvar = nn.Linear(hidden, latent_dim)
        self.decoder = nn.Sequential(
            nn.Linear(latent_dim + spectrum_dim, hidden), nn.ReLU(),
            nn.Linear(hidden, hidden), nn.ReLU(),
            nn.Linear(hidden, spectrum_dim),
        )
        self.spectrum_dim = spectrum_dim

    def encode(self, x, c):
        h = self.encoder(torch.cat([x, c], dim=-1))
        return self.fc_mu(h), self.fc_logvar(h)

    def reparameterize(self, mu, logvar):
        std = torch.exp(0.5 * logvar)
        return mu + std * torch.randn_like(std)

    def decode(self, z, c):
        return self.decoder(torch.cat([z, c], dim=-1))

    def forward(self, target_spec, real_spec):
        mu, logvar = self.encode(real_spec, target_spec)
        z = self.reparameterize(mu, logvar)
        adjusted = self.decode(z, target_spec)
        return adjusted, mu, logvar

    def condition_spectrum(self, target_spec):
        z = torch.randn(target_spec.shape[0], self.fc_mu.out_features,
                        device=target_spec.device)
        return self.decode(z, target_spec)

class TandemNetwork(nn.Module):
    def __init__(self, spectrum_dim, param_dim, hidden=256):
        super().__init__()
        self.inverse_net = nn.Sequential(
            nn.Linear(spectrum_dim, hidden), nn.ReLU(),
            nn.Linear(hidden, hidden), nn.ReLU(),
            nn.Linear(hidden, param_dim), nn.Sigmoid(),
        )
        self.forward_net = nn.Sequential(
            nn.Linear(param_dim, hidden), nn.ReLU(),
            nn.Linear(hidden, hidden), nn.ReLU(),
            nn.Linear(hidden, spectrum_dim),
        )

    def forward(self, spectrum):
        params = self.inverse_net(spectrum)
        reconstructed = self.forward_net(params)
        return params, reconstructed

    def tandem_loss(self, target_spectrum):
        params, reconstructed = self.forward(target_spectrum)
        return F.mse_loss(reconstructed, target_spectrum)

class CVAETandemPipeline:
    def __init__(self, cvae, tandem):
        self.cvae = cvae
        self.tandem = tandem

    @torch.no_grad()
    def design(self, target_spectrum, n_candidates=10):
        adjusted_spectra = torch.stack([
            self.cvae.condition_spectrum(target_spectrum)
            for _ in range(n_candidates)
        ]).squeeze(1)
        all_params, all_recon = [], []
        for spec in adjusted_spectra:
            params, recon = self.tandem(spec.unsqueeze(0))
            all_params.append(params.squeeze(0))
            all_recon.append(recon.squeeze(0))
        all_params = torch.stack(all_params)
        all_recon = torch.stack(all_recon)
        errors = torch.norm(all_recon - target_spectrum, dim=-1)
        best_idx = torch.argmin(errors)
        return all_params[best_idx], all_params, errors
