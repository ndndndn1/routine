## Why this paper fits the topic "sequential variation propagation"

CVD(Chemical Vapor Deposition) 공정에서 반응기 설정 파라미터(온도, 가스 유량, 기판 위치 등)가 코팅 두께로 매핑되는 순방향 문제는 many-to-one이다: 다양한 파라미터 조합이 유사한 두께 프로파일을 생성할 수 있다. 이 논문은 **XGBoost 서로게이트**와 **Approximate Bayesian Computation(ABC)** 를 결합하여, 측정 두께로부터 공정 파라미터의 사후 분포를 역추정하면서 측정 노이즈와 공정 변동의 불확실성을 신뢰구간으로 정량화한다.

## Methods

### 1. XGBoost Surrogate Model

반응기 설정 → 코팅 두께 매핑의 데이터 기반 서로게이트:

```
X = (temperature, gas_flow, substrate_pos, ...) → XGBoost → thickness
```

- 연속, 이산 정수, 이진, 범주형(Doc2Vec 임베딩) 변수의 혼합 데이터 처리
- 물리 기반 시뮬레이터 대비 수천 배 빠른 추론 → ABC 샘플링에 필수적

### 2. Bayesian Model Selection for Priors

파라미터 사전분포를 데이터로부터 자동 결정:

```
P(M_i | D) ∝ P(D | M_i) · P(M_i)
```

- 복수의 사전분포 후보(균일, 정규, 로그정규 등) 중 evidence 최대화로 선택
- 부적절한 사전분포로 인한 사후분포 왜곡 방지

### 3. Weighted Approximate Bayesian Computation (ABC)

사후분포를 ABC로 추정:

```
1. Prior에서 θ 샘플링
2. Surrogate로 y_sim = f(θ) 계산
3. Summary statistics S(y_sim)과 S(y_obs) 비교
4. ||S(y_sim) - S(y_obs)|| < ε인 θ를 수용
5. 가중치 부여하여 사후분포 근사
```

- 요약 통계량(summary statistics) 기반으로 측정 노이즈 필터링
- 가중 ABC로 acceptance 효율 개선

### 4. Geometry-Aware Clustering

생산 그룹별 분석을 위한 기하학 임베딩 기반 클러스터링:

```
Reactor locations → geometry embedding → clustering → group-wise IUQ
```

- 동질적(homogeneous) 생산 그룹 내에서 IUQ 수행하여 편향 감소
- 반응기 위치 간 공정 변동의 공간적 구조를 포착

### 5. 검증

- 실제 CVD 반응기 데이터에서 파라미터 신뢰구간 추정
- 복수 반응기 위치에 걸친 크로스-밸리데이션으로 서로게이트 정확도 확인
- ABC로 추정한 사후분포가 공정 전문가의 사전 지식과 일관

## Conclusion

- XGBoost 서로게이트 + ABC의 결합이 **산업 CVD 공정의 역 불확실성 정량화**를 실현한다.
- 혼합 데이터 유형(연속/이산/범주형)을 통합적으로 처리하는 프레임워크.
- Bayesian model selection이 사전분포 오명세(misspecification) 위험을 완화.
- 공정 변동(process variation)이 코팅 두께에 전파되는 메커니즘을 사후분포의 신뢰구간으로 정량화.
- 기하학 기반 클러스터링이 반응기 위치별 변동 패턴을 분리하여 분석 정밀도 향상.
