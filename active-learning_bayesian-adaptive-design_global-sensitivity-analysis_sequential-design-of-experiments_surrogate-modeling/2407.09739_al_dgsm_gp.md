# Active Learning for Derivative-Based Global Sensitivity Analysis with Gaussian Processes

- **arXiv**: [2407.09739](https://arxiv.org/abs/2407.09739)
- **Authors**: Syrine Belakaria, Benjamin Letham, Janardhan Rao Doppa, Barbara Engelhardt, Stefano Ermon, Eytan Bakshy
- **Submitted**: 2024-07-13 (NeurIPS 2024)
- **Keywords**: active learning, global sensitivity analysis, surrogate modeling, sequential design of experiments, bayesian adaptive design

## Methods

1. **Gaussian Process (GP) surrogate**: A GP emulator is fit to expensive black-box function evaluations; the derivative of the GP posterior provides closed-form estimates for Derivative-based Global Sensitivity Measures (DGSMs), including upper bounds on Sobol total-effect indices.

2. **Novel acquisition functions**: Two families of active learning acquisition functions are proposed that directly target DGSM estimation quality:
   - **Variance/Uncertainty Reduction (VR)**: selects the next evaluation point to maximally reduce posterior variance of the DGSM estimate.
   - **Information Gain (IG)**: selects the point that maximises expected information gain about the sensitivity indices under the GP model.

3. **Integrated (global) variants**: Both VR and IG are extended to integrated forms that aggregate the sensitivity reduction across the full input space rather than at a single point.

4. **Sequential design loop**: At each iteration the acquisition function is optimised, the true function is evaluated, and the GP is updated—following the standard Bayesian sequential design of experiments paradigm.

5. **Benchmarking**: Compared against quasi-random Sobol sampling, the `activegp` R-package baseline, and 19+ acquisition strategy variants on standard sensitivity analysis test functions and a vehicle safety engineering case study.

## Conclusion

The proposed Bayesian active learning framework is the first to directly target DGSMs, enabling efficient identification of influential input variables with far fewer expensive function evaluations than passive sampling. Variance reduction and information gain acquisition functions consistently outperform quasi-random and prior GP-based baselines. The approach is validated on both benchmark sensitivity problems and a real-world vehicle safety application.
