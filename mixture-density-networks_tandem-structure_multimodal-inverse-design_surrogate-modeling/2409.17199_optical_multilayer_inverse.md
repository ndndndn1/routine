# Optical Multilayer Thin Film Structure Inverse Design: From Optimization to Deep Learning

- Authors: Taigao Ma, Mingqian Ma, L. Jay Guo

## Why this paper fits the topic "sequential variation propagation"

광학 다층 박막 구조의 역설계 문제는 본질적으로 many-to-one forward mapping (여러 구조가 동일한 광학 스펙트럼을 생성)과 one-to-many inverse mapping (하나의 목표 스펙트럼에 대해 다수의 유효한 구조가 존재) 간의 모호성을 다룬다. 본 리뷰 논문은 Tandem Network, MDN, VAE, GAN 등 다양한 딥러닝 기법들이 이러한 다중 해 모호성(multimodal ambiguity)을 어떻게 해결하는지 체계적으로 분석하며, 특히 surrogate forward model을 통한 분산 제어와 active learning을 통한 탐색 공간 효율화 전략을 포괄적으로 비교한다. 이는 순차적 변동 전파(sequential variation propagation) 관점에서 forward model의 예측 불확실성이 inverse design의 해 품질에 어떻게 전파되는지를 이해하는 데 핵심적인 프레임워크를 제공한다.

## Methods

### 1. Forward Surrogate Model (순방향 대리 모델)

Transfer Matrix Method(TMM)를 대체하는 신경망 기반 대리 모델로, 구조 파라미터를 입력받아 광학 응답(반사/투과 스펙트럼)을 예측한다.

```
Forward model: f_θ(d) → R(λ)
  Input:  d = [d_1, d_2, ..., d_L]  (layer thicknesses)
  Output: R(λ) = reflectance spectrum over wavelength range

Loss_forward = (1/N) Σ_i ||f_θ(d_i) - R_true(λ)_i||^2   (MSE)
```

### 2. Tandem Network (탠덤 네트워크)

Inverse network와 pre-trained forward network를 직렬 연결하여 one-to-many 문제를 우회한다.

```
Architecture:
  Step 1: Train forward model f_θ(d) → R(λ)  (freeze weights)
  Step 2: Train inverse model g_φ(R) → d_pred
  Step 3: Connect: R_input → g_φ → d_pred → f_θ → R_recon

Tandem Loss:
  L_tandem = α · ||R_recon - R_input||^2 + β · ||d_pred - d_true||^2

  where R_recon = f_θ(g_φ(R_input))
  α, β are weighting hyperparameters (typically α >> β or β = 0)
```

Forward model의 가중치는 고정(frozen)되어 gradient가 inverse network로만 역전파된다. 이를 통해 inverse network는 forward model이 원래 스펙트럼을 재생성할 수 있는 구조를 예측하도록 학습한다.

### 3. Mixture Density Network (MDN)

다중 해를 명시적으로 모델링하기 위해 조건부 분포를 Gaussian mixture로 파라미터화한다.

```
p(d|R) = Σ_{k=1}^{K} π_k(R) · N(d; μ_k(R), σ_k^2(R))

  π_k(R): mixing coefficients (Σ_k π_k = 1, π_k > 0)
  μ_k(R): component means (design parameter predictions)
  σ_k^2(R): component variances

Network output layer:
  - K mixing coefficients via softmax
  - K × D means (D = number of design parameters)
  - K × D variances via exp() or softplus()

Loss (Negative Log-Likelihood):
  L_NLL = -Σ_i log[ Σ_{k=1}^{K} π_k(R_i) · N(d_i; μ_k(R_i), σ_k^2(R_i)) ]
```

MDN은 K개의 Gaussian 성분을 통해 다중 해를 동시에 표현하며, 학습 후 sampling을 통해 다양한 유효 구조를 생성할 수 있다.

### 4. Active Learning (능동 학습)

데이터 효율성을 높이기 위해, surrogate model의 예측 불확실성이 높은 영역에서 선택적으로 시뮬레이션을 수행한다.

```
Active Learning Loop:
  1. Train surrogate model on initial dataset D_0
  2. Evaluate uncertainty U(d) for candidate designs
  3. Select d* = argmax U(d) from candidate pool
  4. Run physics simulation (TMM) for d*
  5. Add (d*, R(d*)) to training set
  6. Retrain surrogate model
  7. Repeat until convergence

Uncertainty metric examples:
  - Ensemble disagreement
  - MC-Dropout variance
  - Query-by-committee
```

### 5. Other Approaches (VAE, GAN, Neural Adjoint)

```
VAE for inverse design:
  Encoder: R(λ) → (μ_z, σ_z)  → z ~ N(μ_z, σ_z^2)
  Decoder: z → d_pred
  L_VAE = ||R_recon - R_target||^2 + β · KL(q(z|R) || p(z))

GAN for inverse design:
  Generator: G(z, R_target) → d_pred
  Discriminator: D(d, R) → real/fake
  L_GAN = min_G max_D [E[log D(d_real)] + E[log(1 - D(G(z)))]]
         + λ · ||f_θ(G(z)) - R_target||^2

Neural Adjoint:
  Optimize d directly via gradient descent through pre-trained forward model:
  d* = argmin_d ||f_θ(d) - R_target||^2
  Update: d ← d - η · ∂||f_θ(d) - R_target||^2 / ∂d
```

## Conclusion

- 광학 다층 박막의 역설계는 본질적으로 one-to-many mapping 문제이며, 단순한 inverse neural network는 다중 해 사이에서 평균화(averaging)되는 문제가 발생한다
- **Tandem network**는 pre-trained forward model을 통해 스펙트럼 공간에서의 재구성 오차를 최소화하여 one-to-many 문제를 효과적으로 우회한다
- **MDN**은 조건부 확률 분포를 직접 학습하여 다중 해를 명시적으로 표현하는 유일한 방법이며, 생성적 접근법 중 가장 해석 가능하다
- **Active learning**은 시뮬레이션 비용이 높은 경우 데이터 효율성을 크게 향상시킨다
- **Surrogate model**의 정확도가 tandem network와 neural adjoint 방식의 역설계 품질에 직접적으로 영향을 미치므로, forward model의 분산 제어가 핵심이다
- 최근 OptoGPT 등 foundation model 기반 접근법이 다양한 재료 배치와 구조에 대한 범용 역설계 가능성을 제시하고 있다
