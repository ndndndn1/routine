# Data-Driven Inverse Uncertainty Quantification: Application to the Chemical Vapor Deposition Reactor Modeling

- arXiv: [2512.13354](https://arxiv.org/abs/2512.13354)
- HTML: https://arxiv.org/html/2512.13354
- Submitted: 2025-12 (within routine window 2024-05-02 ~ 2026-05-02, base date 2026-05-02)
- Categories: cs.CE, stat.ML
- Keywords matched (≥3): **process variation**, **global sensitivity analysis**, **surrogate modeling**, **bayesian optimization**

## Why this paper fits the topic "sequential variation propagation"

Chemical Vapor Deposition (CVD) 공정에서 입력 파라미터(온도, 유량, 압력 등)의 변동이 코팅 품질(두께 균일성, 조성)에 어떻게 전파되는지를 역으로 추정하는 inverse UQ 문제다. 순방향 시뮬레이션은 many-to-one이지만, 관측된 코팅 품질로부터 공정 파라미터 분포를 역추정하는 것은 one-to-many 문제다. XGBoost surrogate로 비용 높은 CFD 시뮬레이션을 대체하고, Approximate Bayesian Computation (ABC)으로 공정 파라미터의 사후분포를 추정하며, Sobol' indices 기반 global sensitivity analysis로 품질 변동에 가장 기여하는 파라미터를 식별한다.

## Methods

### 1. CVD Reactor Forward Model

- 다중 물리(multi-physics) CFD 시뮬레이션: 유동 + 열전달 + 화학 반응 + 질량 전달
- 입력: 가스 유량, 기판 온도, 반응기 압력, 전구체 농도 등
- 출력: 코팅 두께 분포, 조성 균일성 등

### 2. XGBoost Surrogate Model

- CFD 시뮬레이션 결과로 XGBoost 회귀 모델 학습
- Gradient boosting ensemble로 비선형 입출력 관계 포착
- Cross-validation으로 surrogate accuracy 검증 (R² > 0.95)

### 3. Global Sensitivity Analysis (Sobol' Indices)

- Surrogate 기반 Monte Carlo sampling으로 Sobol' first-order 및 total-order indices 계산
- `S_i` (first-order): 각 파라미터의 독립적 기여
- `S_{Ti}` (total-order): 상호작용 효과 포함 기여
- 기판 온도와 전구체 농도가 코팅 품질 변동의 주요 원인으로 식별

### 4. Inverse UQ via Approximate Bayesian Computation

- 관측된 코팅 품질 데이터로부터 공정 파라미터의 사후분포 추정
- ABC-SMC (Sequential Monte Carlo): 순차적으로 tolerance ε 줄이며 posterior 정교화
- XGBoost surrogate가 ABC의 forward model 호출을 대체 → 계산 비용 O(10⁴) 배 절감

### 5. Validation

- 산업 CVD 반응기 데이터로 검증
- ABC posterior의 MAP 추정이 실제 공정 조건과 일치
- GSA 결과가 도메인 전문가의 경험적 지식과 부합
- Surrogate-based ABC가 direct ABC 대비 동등 정확도, 수천 배 빠른 수행

## Conclusion

- XGBoost surrogate + ABC-SMC + Sobol' GSA를 통합한 **CVD 공정의 inverse UQ 프레임워크**.
- 공정 변동(process variation)이 코팅 품질에 전파되는 메커니즘을 정량적으로 역추정.
- GSA가 품질 변동의 주요 원인 파라미터를 식별하여 공정 제어 우선순위 결정 지원.
- Surrogate 기반 접근으로 산업 규모 문제에 실용적 적용 가능.
