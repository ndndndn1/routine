# JADAI: Jointly Amortizing Adaptive Design and Bayesian Inference

- **arXiv**: [2512.22999](https://arxiv.org/abs/2512.22999)
- **Authors**: Niels Bracher, Lars Kuhmichel, Desi R. Ivanova, Xavier Intes, Paul-Christian Burkner, Stefan T. Radev
- **Submitted**: 2025-12-28
- **Keywords**: bayesian adaptive design, sequential design of experiments, invertible neural networks

## Methods

JADAI jointly trains three neural components end-to-end for adaptive experimental design with Bayesian inference, amortizing the cost of both design optimization and posterior computation.

1. **Three-Component Architecture**: The framework consists of (a) a policy network that selects the next experiment given the history, (b) a history network that compresses the growing sequence of experiment-outcome pairs into a fixed-size summary, and (c) an inference network that maps the summary to the posterior distribution over model parameters. All three are trained jointly end-to-end.

2. **Amortized Design Optimization**: Traditional sequential experimental design requires solving an expensive optimization problem at each step (maximizing expected information gain). JADAI amortizes this cost by training the policy network on simulated experimental sequences, so at deployment time, the next experiment is selected by a single forward pass rather than iterative optimization.

3. **End-to-End Training Objective**: The loss function aggregates incremental reductions in posterior error along experimental sequences. This directly optimizes for the quality of inference after a complete sequence of adaptively chosen experiments, rather than greedily maximizing information gain at each step.

4. **Flow-Based Inference Network**: The inference network uses normalizing flows (a class of invertible neural networks) to represent complex, potentially multimodal posterior distributions. This is essential for inverse problems where the posterior over model parameters can be non-Gaussian and multimodal.

5. **Scalability to Variable-Length Sequences**: The history network uses attention-based architectures to handle variable-length experimental sequences, enabling deployment in settings where the total number of experiments is not known in advance.

## Conclusion

JADAI demonstrates that jointly amortizing design and inference yields better experimental sequences than greedy sequential approaches, while being orders of magnitude faster at deployment time. The flow-based inference network captures complex posterior structure including multimodality, which is critical for inverse problems with non-unique solutions. The framework is validated on several benchmark problems in Bayesian experimental design, showing that the jointly trained policy learns to balance exploration and exploitation across the experimental sequence without explicit acquisition function engineering.

import torch
import torch.nn as nn

class HistoryEncoder(nn.Module):
    def __init__(self, design_dim, outcome_dim, hidden=128, summary_dim=64):
        super().__init__()
        self.embed = nn.Linear(design_dim + outcome_dim, hidden)
        self.attn = nn.MultiheadAttention(hidden, num_heads=4, batch_first=True)
        self.project = nn.Linear(hidden, summary_dim)

    def forward(self, designs, outcomes):
        pairs = torch.cat([designs, outcomes], dim=-1)
        h = torch.relu(self.embed(pairs))
        h, _ = self.attn(h, h, h)
        summary = h.mean(dim=1)
        return self.project(summary)

class DesignPolicy(nn.Module):
    def __init__(self, summary_dim, design_dim, hidden=128):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(summary_dim, hidden), nn.SiLU(),
            nn.Linear(hidden, hidden), nn.SiLU(),
            nn.Linear(hidden, design_dim),
        )

    def forward(self, summary):
        return self.net(summary)

class FlowInference(nn.Module):
    def __init__(self, param_dim, summary_dim, n_layers=4, hidden=128):
        super().__init__()
        self.layers = nn.ModuleList()
        for _ in range(n_layers):
            split = param_dim // 2
            net = nn.Sequential(
                nn.Linear(split + summary_dim, hidden), nn.SiLU(),
                nn.Linear(hidden, (param_dim - split) * 2),
            )
            self.layers.append(net)
        self.param_dim = param_dim

    def forward(self, z, summary):
        log_det = 0
        split = self.param_dim // 2
        for net in self.layers:
            z1, z2 = z[:, :split], z[:, split:]
            params = net(torch.cat([z1, summary], dim=-1))
            s, t = params.chunk(2, dim=-1)
            s = torch.tanh(s) * 0.5
            z2 = z2 * torch.exp(s) + t
            log_det += s.sum(-1)
            z = torch.cat([z2, z1], dim=-1)
        return z, log_det

    def sample(self, summary, n_samples=100):
        z = torch.randn(n_samples, self.param_dim, device=summary.device)
        s_expanded = summary.unsqueeze(0).expand(n_samples, -1)
        samples, _ = self.forward(z, s_expanded)
        return samples

class JADAI(nn.Module):
    def __init__(self, design_dim, outcome_dim, param_dim):
        super().__init__()
        summary_dim = 64
        self.history = HistoryEncoder(design_dim, outcome_dim, summary_dim=summary_dim)
        self.policy = DesignPolicy(summary_dim, design_dim)
        self.inference = FlowInference(param_dim, summary_dim)

    def training_loss(self, designs_seq, outcomes_seq, true_params):
        total_loss = 0
        batch = true_params.shape[0]
        for t in range(1, designs_seq.shape[1]):
            summary = self.history(designs_seq[:, :t], outcomes_seq[:, :t])
            z = torch.randn(batch, true_params.shape[-1], device=true_params.device)
            samples, log_det = self.inference(z, summary)
            posterior_err = torch.mean((samples - true_params) ** 2, dim=-1)
            total_loss += posterior_err.mean() - 0.01 * log_det.mean()
        return total_loss / designs_seq.shape[1]
