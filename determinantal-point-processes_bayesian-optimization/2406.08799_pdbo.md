# Pareto Front-Diverse Batch Multi-Objective Bayesian Optimization

- **arXiv**: [2406.08799](https://arxiv.org/abs/2406.08799)
- **Authors**: Alaleh Ahmadianshalchi, Syrine Belakaria, Janardhan Rao Doppa
- **Submitted**: 2024-06-13
- **Venue**: AAAI 2024
- **Keywords**: Determinantal Point Processes, bayesian optimization

## Methods

PDBO (Pareto-front Diverse Batch Optimization) addresses two core challenges in multi-objective Bayesian optimization (MOBO): (1) how to automatically select the best acquisition function at each BO iteration, and (2) how to select a diverse batch of inputs considering multiple objectives.

1. **Multi-armed bandit acquisition selection**: PDBO employs a multi-armed bandit (MAB) policy to adaptively select one acquisition function from a library (e.g., EI, UCB, PI) at each iteration, removing the need for manual tuning.

2. **Cheap MOO for candidate generation**: The selected acquisition function is assigned to each expensive objective, and a cheap multi-objective optimization (e.g., NSGA-II) is solved to produce a candidate set of Pareto-optimal inputs.

3. **DPP-based diverse batch selection**: A Determinantal Point Process (DPP) is constructed using the GP surrogate covariance as the similarity kernel. The DPP's repulsive property ensures that the selected batch of inputs is diverse in both the input space and the Pareto front. The L-ensemble DPP kernel is:

   L(x_i, x_j) = q(x_i) * k(x_i, x_j) * q(x_j)

   where q(x) is a quality score (acquisition value) and k(x_i, x_j) is the GP kernel measuring similarity. Sampling from this DPP yields batches that are simultaneously high-quality and diverse.

4. **Surrogate model**: Independent Gaussian Processes model each objective, providing posterior mean and variance for acquisition function computation.

## Conclusion

Experiments on multiple MOO benchmarks (synthetic and real-world) demonstrate that PDBO outperforms prior batch MOBO methods (qEHVI, DGEMO, MESMO, USeMO) in both the quality and diversity of discovered Pareto solutions. The DPP-based batch selection is the key differentiator: it avoids the clustering behavior of naive batch strategies and ensures better coverage of the Pareto front. The MAB-based acquisition selection further improves robustness across different problem landscapes without manual hyperparameter tuning.

## Sequence-Aware Extension

See `sequence_aware_impl.py` for a teaching extension to the setting where experiments are organized into S sequences (recipes, wafers, process stages) and each BO iteration produces a DOE (Design of Experiments) of m_s parameter-sweep points per sequence.

- Intrinsic coregionalization (ICM) multi-task GP per objective:
  `k((s,x),(s',x')) = B[s,s'] · k_rbf(x,x')`, with `B = (1-ρ)·I + ρ·1·1ᵀ`, parameterized by a single shared-variance knob ρ ∈ [0,1).
- Candidate generation and the L-ensemble DPP run per sequence so each batch respects exact per-sequence DOE quotas m_s. Within-sequence diversity comes from the DPP; cross-sequence information transfer comes from B in the surrogate.
- MAB acquisition selection (UCB/EI) and the DPP sampler are unchanged.

ρ=0 recovers independent per-sequence PDBO; ρ→1 approaches a fully pooled surrogate. File is self-contained (no import from `reference_impl.py`), matching repo convention.
