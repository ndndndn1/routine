# Physics-Constrained Fine-Tuning of Flow-Matching Models for Generation and Inverse Problems

- HTML: https://arxiv.org/html/2508.09156v1
- Submitted: 2025-08-05 (rev. 2026-01-27; within routine window 2024-05-23 ~ 2026-05-23)
- Categories: cs.LG, physics.comp-ph
- Keywords matched (≥3): **physics-informed**, **invertible neural networks**, **surrogate modeling**
- Authors: Jan Tauberschmidt, Sophie Fellenz, Sebastian J. Vollmer, Andrew B. Duncan (DFKI, RPTU, Imperial College London)

## Why this paper fits the topic "sequential variation propagation"

Flow-matching 생성 모델은 노이즈에서 솔루션 필드로의 연속 변환을 학습하는데, 물리적 제약 없이 학습하면 PDE를 위반하는 비물리적 해를 생성한다. 이 논문은 **weak-form PDE 잔차를 미분 가능한 후학습(post-training) 절차로 최소화**하여, 학습된 분포를 왜곡하지 않으면서 물리적 일관성을 강제한다. 역문제에서는 **잠재 파라미터 예측기(latent parameter predictor)** 를 증강하여 소스 항, 재료 파라미터, 경계 조건 등 미지 입력을 동시 추정한다. 생성 과정의 각 단계에서 물리 잔차가 전파되어 해 다중성을 물리적으로 유효한 영역으로 제한하는 구조이다.

## Methods

### 1. Flow-Matching Generative Model

연속 normalizing flow로 base distribution → solution field 매핑:

```
dz/dt = v_θ(z, t),   z(0) ~ p_base,   z(1) ≈ p_data
```

- velocity field v_θ를 neural network으로 파라미터화
- ODE 적분으로 샘플 생성 → invertible by construction

### 2. Physics-Constrained Fine-Tuning

사전 학습된 flow model에 물리 제약을 후학습으로 추가:

```
L_physics = ∫_Ω R(u; φ)² dΩ   (weak-form PDE residual)

L_total = L_data + λ · L_physics + L_BC
```

- **Weak-form 잔차**: 시험 함수(test function)와의 내적으로 PDE 잔차 계산
- 경계 조건(Dirichlet/Neumann)도 별도 loss로 강제
- 기존 학습된 분포를 보존하면서 물리적 일관성만 추가

### 3. Latent Parameter Predictor for Inverse Problems

미지의 물리 입력을 추정하는 보조 네트워크:

```
(z(1), observation) → ψ_φ → (source_term, material_params, BC)
```

- 생성 모델과 파라미터 예측기를 **joint optimization**
- 관측 데이터에 부합하면서 PDE를 만족하는 필드와 파라미터를 동시 생성

### 4. 검증

표준 PDE 벤치마크에서 평가:

- Poisson 방정식, 열전도 방정식, 대류-확산 방정식
- 물리 미세 조정 후 **PDE 잔차가 1–2 자릿수 감소**
- 잠재 계수(latent coefficients)의 정확한 복원 확인
- 기존 physics-informed 접근(PINN 등) 대비 **생성 다양성 유지** 장점

## Conclusion

- Flow-matching 모델의 후학습으로 **물리적 일관성을 사후 주입**하는 실용적 파이프라인.
- 기존 학습 분포를 왜곡하지 않으면서 PDE 잔차를 최소화하여, 생성 다양성과 물리적 정확성을 동시 달성.
- 역문제에서 잠재 파라미터 예측기와의 joint optimization이 ill-posed 문제의 해 다중성을 물리적으로 유효한 범위로 제약.
- 범용 프레임워크로서 다양한 PDE 시스템에 적용 가능하며, flow model architecture에 비의존적.
- cs.LG와 physics.comp-ph 양 분야에 걸친 연구로 주제의 학제적 성격을 반영.
