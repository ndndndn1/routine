## Why this paper fits the topic "sequential variation propagation"

물리 실험은 비용이 높고 재현이 어렵기 때문에 *어디에서* 실험할지의 선택이 결정적이다. 컴퓨터 모델(surrogate)로부터 확보한 prior knowledge와 실제 관측의 discrepancy를 Kennedy-O'Hagan(KOH) 프레임워크로 통합 모델링한 뒤, **mutual information(MI) 기반 sequential design**으로 예측 분산을 가장 빠르게 줄이는 실험 지점을 선택한다. 이는 역문제에서 "불확실성이 큰 해 영역"을 순차적으로 좁혀가는 sequential variation propagation의 실험 설계 관점 구현이다.

## Methods

### 1. Kennedy-O'Hagan (KOH) 모델

물리 실험과 컴퓨터 시뮬레이션을 통합하는 표준 프레임워크:

```
y_phys(x) = η(x, θ) + δ(x) + ε
```

- `η(x, θ)`: 컴퓨터 모델 (calibration parameter θ 포함)
- `δ(x)`: model discrepancy (시뮬레이션이 포착 못하는 물리)
- `ε ~ N(0, σ²)`: 관측 노이즈
- 각 항을 coupled GP로 모델링, Bayesian posterior 추론

### 2. Mutual Information (MI) 기반 design criterion

기존 IMSPE(Integrated Mean Squared Prediction Error) 대신 **MI를 acquisition으로 사용**:

```
α_MI(x_new) = I(y_phys(x*); y_new | D)
            = H(y_phys(x*) | D) - H(y_phys(x*) | D ∪ {x_new, y_new})
```

- `x*`: 예측하려는 미래 입력 지점들
- MI는 새 관측이 예측에 가져올 정보 이득(information gain)을 직접 측정
- IMSPE보다 **robust**: 모델 불확실성이 큰 초기 단계에서 특히 유리

### 3. Hybrid criterion

MI에 **local model complexity** 지표를 결합한 hybrid acquisition:

```
α_hybrid(x) = α_MI(x) + λ · complexity(x)
```

local complexity가 높은 영역은 discrepancy δ가 복잡 → 더 많은 관측이 필요 → 추가 가중

### 4. 계산 가속 전략

Fully Bayesian inference의 계산 비용을 줄이는 두 가지 기법:

1. **Gaussian Mixture Compression**: posterior를 GM으로 근사하여 moment 계산 가속
2. **Schur complement + rank-1 update**: 새 관측 추가 시 GP posterior를 O(n²)에 갱신

### 5. 검증

- Synthetic function (known discrepancy) — MI vs IMSPE vs maximin 비교
- Real biochemical case study — sequential (offline) 및 adaptive (online) BED
- MI 기반 설계가 전 조건에서 IMSPE보다 예측 RMSE 낮음

## Conclusion

- MI 기반 sequential design이 **모델 불확실성 높은 초기 단계에서 IMSPE보다 견고한 성능**을 보인다.
- Hybrid criterion은 discrepancy가 공간적으로 불균일한 경우 추가적인 이점을 제공.
- KOH 프레임워크 내에서 물리 시뮬레이션(surrogate)과 실험의 정보를 효율적으로 융합하여, 제한된 실험 예산으로 예측 분산을 최대한 억제.
- 역문제에서 forward surrogate의 discrepancy와 posterior uncertainty를 동시에 줄이는 sequential 전략으로 직접 활용 가능.
