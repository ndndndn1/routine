# Sequential Bayesian Optimal Experimental Design in Infinite Dimensions via Policy Gradient Reinforcement Learning

- **arXiv:** [2601.05868](https://arxiv.org/abs/2601.05868)
- **저자:** Kaichen Shen, Peng Chen
- **발표일:** 2026-01-09
- **키워드:** sequential design of experiments, bayesian adaptive design, surrogate modeling, physics-informed
- **공식 코드:** 없음

## 배경

PDE 기반 역문제에서 무한 차원 확률장 매개변수를 추정하기 위한 순차적 베이지안 최적 실험설계(SBOED)를 다룬다. 기존 SBOED 방법은 유한 차원에 국한되거나, 그리디 1-스텝 근사만 사용하는 한계가 있다. 본 논문은 **다-스텝 최적화** 관점에서 SBOED를 유한 지평 마르코프 결정 과정(MDP)으로 재정식화하고, 정책 경사 강화학습(PGRL)으로 상각화된 설계 정책을 학습한다.

## Methods

1. **이중 차원 축소 (Dual Dimension Reduction)**
   - 매개변수 공간: derivative-informed active subspace 투영으로 주요 방향만 추출
   - 상태 공간: PCA로 관측 데이터를 저차원 표현으로 축소
   - 고차원 함수장을 다루면서도 정책 학습에 필요한 상태-행동 공간을 감당 가능한 크기로 유지

2. **LANO (Latent Attention Neural Operator) 서로게이트**
   - 축소된 잠재 공간에서 매개변수→해 맵과 그 야코비안을 동시에 예측
   - 비용이 큰 PDE 솔버 호출 없이 EIG(기대 정보 이득) 평가 가능
   - Attention 메커니즘으로 입력 함수의 비국소 의존성을 포착

3. **정책 경사 강화학습 (PGRL)**
   - SBOED를 T-스텝 MDP로 모델링: 상태 = 과거 (설계, 관측) 이력, 행동 = 다음 설계
   - 정책 네트워크가 상태를 입력받아 다음 최적 설계를 출력
   - REINFORCE + baseline으로 총 EIG(정보 이득)를 최대화
   - 학습된 정책은 상각화되어 새로운 실험 시나리오에 즉시 적용 가능

4. **EIG 추정**
   - Nested Monte Carlo 대신 Laplace 근사 기반 상·하한으로 빠른 EIG 평가
   - LANO 서로게이트의 야코비안으로 Fisher 정보 행렬 계산

## Conclusion

- PDE 기반 역문제에서 무한 차원 매개변수에 대한 최초의 다-스텝 SBOED 프레임워크 제시
- 이중 차원 축소 + LANO 서로게이트 + PGRL 조합으로 실시간 설계 결정 가능
- 1D/2D Darcy flow, 2D convection-diffusion 문제에서 1-스텝 그리디 설계 대비 유의미한 정보 이득 향상
- 학습된 정책이 다른 참 매개변수에 대해서도 일반화됨을 실험적으로 검증

## 주제 연관성

Many-to-one 순방향 PDE 모델의 역문제에서 관측 설계를 순차적으로 최적화하여 해의 다중성(불확실성)을 효율적으로 축소한다. 서로게이트 + 정보 이론 + RL로 탐색 공간 폭발을 억제하는 전략이 sequential variation propagation의 핵심 과제에 직접 대응한다.
