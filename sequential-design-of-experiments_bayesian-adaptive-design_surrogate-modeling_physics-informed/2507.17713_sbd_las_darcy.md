# Sequential Bayesian Design for Efficient Surrogate Construction in the Inversion of Darcy Flows

- arXiv: [2507.17713](https://arxiv.org/abs/2507.17713)
- HTML: https://arxiv.org/html/2507.17713v1
- Submitted: 2025-07-23 (within routine window 2024-05-23 ~ 2026-05-23)
- Categories: stat.ML, cs.LG
- Keywords matched (≥3): **sequential design of experiments**, **bayesian adaptive design**, **surrogate modeling**, **physics-informed**
- Authors: Hongji Wang, Hongqiao Wang, Jinyong Ying, Qingping Zhou

## Why this paper fits the topic "sequential variation propagation"

Darcy 흐름의 역문제는 전형적인 다대일(many-to-one) 구조이다: 여러 투수계수장이 동일한 관측 압력을 생성할 수 있다. 이 논문은 **순차 베이지안 설계(SBD)** 를 통해 서로게이트가 사후분포(posterior)의 고확률 영역에만 국소적으로 정확하도록 훈련 데이터를 능동적으로 선택한다. 이는 일대다 역문제의 탐색 공간을 likelihood의 고밀도 영역으로 집중시켜 분산을 억제하는 전략으로, sequential variation propagation의 핵심 과제를 직접 다룬다.

## Methods

### 1. Locally Accurate Surrogate (LAS)

전체 파라미터 공간에서 균일하게 정확한 서로게이트 대신, **사후분포의 고확률 영역에만 국소적으로 정확한 서로게이트**를 구축:

```
G_surr(u) ≈ G(u)   for u ∈ supp(π_post)
```

- 조잡한 격자(coarse solver) 출력 + 잔차 네트워크(residual network)로 bias를 보정
- FNO(Fourier Neural Operator), DeepONet 등 데이터 기반 연산자 대리 모델 사용 가능
- 핵심 아이디어: 사후분포 밖의 영역에서는 정확도를 희생하여 **필요 훈련 데이터 수를 대폭 절감**

### 2. Sequential Bayesian Design (SBD)

사후분포의 고확률 영역이 사전에 알려지지 않으므로, **순차적으로 탐색 → 서로게이트 갱신 → 사후분포 재추정**의 루프를 반복:

```
for t = 1, 2, ..., T:
    1. 현재 서로게이트 G_t로 사후분포 π_t 추정 (MCMC)
    2. π_t에서 고확률 샘플 {u_i}를 추출
    3. acquisition function으로 다음 훈련 점 u_{t+1} 선택
    4. 정밀 solver G(u_{t+1}) 평가 후 훈련 집합에 추가
    5. 서로게이트 G_{t+1} 재훈련
```

### 3. Acquisition Function

서로게이트 예측 불확실성과 사후 밀도를 결합한 가중 정보 이득:

```
α(u) = Var_surr(u) · π_t(u | D)
```

- 사후 밀도가 높고 동시에 서로게이트 불확실성이 큰 영역을 우선 탐색
- 불필요한 영역 탐색을 회피하여 계산 예산을 효율적으로 배분

### 4. 검증

- 2D/고차원 Darcy 흐름 역문제에서 전역 서로게이트 대비 **동일 정확도 달성에 필요한 정밀 solver 호출 수를 50–70% 절감**
- SBD-LAS가 기존 균일 설계 및 Latin Hypercube 설계보다 사후분포 추정 정확도(KL divergence) 우수

## Conclusion

- 국소 정확 서로게이트 + 순차 베이지안 설계의 결합은 역문제에서 **탐색 공간을 사후분포의 실질적 지지(support)로 압축**하여 계산 효율을 극대화한다.
- Darcy 흐름뿐 아니라 PDE 기반 역문제 전반에 범용적으로 적용 가능한 프레임워크.
- 서로게이트 선택에 제한이 없어(FNO, DeepONet, GP 등) 확장성이 높다.
- 역문제의 해 다중성(ambiguity)을 다루는 데 있어, 불확실성이 높은 영역만 선별적으로 정밀화하는 것이 전역 정밀화보다 효율적임을 실증.
