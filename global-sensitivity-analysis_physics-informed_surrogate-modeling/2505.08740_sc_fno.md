# Sensitivity-Constrained Fourier Neural Operators for Forward and Inverse Problems in Parametric Differential Equations

- arXiv: [2505.08740](https://arxiv.org/abs/2505.08740)
- Submitted: 2025-05-13 (within routine window 2024-05-09 ~ 2026-05-09)
- Authors: Haoming Ma, Wenzhuo Xu, Christopher McComb, Noelia Grande Gutierrez
- Categories: cs.LG, cs.CE, math.NA
- Keywords matched (>=3): **global sensitivity analysis**, **physics-informed**, **surrogate modeling**

## Why this paper fits the topic "sequential variation propagation"

파라메트릭 PDE에서 입력 파라미터 p의 변동(variation)이 해 u(x;p)에 어떻게 전파되는지를 정량화하는 것이 핵심 문제이다. 본 논문은 Fourier Neural Operator(FNO)의 학습 과정에 **감도 du/dp를 직접 정규화 항으로 통합**하여, many-to-one 순방향 문제에서 파라미터 변동에 대한 해의 민감도를 정확히 포착하고, one-to-many 역방향 문제에서는 감도 정보를 활용해 ill-posedness를 완화한다. 이는 variation propagation 경로를 operator 학습 단계에서 명시적으로 제어하는 접근이다.

## Methods

### 1. Parametric PDE의 Operator Learning 정의

파라미터화된 PDE 시스템에서 입력 함수 a(x; p)로부터 해 u(x; p)로의 매핑을 학습:

```
G†: A → U,   a(x; p) ↦ u(x; p)
```

FNO는 이 매핑을 Fourier 공간에서의 적분 커널로 근사:

```
v_{l+1}(x) = σ(W_l · v_l(x) + K_l(v_l)(x))

K_l(v_l)(x) = F^{-1}[R_l · F[v_l]](x)
```

여기서 `F`는 FFT, `R_l`은 학습 가능한 Fourier 모드 가중치, `σ`는 활성화 함수.

### 2. Sensitivity Field 정의

파라미터 p에 대한 해의 감도(sensitivity)를 다음과 같이 정의:

```
s(x; p) = ∂u(x; p) / ∂p
```

벡터 파라미터의 경우 Jacobian 형태:

```
S(x; p) = [∂u/∂p_1, ∂u/∂p_2, ..., ∂u/∂p_m]
```

이 감도 필드는 유한차분 또는 adjoint method로 ground truth를 생성:

```
s(x; p) ≈ [u(x; p + εe_j) - u(x; p - εe_j)] / (2ε)
```

### 3. Sensitivity-Constrained Loss Function

표준 FNO 데이터 손실에 감도 정합(sensitivity matching) 항을 추가:

```
L_total = L_data + λ · L_sensitivity

L_data = (1/N) Σ_i ||G_θ(a_i) - u_i||²

L_sensitivity = (1/N) Σ_i ||∂G_θ(a_i)/∂p - s_i||²
```

여기서 `∂G_θ/∂p`는 자동 미분(automatic differentiation)으로 계산하고, `s_i`는 수치 시뮬레이션에서 얻은 감도 ground truth이다.

### 4. Global Sensitivity Analysis 연계

학습된 SC-FNO를 이용한 Sobol' 감도 지수 계산:

```
S_j = Var[E[u | p_j]] / Var[u]    (1차 Sobol' 지수)
S_Tj = 1 - Var[E[u | p_{~j}]] / Var[u]    (전체 Sobol' 지수)
```

SC-FNO의 감도 정규화는 이 지수들의 추정 정확도를 향상시킨다. 특히 surrogate 기반 Monte Carlo 추정에서 감도의 정확성이 Sobol' 지수의 편향을 줄인다.

### 5. Inverse Problem에의 적용

역문제에서 관측 u_obs로부터 파라미터 p*를 복원할 때, 감도 정보를 gradient-based 최적화에 활용:

```
p* = argmin_p ||G_θ(a(·; p)) - u_obs||² + R(p)

∇_p L = (∂G_θ/∂p)^T · (G_θ(a) - u_obs) + ∇R(p)
```

SC-FNO는 `∂G_θ/∂p`를 정확히 학습했으므로, 역문제 수렴 속도와 정확도가 향상된다.

### 6. 검증 문제

- 1D Burgers' equation: 점성 계수 ν에 대한 감도
- 2D Darcy flow: 투과도 필드의 파라미터에 대한 감도
- Navier-Stokes: Reynolds 수에 대한 감도
- 각 문제에서 SC-FNO는 표준 FNO 대비 감도 예측 오차 50-80% 감소

## Conclusion

- FNO 학습에 **sensitivity matching regularization**을 도입하여, 해와 감도를 동시에 정확하게 학습하는 SC-FNO 프레임워크를 제안.
- 순방향 문제에서 해의 정확도를 유지하면서 **파라미터 감도의 정확도를 크게 향상** (상대 오차 50-80% 감소).
- **Global sensitivity analysis** (Sobol' 지수)에서 SC-FNO 기반 추정이 표준 FNO 대비 더 정확한 감도 순위를 산출.
- 역문제에서 정확한 gradient 정보 제공으로 **수렴 속도 향상 및 ill-posedness 완화**.
- 감도 ground truth 생성에 추가 시뮬레이션이 필요하지만, 유한차분 근사로 효율적으로 생성 가능.
