# Physics-Informed Deep Neural Network Design of Reactively Loaded Metasurfaces

- **arXiv**: [2603.15430](https://arxiv.org/abs/2603.15430)
- **Authors**: Malik Almunif, John Le, Anthony Grbic
- **Submitted**: 2026-03 (University of Michigan)
- **Keywords**: physics-informed, Tandem Structure, surrogate modeling

## Methods

1. **Tandem DNN architecture**: An inverse network maps target far-field radiation patterns to reactive load distributions. The inverse DNN is coupled to a physics-based forward solver during training (tandem configuration).

2. **Physics-based microwave network forward solver**: A fast analytical model based on impedance matrix and active element patterns replaces iterative full-wave EM simulation. Only a single full-wave simulation is needed pre-training to extract the impedance matrix.

3. **Cosine-similarity loss**: Training is guided by comparing the forward solver's predicted radiation pattern with the target pattern via cosine similarity, ensuring the inverse network learns physically consistent mappings.

4. **Aperture-coupled metasurface unit cells**: The design domain consists of unit cells loaded with tuneable reactances; the network predicts the reactance distribution achieving a desired beam shape or direction.

5. **Design validation**: Shaped and steered far-field patterns are synthesised across multiple examples, demonstrating the tandem physics-informed DNN's practical accuracy.

## Conclusion

The tandem physics-informed DNN architecture significantly reduces computational cost for metasurface inverse design by embedding a fast physics-based surrogate into the training loop, eliminating the need for iterative full-wave simulation. The approach accurately synthesises shaped and steered far-field radiation patterns, demonstrating the value of integrating domain-specific physical knowledge into inverse design neural networks.
