# Physics-Informed Deep Neural Network Design of Reactively Loaded Metasurfaces

- **arXiv:** [2603.15430](https://arxiv.org/abs/2603.15430)
- **Authors:** Malik Almunif, John Le, Anthony Grbic (University of Michigan)
- **Submitted:** 2026-03-16
- **Keywords:** physics-informed, Tandem Structure, surrogate modeling

## Methods

1. **Tandem DNN Architecture**
   - 두 단계로 구성: (a) Inverse DNN — 목표 복사 패턴(far-field radiation pattern)을 반응성 부하(reactive load) 분포로 매핑, (b) Physics-based Forward Solver — 예측된 부하 분포로부터 실제 복사 패턴을 계산
   - Inverse DNN이 one-to-many 매핑을 학습하고, Forward Solver가 물리적 일관성을 보장하는 tandem 구조

2. **Physics-Based Microwave Network Forward Solver**
   - 메타표면의 단위 셀(unit cell)을 마이크로웨이브 네트워크 이론으로 모델링
   - 전자기 응답의 빠른 평가를 가능하게 하여, 전파 시뮬레이션(full-wave simulation) 대비 훈련 비용을 대폭 절감
   - 물리 기반이므로 DNN 예측에 대한 즉각적 물리 검증 역할

3. **Cosine-Similarity Loss**
   - 목표 복사 패턴과 forward solver가 계산한 패턴 간의 코사인 유사도를 손실함수로 사용
   - 패턴의 전체적 형상(shape) 일치에 집중하여, 절대 진폭 오차보다 방향성 일치를 우선

4. **Design Examples**
   - Shaped beam 패턴, steered beam 패턴 등 다양한 복사 패턴 합성을 시연
   - Inverse DNN이 예측한 반응성 부하 분포가 물리적으로 실현 가능한 범위 내에 있음을 검증

## Conclusion

- Tandem 구조에서 물리 기반 forward solver가 DNN의 역매핑 오류를 즉각 보정하여 물리적 타당성을 보장
- Full-wave simulation 없이 마이크로웨이브 네트워크 모델로 훈련하여 효율적
- One-to-many 역매핑 문제에서 물리 solver가 해 공간을 물리적으로 유효한 영역으로 제한
- 메타표면 역설계에 Tandem 구조의 효과를 입증하며, 다른 전자기 역설계에도 적용 가능
