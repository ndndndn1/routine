## Why this paper fits the topic "sequential variation propagation"

포토닉 역설계에서 순방향 시뮬레이션은 many-to-one이다: 다양한 구조가 유사한 광학 응답을 생성한다. AdjointDiffusion은 **adjoint sensitivity 그래디언트를 diffusion 모델의 샘플링 과정에 통합**하여, 생성 과정 각 단계에서 물리 법칙을 반영한 감도 기반 안내를 수행한다. 또한 **제조 공차(fabrication constraints)** 를 명시적으로 포함하여, 공정 변동에 robust한 설계만 생성되도록 탐색 공간을 제약한다. 이는 순차적으로 물리 감도 정보를 전파하며 변동에 강건한 해를 생성하는 접근이다.

## Methods

### 1. Conditional Diffusion Model

역설계 구조를 생성하는 조건부 확산 모델:

```
p_θ(x₀ | c) where c = target optical response
```

- 노이즈에서 디바이스 구조로의 역확산(reverse diffusion) 과정
- 목표 광학 응답 c로 조건화하여 원하는 성능의 구조 생성

### 2. Adjoint Sensitivity Guidance

확산 모델의 각 역확산 단계에 adjoint sensitivity 그래디언트를 주입:

```
x_{t-1} = denoise(x_t) + η · ∇_x J(x_t)

J(x) = FoM(FDTD(x))   (adjoint method으로 ∇J 계산)
```

- Adjoint method: FDTD 순방향 + 역방향 1회로 전체 그래디언트 계산
- **~200회의 시뮬레이션**으로 ~10⁵–10⁶회가 필요한 순수 DL 접근 대체
- 매 단계마다 물리적으로 최적화된 방향으로 생성 과정을 유도

### 3. Fabrication-aware Constraints

제조 공차를 설계 과정에 반영:

```
x_filtered = MorphologicalFilter(x, min_feature_size)
```

- 최소 피처 크기(minimum feature size) 제약
- 곡률 제한, 연결성 보장 등 제조 가능성 조건
- 공정 변동에 민감한 미세 구조를 사전 배제

### 4. 검증

두 가지 표준 포토닉 설계 문제에서 평가:

- **Bent waveguide**: 곡선 도파관 설계
- **CMOS image sensor color router**: 컬러 라우터 설계
- 기존 SOTA 비선형 최적화기 대비 **일관된 성능 우위**
- 순수 DL 대비 **시뮬레이션 횟수 3 자릿수 이상 절감**(~200 vs ~10⁵)
- 제조 공차 반영 시에도 성능 저하 최소화

## Conclusion

- Adjoint sensitivity + diffusion model의 결합이 **물리 기반 안내와 생성 모델의 다양성을 동시에 달성**.
- 제조 공차를 명시적으로 포함하여 공정 변동에 robust한 설계를 생성하며, 실제 제작 가능한 구조만 탐색.
- 시뮬레이션 효율이 극적으로 향상(~200회)되어 실용적인 역설계 파이프라인 실현.
- 확산 모델의 순차적 역확산 과정이 sensitivity 정보를 단계별로 전파(propagate)하여, 탐색 공간을 물리적으로 유효하고 제조 가능한 영역으로 점진적으로 수축.
