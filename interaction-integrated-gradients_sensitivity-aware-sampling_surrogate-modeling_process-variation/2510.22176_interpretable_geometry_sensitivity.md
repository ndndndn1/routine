## Why this paper fits the topic "sequential variation propagation"

역문제(inverse design)에서 하나의 목표 스펙트럼에 여러 기하학적 해가 대응하는 one-to-many 다중성 문제를 다룬다. 특히 제조 공정 변동(fabrication variability)이 디바이��� 성능에 미치는 영향을 Integrated Gradients 기반 attribution으로 해석 가능하게 분석하여, 공정 변��에 강건한 역설계 후보를 선별하는 sensitivity-aware 접근법을 제시한다. Convolutional surrogate 모델이 비용 높은 전자기 시뮬레이션을 대체하며, geometry sensitivity map이 어떤 구조 파라미터가 성능 변동에 가장 민감한지 pixel 수준에서 시각화한다.

## Methods

### 1. Convolutional Surrogate Model

- 2D geometry image → figure-of-merit (FoM) 매핑을 CNN surrogate로 학습
- FDTD 시뮬레이션 대비 수천 배 빠른 추론 → gradient 기반 attribution 가능

### 2. Integrated Gradients Attribution

- Integrated Gradients (IG)를 사용해 각 geometry pixel이 FoM에 기여하는 정도를 계산
- Attribution `A_i = (x_i - x_i') × ∫₀¹ ∂F/∂x_i(x' + α(x - x')) dα`
- Baseline `x'`은 uniform slab (featureless geometry)
- 결과: pixel 수준 geometry sensitivity map → 어느 영역이 공정 변동에 취약한지 시각화

### 3. Fabrication Variability Analysis (Process Variation)

- 리소그래피 해상도 한계를 반영한 perturbation 모델: edge erosion/dilation ±δ
- Sensitivity map × perturbation mask → 예상 FoM 변동 추정
- 높은 sensitivity 영역이 좁은 feature에 집중됨 → 공정 변동에 가장 취약한 구조 영역 식별

### 4. Sensitivity-Aware Inverse Design Selection

- 역설계 후보군 중 FoM은 비슷하지만 sensitivity map의 총 변동(total variation)이 작은 설계를 선택
- 이를 통해 one-to-many 역문제의 해 다중성에서 공정 변동에 가장 강건한 해를 선별

### 5. Validation

- Silicon photonic inverse-designed devices (mode converters, wavelength demultiplexers)
- IG attribution과 FDTD 직접 perturbation 결과 간 높은 상관(Pearson > 0.9)
- Sensitivity-aware selection이 random selection 대비 공정 변동 하에서 FoM 분산을 40-60% 감소

## Conclusion

- Integrated Gradients 기반 geometry sensitivity가 역설계 photonic 디바이스의 **공정 변동 취약점**을 해석 가능하게 식별한다.
- CNN surrogate의 differentiability를 활용하여 한 번의 forward + backward pass로 전체 geometry에 대한 sensitivity map을 생성, FDTD perturbation 대비 O(10³) 배 빠르다.
- One-to-many 역문제에서 다수의 해 중 **공정 변동에 강건한 해를 선별**하는 실용적 프레임워크를 제공.
