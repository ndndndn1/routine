# Informed Initialization for Bayesian Optimization and Active Learning (HIPE)

- **arXiv**: [2510.23681](https://arxiv.org/abs/2510.23681)
- **Authors**: Carl Hvarfner, David Eriksson, Eytan Bakshy, Max Balandat
- **Submitted**: 2025-10-27 (NeurIPS 2025)
- **Keywords**: active learning, bayesian optimization, surrogate modeling, bayesian adaptive design, sequential design of experiments

## Methods

HIPE addresses the often-overlooked initialization phase of Bayesian Optimization and Active Learning, proposing an acquisition strategy that explicitly balances predictive uncertainty reduction with GP hyperparameter learning.

1. **Initialization as Sequential Design**: Rather than using random, quasi-random (Sobol), or space-filling (Latin Hypercube) initializations, HIPE treats the initialization phase as a sequential experimental design problem. Each initialization point is chosen to maximize an information-theoretic criterion.

2. **Hyperparameter-Informed Predictive Exploration (HIPE)**: The acquisition function jointly optimizes for (a) reducing the GP surrogate's predictive uncertainty and (b) improving the quality of the GP's hyperparameter estimates. The key insight is that poor hyperparameter estimates during initialization propagate to poor acquisition function evaluations during the main optimization loop.

3. **Closed-Form Expression**: For GPs with standard kernels, the HIPE acquisition function admits a closed-form expression, avoiding expensive Monte Carlo estimation. This makes it practical even for large-batch initialization where computational overhead must be minimized.

4. **Large-Batch Few-Shot Settings**: HIPE is particularly effective when the total evaluation budget is small relative to the problem dimension. In these settings, the initialization phase constitutes a large fraction of the total budget, so its quality has outsized impact on final performance.

5. **Dual Application to BO and AL**: The same HIPE criterion applies to both Bayesian Optimization (where the goal is finding the optimum) and Active Learning (where the goal is accurate global prediction). The hyperparameter-aware component is equally valuable in both settings.

## Conclusion

HIPE demonstrates that informed initialization can significantly improve the performance of both Bayesian Optimization and Active Learning, particularly in few-shot settings. The acquisition function's dual focus on predictive uncertainty and hyperparameter quality provides better surrogate models earlier in the optimization process, leading to better acquisition function evaluations and ultimately better final solutions. Published at NeurIPS 2025, the work establishes initialization as a first-class design decision in surrogate-based optimization, rather than a perfunctory step before "real" optimization begins.

```python
import numpy as np
from sklearn.gaussian_process import GaussianProcessRegressor
from sklearn.gaussian_process.kernels import Matern, ConstantKernel

class HIPE:
    def __init__(self, bounds, kernel=None):
        self.bounds = np.array(bounds)
        self.dim = len(bounds)
        if kernel is None:
            kernel = ConstantKernel() * Matern(nu=2.5)
        self.gp = GaussianProcessRegressor(
            kernel=kernel, n_restarts_optimizer=10, normalize_y=True
        )
        self.X = []
        self.Y = []

    def _predictive_uncertainty(self, candidates):
        if len(self.X) < 2:
            return np.ones(len(candidates))
        _, std = self.gp.predict(candidates, return_std=True)
        return std

    def _hyperparameter_info(self, candidates):
        if len(self.X) < 2:
            return np.ones(len(candidates))
        X_arr = np.array(self.X)
        kernel = self.gp.kernel_
        lengthscales = np.exp(kernel.get_params().get('k2__length_scale', 1.0))
        if np.isscalar(lengthscales):
            lengthscales = np.full(self.dim, lengthscales)
        info_scores = np.zeros(len(candidates))
        for i, c in enumerate(candidates):
            dists = np.abs(X_arr - c) / lengthscales
            min_dist = np.min(np.max(dists, axis=1))
            info_scores[i] = min_dist
        return info_scores

    def acquisition(self, candidates, alpha=0.5):
        pred_unc = self._predictive_uncertainty(candidates)
        hyper_info = self._hyperparameter_info(candidates)
        pred_unc = pred_unc / (pred_unc.max() + 1e-8)
        hyper_info = hyper_info / (hyper_info.max() + 1e-8)
        return (1 - alpha) * pred_unc + alpha * hyper_info

    def select_next(self, oracle_fn, n_candidates=5000):
        candidates = np.random.uniform(
            self.bounds[:, 0], self.bounds[:, 1],
            size=(n_candidates, self.dim)
        )
        scores = self.acquisition(candidates)
        best_idx = np.argmax(scores)
        x_new = candidates[best_idx]
        y_new = oracle_fn(x_new)
        self.X.append(x_new)
        self.Y.append(y_new)
        if len(self.X) >= 2:
            self.gp.fit(np.array(self.X), np.array(self.Y))
        return x_new, y_new

    def initialize(self, oracle_fn, n_init=10):
        for _ in range(n_init):
            self.select_next(oracle_fn)
        return np.array(self.X), np.array(self.Y)
```
