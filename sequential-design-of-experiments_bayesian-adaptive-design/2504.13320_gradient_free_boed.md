## Why this paper fits the topic "sequential variation propagation"

Bayesian Optimal Experimental Design (BOED)에서 Expected Information Gain (EIG)을 최대화하는 것은 곧 *관측을 통해 posterior 분산을 가장 빠르게 줄이는 실험 지점을 선택*하는 것이다. 이 논문은 PDE-constrained inverse problem에서 gradient가 없는 상황에서도 **ensemble 기반 입자 시스템(EKI + ALDI)**으로 sequential design을 수행한다. 역문제의 one-to-many ambiguity를 EIG로 직접 측정하고, 각 실험 단계에서 이를 최대로 줄이는 전략은 sequential variation propagation의 정보이론적 구현이다.

## Methods

### 1. BOED 문제 정의

Sequential setting에서 각 단계 t마다:
```
ξ_t* = argmax_ξ  EIG(ξ; D_{1:t-1})
     = argmax_ξ  E_y[KL(p(θ|y, ξ, D) || p(θ|D))]
```

EIG는 이중 기댓값(nested expectation)을 포함하여 계산이 어렵다.

### 2. Variational bounds on EIG

계산 가능한 상한/하한을 제공:

- **Variational Gaussian approximation**: posterior를 `N(μ_θ, Σ_θ)`로 근사
  ```
  EIG ≈ H[N(μ_prior, Σ_prior)] - E_y[H[N(μ_post(y), Σ_post(y))]]
  ```
- **Parametrized Laplace approximation**: MAP 주변에서 Hessian 기반 2차 근사

### 3. Gradient-free 최적화: Ensemble Kalman Inversion (EKI)

Design 변수 ξ를 최적화하기 위해 **EKI**를 사용:
- Gradient 불필요 — ensemble의 경험적 공분산으로 탐색 방향 결정
- Forward model의 adjoint 계산이 필요 없어 PDE solver를 블랙박스로 활용 가능

```
ξ_j^{n+1} = ξ_j^n + C^n_ξG (C^n_GG + Σ_noise)^{-1} (EIG_target - EIG(ξ_j^n))
```

### 4. Posterior sampling: Affine-Invariant Langevin Dynamics (ALDI)

EIG 계산에 필요한 posterior sampling도 gradient-free:
- Ensemble이 상호작용하며 posterior를 탐색
- Affine invariance로 ill-conditioned posterior에서도 안정적

### 5. 전체 sequential loop

```
for t = 1, ..., T:
    1. ALDI: posterior p(θ | D_{1:t-1}) 샘플링
    2. EKI: EIG를 최대화하는 ξ_t 탐색
    3. 실험 수행: y_t = G(θ_true, ξ_t) + ε
    4. D_{1:t} = D_{1:t-1} ∪ {(ξ_t, y_t)}
```

### 6. 검증

- Linear Gaussian model (해석해 존재 — 정확도 검증)
- Nonlinear ODE model
- PDE-based inference (Darcy flow) — 고차원 설계 공간에서도 작동

## Conclusion

- EKI + ALDI 조합으로 **gradient 없이도 sequential BOED를 수행** 가능함을 보였다.
- Variational Gaussian / Laplace 근사가 EIG의 실용적 상한/하한을 제공, 계산 비용을 크게 줄임.
- PDE-constrained inverse problem에서 adjoint 없이도 정보이론적으로 최적의 실험을 순차적으로 설계 가능.
- 역문제에서 탐색 공간의 불확실성을 EIG로 직접 정량화하고 각 단계에서 최대로 줄이는 전략은, variation propagation의 관점에서 가장 효율적인 분산 축소 경로를 탐색하는 것과 동치.
