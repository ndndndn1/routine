# Interpretable Geometry Sensitivity for Inverse Design of Integrated Photonics

- **arXiv**: https://arxiv.org/abs/2510.22176
- **Authors**: (Photonics inverse design group, details in paper)
- **Published**: 2025-10 (updated 2026-02)
- **Categories**: physics.optics, cs.LG
- **Keywords**: sensitivity-aware sampling, surrogate modeling, Interaction-Integrated Gradients (Integrated Gradients variant)

## Methods

본 논문은 역설계된 자유형(free-form) 포토닉 소자에 대해 Integrated Gradients(IG)를 활용하여 pixel-level 기하학적 민감도 맵을 생성하고, 이를 공정 변동 허용 분석 및 제조성 향상에 활용한다.

핵심 구성:
1. **Convolutional Surrogate Model**: binary mask(설계 패턴) → figures of merit(FoM, 예: 삽입 손실, 크로스토크)를 예측하는 경량 CNN 서로게이트. Wavelength-division demultiplexers (WDM, 1310/1550 nm) 대상.
2. **Integrated Gradients (IG) Attribution**: 서로게이트 모델에 IG를 적용하여 각 pixel이 FoM에 기여하는 정도를 정량화.
   - Baseline: 균일 매질(reference)
   - Path integral: baseline → actual design까지 선형 보간 경로를 따라 기울기 적분
   - 결과: 전자기적으로 중요한 하위구조(substructure)에 높은 attribution 집중
3. **Sensitivity-Aware Perturbation Testing**: 고감도 영역과 저감도 영역에 동일 면적의 기하학적 변형을 가하여 성능 변화 비교. 고감도 영역 변형 시 최대 11배 높은 초과 삽입 손실(excess insertion loss) 발생.
4. **실험적 검증**: 시뮬레이션 기반 sensitivity map과 실제 제작 소자의 측정 결과가 일치함을 확인. 학습된 민감도 맵이 실제 간섭 및 제조 관련 물리를 반영.

역설계 다중성 억제 관련:
- 민감도 맵을 통해 설계 공간에서 "중요한 영역"과 "무관한 영역"을 구분 → 탐색 공간의 효과적 차원 축소.
- 공정 변동에 민감한 구조를 사전에 식별하여 제조 로버스트 설계 유도.
- Tolerance-aware constraint allocation: 고민감 영역에 더 엄격한 공차, 저민감 영역에 완화된 공차 적용.

## Conclusion

- Integrated Gradients 기반 attribution이 역설계된 포토닉 소자의 물리적으로 의미 있는 민감도 정보를 포착함을 실증.
- 고민감 영역 perturbation 시 저민감 영역 대비 최대 11x 높은 성능 저하 확인.
- 시뮬레이션-제조 간 일관성 검증: 학습된 sensitivity map이 실제 제조 물리를 반영.
- 실용적 응용: tolerance-aware design, targeted metrology, manufacturability-informed design.
- 범용적 프레임워크: CNN 서로게이트 + IG 조합은 다양한 역설계 도메인에 적용 가능.
- 한계: 2D binary mask에 한정. 연속 두께 변화나 3D 구조로의 확장 필요.

## Code

공식 코드 미공개. 아래는 CNN 서로게이트 + Integrated Gradients 기반 sensitivity analysis 재현 구현.

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
import numpy as np


class PhotonicSurrogate(nn.Module):
    """Lightweight CNN surrogate for photonic device FoM prediction."""
    def __init__(self, grid_size=64, n_fom=4):
        super().__init__()
        self.conv = nn.Sequential(
            nn.Conv2d(1, 32, 3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(2),
            nn.Conv2d(32, 64, 3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(2),
            nn.Conv2d(64, 128, 3, padding=1),
            nn.ReLU(),
            nn.AdaptiveAvgPool2d(4),
        )
        self.fc = nn.Sequential(
            nn.Linear(128 * 4 * 4, 256),
            nn.ReLU(),
            nn.Linear(256, n_fom),
        )

    def forward(self, mask):
        if mask.dim() == 3:
            mask = mask.unsqueeze(1)
        h = self.conv(mask)
        h = h.flatten(1)
        return self.fc(h)


def integrated_gradients(model, input_mask, target_fom_idx=0, baseline=None, n_steps=100):
    """
    Compute Integrated Gradients attribution for a photonic design mask.

    Args:
        model: trained surrogate CNN
        input_mask: binary design mask (1, H, W)
        target_fom_idx: index of figure-of-merit to attribute
        baseline: reference input (default: uniform medium, all zeros)
        n_steps: number of interpolation steps

    Returns:
        attribution_map: pixel-level sensitivity (H, W)
    """
    if baseline is None:
        baseline = torch.zeros_like(input_mask)

    input_mask = input_mask.clone().detach()
    baseline = baseline.clone().detach()

    # Linear interpolation path
    alphas = torch.linspace(0, 1, n_steps + 1, device=input_mask.device)
    scaled_inputs = torch.stack([
        baseline + alpha * (input_mask - baseline) for alpha in alphas
    ])  # (n_steps+1, 1, H, W)

    scaled_inputs.requires_grad_(True)
    outputs = model(scaled_inputs)
    target_output = outputs[:, target_fom_idx]

    # Compute gradients
    grads = torch.autograd.grad(
        outputs=target_output.sum(),
        inputs=scaled_inputs,
        create_graph=False,
    )[0]

    # Riemann sum approximation of path integral
    avg_grads = (grads[:-1] + grads[1:]).mean(dim=0) / 2
    attribution = (input_mask - baseline) * avg_grads.squeeze(0)

    return attribution.squeeze(0)


def sensitivity_map(model, design_mask, n_fom=4, n_steps=100):
    """Compute aggregated sensitivity map across all FoMs."""
    total_attribution = torch.zeros_like(design_mask.squeeze())
    for fom_idx in range(n_fom):
        attr = integrated_gradients(model, design_mask, target_fom_idx=fom_idx, n_steps=n_steps)
        total_attribution += attr.abs()
    return total_attribution / n_fom


def perturbation_test(model, design_mask, sensitivity, n_tests=50, patch_size=3):
    """
    Compare FoM degradation between perturbations in high vs low sensitivity regions.
    Returns ratio of degradation (high_sens / low_sens).
    """
    flat_sens = sensitivity.flatten()
    n_pixels = flat_sens.numel()

    # Get high and low sensitivity pixel indices
    sorted_idx = flat_sens.argsort()
    low_sens_idx = sorted_idx[:n_pixels // 4]
    high_sens_idx = sorted_idx[3 * n_pixels // 4:]

    # Original prediction
    with torch.no_grad():
        original_fom = model(design_mask.unsqueeze(0)).squeeze()

    high_sens_losses = []
    low_sens_losses = []

    h, w = design_mask.shape[-2:]
    for _ in range(n_tests):
        # Perturb high sensitivity region
        mask_h = design_mask.clone()
        idx = high_sens_idx[torch.randint(len(high_sens_idx), (1,))].item()
        row, col = idx // w, idx % w
        r1, r2 = max(0, row - patch_size // 2), min(h, row + patch_size // 2 + 1)
        c1, c2 = max(0, col - patch_size // 2), min(w, col + patch_size // 2 + 1)
        mask_h[..., r1:r2, c1:c2] = 1.0 - mask_h[..., r1:r2, c1:c2]
        with torch.no_grad():
            fom_h = model(mask_h.unsqueeze(0)).squeeze()
        high_sens_losses.append((original_fom - fom_h).abs().mean().item())

        # Perturb low sensitivity region
        mask_l = design_mask.clone()
        idx = low_sens_idx[torch.randint(len(low_sens_idx), (1,))].item()
        row, col = idx // w, idx % w
        r1, r2 = max(0, row - patch_size // 2), min(h, row + patch_size // 2 + 1)
        c1, c2 = max(0, col - patch_size // 2), min(w, col + patch_size // 2 + 1)
        mask_l[..., r1:r2, c1:c2] = 1.0 - mask_l[..., r1:r2, c1:c2]
        with torch.no_grad():
            fom_l = model(mask_l.unsqueeze(0)).squeeze()
        low_sens_losses.append((original_fom - fom_l).abs().mean().item())

    ratio = np.mean(high_sens_losses) / (np.mean(low_sens_losses) + 1e-8)
    return {
        'high_sens_degradation': np.mean(high_sens_losses),
        'low_sens_degradation': np.mean(low_sens_losses),
        'sensitivity_ratio': ratio,  # expected ~11x per paper
    }


def tolerance_aware_design(sensitivity, strict_tolerance=0.01, relaxed_tolerance=0.1, threshold_percentile=75):
    """
    Assign manufacturing tolerances based on sensitivity map.
    High-sensitivity regions get strict tolerance; low-sensitivity get relaxed.
    """
    threshold = np.percentile(sensitivity.numpy(), threshold_percentile)
    tolerance_map = torch.where(
        sensitivity > threshold,
        torch.full_like(sensitivity, strict_tolerance),
        torch.full_like(sensitivity, relaxed_tolerance),
    )
    return tolerance_map
```
