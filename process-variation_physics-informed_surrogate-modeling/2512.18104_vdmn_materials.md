# Microstructure-based Variational Neural Networks for Robust Uncertainty Quantification in Materials Digital Twins

- arXiv: [2512.18104](https://arxiv.org/abs/2512.18104)
- Submitted: 2024-12-24 (within routine window 2024-05-09 ~ 2026-05-09)
- Authors: Yonglin Chen, Zhengtao Gan, Zheng Liu, Zeliang Liu
- Categories: cs.CE, cs.LG, cond-mat.mtrl-sci
- Keywords matched (>=3): **physics-informed**, **surrogate modeling**, **process variation**

## Why this paper fits the topic "sequential variation propagation"

복합재료의 미세구조(microstructure)는 제조 공정의 변동(process variation)으로 인해 확률적으로 분포하며, 이 미세구조 변동이 거시적 역학 응답으로 전파(propagation)되는 과정이 핵심 문제이다. 본 논문의 Variational Deep Material Network(VDMN)은 미세구조의 확률적 변동을 잠재 변수로 인코딩하고, 이를 계층적 물질 모델을 통해 기계적 응답까지 순차적으로 전파시켜 불확실성을 정량화한다. 역문제(inverse)에서는 관측된 거시 응답으로부터 미세구조 파라미터를 추론하는 one-to-many 문제의 모호성을 변분 사후분포(variational posterior)로 처리하여, 공정 변동에 의한 분산을 체계적으로 제어한다.

## Methods

### 1. Deep Material Network (DMN) 기본 구조

DMN은 복합재료의 미세구조-역학 관계를 계층적 이진 트리(binary tree)로 모델링한다. 각 노드는 두 재료 상(phase)의 선형 혼합을 나타내며, 리프(leaf) 노드에서 루트(root)로 상향 균질화(homogenization)를 수행:

```
Level L (leaves):  C_i^L = C_phase(material_i)    (구성 상의 강성 텐서)

Level l -> l-1:    C_j^{l-1} = Homogenize(C_{2j}^l, C_{2j+1}^l, w_j, theta_j)

Level 0 (root):    C_eff = C^0    (유효 거시 강성)
```

균질화 함수는 Voigt-Reuss 경계 혼합 또는 Hashin-Shtrikman 경계를 따르며, 학습 가능한 파라미터는 각 노드의 체적 분율 `w_j`와 회전각 `theta_j`이다.

### 2. Variational Encoding of Microstructure Uncertainty

VDMN은 DMN의 결정론적 파라미터를 확률 변수로 확장한다. 미세구조 변동을 잠재 변수 z로 인코딩:

```
z ~ q_phi(z | microstructure_image)    (인코더: 변분 사후분포)

[w, theta] = g_psi(z)                  (디코더: 잠재 변수 -> DMN 파라미터)
```

인코더는 미세구조 이미지를 입력받아 잠재 분포를 출력하는 CNN이며, 디코더는 잠재 변수로부터 DMN의 체적 분율과 회전각을 복원한다.

### 3. Evidence Lower Bound (ELBO) 학습

학습 목적함수는 변분 하한(ELBO)을 최대화:

```
ELBO = E_{z ~ q_phi}[log p(sigma_obs | z, epsilon)] - beta * KL[q_phi(z|X) || p(z)]
```

여기서:
- `sigma_obs`: 관측된 응력-변형 응답
- `epsilon`: 부과된 변형
- `p(sigma_obs | z, epsilon)`: DMN forward를 통해 z에서 예측된 응력의 우도
- `KL[...]`: 잠재 분포와 사전분포 간의 KL 발산 (정규화 항)
- `beta`: KL 가중치 (beta-VAE 스타일)

### 4. Forward Uncertainty Propagation (순방향)

미세구조 변동으로 인한 거시 응답의 불확실성을 Monte Carlo로 전파:

```
For k = 1, ..., K:
    z_k ~ q_phi(z | X_micro)
    [w_k, theta_k] = g_psi(z_k)
    sigma_k = DMN_forward(w_k, theta_k, epsilon)

sigma_mean = (1/K) * sum(sigma_k)
sigma_var  = (1/K) * sum((sigma_k - sigma_mean)^2)
```

이를 통해 공정 변동이 유발하는 응력 응답의 **평균과 신뢰구간**을 정량화한다.

### 5. Inverse Problem: 미세구조 추론

관측된 거시 응답 `sigma_obs`로부터 미세구조 파라미터를 역추론:

```
p(z | sigma_obs) ∝ p(sigma_obs | z) * p(z)
```

VDMN은 학습된 생성 모델을 통해 다수의 잠재 샘플 `{z_k}`를 생성하고, 각각을 DMN forward로 평가하여 관측 응답에 부합하는 미세구조 후보군을 산출한다. 이는 one-to-many 역문제의 다중 해를 확률 분포로 자연스럽게 표현한다.

### 6. 검증 문제

- 2상(two-phase) 복합재: 섬유 강화 폴리머에서 섬유 체적 분율과 배향의 변동
- 3상(three-phase) 복합재: 입자, 매트릭스, 공극이 있는 세라믹 복합재
- FE homogenization 대비 VDMN의 불확실성 예측 정확도 검증
- 역문제: 응력-변형 곡선으로부터 미세구조 체적 분율 추론

## Conclusion

- DMN 기반의 **물리 정보 계층 구조**에 변분 추론을 결합하여, 미세구조 불확실성을 거시 역학 응답까지 효율적으로 전파하는 VDMN 프레임워크를 제안.
- Forward problem에서 Monte Carlo 기반 불확실성 전파가 FE 균질화 결과와 높은 일치도를 보이면서도 **3-4 orders of magnitude 빠른 추론** 가능.
- Inverse problem에서 변분 사후분포를 통해 **다중 해(non-unique solutions)를 확률적으로 표현**, 공정 변동으로 인한 모호성을 정량화.
- 제조 공정의 디지털 트윈(Digital Twin) 구축에서 **미세구조 변동 -> 성능 변동** 경로를 실시간으로 예측하고 제어하는 기반 기술을 제공.
- beta-VAE 가중치 조절을 통해 재구성 정확도와 잠재 공간 정규화 사이의 trade-off를 제어 가능.
