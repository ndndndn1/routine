## Why this paper fits the topic "sequential variation propagation"

순방향 문제(many-to-one)에서 파라미터 x가 관측 y로 매핑될 때 정보 손실이 발생하며, 역방향(one-to-many)에서는 하나의 y에 대해 다수의 x 후보가 존재하는 모호성(ambiguity)이 핵심 과제이다. 본 논문은 상삼각(upper) 맵과 하삼각(lower) 맵을 합성하여 하나의 가역(invertible) 생성 모델을 구축함으로써, 순방향에서는 likelihood p(y|x) 샘플링, 역방향에서는 posterior p(x|y) 샘플링을 동일한 맵으로 수행할 수 있게 한다. 이는 역문제의 다중해 분산을 Bayesian posterior로 정량화하고 제어하는 직접적인 프레임워크를 제공한다.

## Methods

### 1. Bayesian Framework for Forward/Inverse Problems

Forward problem: given parameter `x`, observe `y ~ p(y|x)` (likelihood).
Inverse problem: given observation `y`, infer `x ~ p(x|y)` (posterior).

Bayes' theorem connects the two:

```
p(x|y) = p(y|x) p(x) / p(y)
```

The goal is to learn a single invertible map that can sample from both `p(y|x)` and `p(x|y)`.

### 2. Triangular Maps for Conditional Sampling

A **lower triangular map** `T_L: (x, z) -> (x, y)` is defined as:

```
T_L(x, z) = (x, f(x, z))
```

where `f(x, .)` is invertible for each fixed `x`. This map transforms a reference variable `z ~ p_z(z)` (e.g., standard Gaussian) into the observation `y`, conditioned on `x`. Thus it generates samples from the likelihood `p(y|x)`.

An **upper triangular map** `T_U: (z', y) -> (x, y)` is defined as:

```
T_U(z', y) = (g(z', y), y)
```

where `g(., y)` is invertible for each fixed `y`. This map transforms a reference variable `z' ~ p_{z'}(z')` into the parameter `x`, conditioned on `y`. Thus it generates samples from the posterior `p(x|y)`.

### 3. Composition into an Invertible Generative Model

The key insight is to compose both maps into a single invertible mapping:

```
G = T_L o T_U : (z', z) -> (x, y)
G(z', z) = T_L(T_U(z', z))
         = T_L(g(z', z), z)
         = (g(z', z), f(g(z', z), z))
         = (x, y)
```

Since both `T_L` and `T_U` are invertible (they are triangular with invertible diagonal blocks), their composition `G` is also invertible:

```
G^{-1}(x, y) = T_U^{-1}(T_L^{-1}(x, y))
```

The inverse allows recovering `(z', z)` from `(x, y)`, enabling density evaluation via the change-of-variables formula:

```
log p(x, y) = log p_z(z) + log p_{z'}(z') + log |det J_G^{-1}(x, y)|
```

### 4. Training Loss

The model is trained by minimizing a combined loss:

```
L = L_forward + L_inverse + L_joint
```

where:

- **Forward loss** (likelihood fitting): penalizes mismatch between generated `y` and observed data for given `x`:
  ```
  L_forward = E_{x ~ p(x)} [ KL( p(y|x) || q_theta(y|x) ) ]
  ```

- **Inverse loss** (posterior fitting): penalizes mismatch between inferred `x` and true parameters for given `y`:
  ```
  L_inverse = E_{y ~ p(y)} [ KL( p(x|y) || q_theta(x|y) ) ]
  ```

- **Joint loss** (maximum likelihood on the composed map):
  ```
  L_joint = -E_{(x,y) ~ p(x,y)} [ log q_theta(x, y) ]
  ```
  which, via the change-of-variables formula, decomposes into reconstruction of `(z', z)` and the log-determinant of the Jacobian.

### 5. Parameterization via Normalizing Flows

Each component map `f` and `g` is parameterized as a normalizing flow — a composition of simple invertible layers (e.g., affine coupling layers):

```
f(x, z) = h_K o h_{K-1} o ... o h_1 (z; x)
```

where each `h_k` is an affine coupling layer conditioned on `x`:

```
h_k(z; x): z_1 = z_1
            z_2 = z_2 * exp(s_k(z_1, x)) + t_k(z_1, x)
```

with `s_k` and `t_k` being neural networks. The Jacobian determinant is:

```
log |det J_{h_k}| = sum(s_k(z_1, x))
```

## Conclusion

- The paper provides a principled Bayesian framework for constructing **a single invertible generative model** that simultaneously handles forward simulation and inverse inference, by composing upper and lower triangular maps.
- The invertibility guarantees that both the likelihood `p(y|x)` and the posterior `p(x|y)` can be sampled exactly from the same model, eliminating the need for separate forward and inverse networks.
- The composed map inherits tractable Jacobian determinants from the triangular structure, enabling efficient density evaluation and maximum likelihood training.
- Numerical experiments on stylized inverse problems demonstrate that the model accurately recovers both conditional distributions and provides calibrated uncertainty quantification.
- The approach bridges normalizing flows and classical Bayesian inverse problem theory, offering a computationally efficient alternative to MCMC for posterior sampling.
