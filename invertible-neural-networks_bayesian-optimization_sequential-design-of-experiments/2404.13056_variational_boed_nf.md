## Why this paper fits the topic "sequential variation propagation"

순방향 모델 y = f(x, theta) + noise에서 실험 설계 변수 x의 선택이 관측 y의 정보량을 결정하며, 역방향에서는 y로부터 theta를 추론할 때 posterior 분산이 실험 설계에 따라 크게 달라진다. 본 논문은 조건부 가역 신경망(cINN)을 variational distribution으로 사용하여 expected information gain (EIG)의 하한을 최대화하는 실험 설계를 순차적으로 탐색하며, 이 과정에서 posterior 분산을 직접 최소화하는 것과 동등한 효과를 얻는다. Coupling layer 기반 normalizing flow가 비가우시안 및 다봉(multi-modal) posterior를 정확히 포착함으로써, one-to-many 역문제의 모호성을 실험 설계를 통해 체계적으로 줄이는 sequential design 프레임워크를 제공한다.

## Methods

### 1. Expected Information Gain (EIG)

Bayesian OED seeks the design `d*` that maximises the expected information gain:

```
EIG(d) = E_{y|d}[ KL( p(theta|y,d) || p(theta) ) ]
       = E_{y|d}[ H[p(theta)] - H[p(theta|y,d)] ]
       = E_{p(y,theta|d)}[ log p(theta|y,d) - log p(theta) ]
```

Direct computation requires nested Monte Carlo and access to the likelihood, both of which are expensive. Variational OED replaces the intractable posterior with a variational approximation.

### 2. Variational Lower Bound (vOED)

Replace `p(theta|y,d)` with a variational approximation `q_phi(theta|y,d)`:

```
EIG(d) >= EIG_LB(d) = E_{p(y,theta|d)}[ log q_phi(theta|y,d) - log p(theta) ]
```

This is a lower bound because `KL(p||q) >= 0`. The bound is tight when `q_phi = p(theta|y,d)`. The optimisation is:

```
d*, phi* = argmax_{d, phi}  EIG_LB(d, phi)
```

### 3. Conditional Invertible Neural Network (cINN) as Variational Distribution

The variational distribution `q_phi(theta|y,d)` is parameterised as a conditional normalizing flow -- a cINN built from compositions of coupling layers.

**Coupling layer** `C_k`:

```
Input:  (theta_1, theta_2)  [split of theta into two halves]
Output: (theta_1, theta_2')

theta_2' = theta_2 * exp(s_k(theta_1; y, d)) + t_k(theta_1; y, d)
```

where `s_k` and `t_k` are neural networks that take `theta_1` concatenated with the conditioning variables `(y, d)` as input.

The full cINN is a composition of `K` coupling layers with alternating splits:

```
q_phi(theta|y,d) = p_z(T_phi^{-1}(theta; y,d)) * |det J_{T_phi^{-1}}|
```

where `T_phi = C_K o P_K o ... o C_1 o P_1`, `P_k` are permutation layers, and:

```
log |det J| = sum_{k=1}^{K} sum_j s_k^{(j)}(theta_1; y, d)
```

### 4. Summary Network for Data Reduction

When the observation `y` is high-dimensional, a **summary network** `h_psi` compresses it:

```
y_summary = h_psi(y)    [h_psi: R^{d_y} -> R^{d_s}, d_s << d_y]
```

The coupling layers then condition on `(y_summary, d)` instead of `(y, d)`. The summary network parameters `psi` are optimised jointly with the flow parameters `phi`.

### 5. Monte Carlo Gradient Estimators

The lower bound is estimated as:

```
EIG_LB(d, phi) ≈ (1/N) sum_{i=1}^{N} [ log q_phi(theta_i | y_i, d) - log p(theta_i) ]
```

where `(theta_i, y_i) ~ p(theta) p(y|theta, d)` are prior-predictive samples. Gradients w.r.t. both `d` and `phi` are computed via backpropagation through the flow.

### 6. Upper Bound Estimator

An upper bound on EIG uses a variational marginal likelihood:

```
EIG_UB(d) = E_{p(y,theta|d)}[ log p(y|theta,d) ] - E_{p(y|d)}[ log r_psi(y|d) ]
```

where `r_psi(y|d)` is a variational approximation to the marginal `p(y|d)`, also parameterisable by a normalizing flow.

### 7. Sequential OED

For sequential experiments `d_1, d_2, ..., d_T`:

```
d_{t+1} = argmax_d  EIG(d | D_{1:t})
```

where `D_{1:t} = {(d_i, y_i)}_{i=1}^{t}` are past design-observation pairs. The posterior from previous rounds becomes the prior for the next, and a new cINN is trained (or fine-tuned) at each step.

## Conclusion

- **vOED-NFs** achieve lower EIG estimation bias compared to Gaussian or mixture-of-Gaussian variational families, under a fixed computational budget of forward model evaluations.
- A composition of 4-5 coupling layers is sufficient to capture complex, non-Gaussian, and multi-modal posterior distributions.
- The summary network enables scalability to high-dimensional observation spaces without loss of EIG estimation accuracy.
- Validated on benchmark problems (linear Gaussian, nonlinear) and demonstrated on PDE-governed cathodic electrophoretic deposition and stochastic aphid population models.
- The resulting normalizing-flow posteriors agree well with ground-truth posteriors from MCMC, effectively capturing multi-modality and skewness.
- Sequential application progressively reduces posterior uncertainty, demonstrating effective variance control through optimal design selection.
