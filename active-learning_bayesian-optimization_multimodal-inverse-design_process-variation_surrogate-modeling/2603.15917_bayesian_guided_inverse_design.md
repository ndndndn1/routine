# Bayesian-Guided Inverse Design of Hyperelastic Microstructures: Application to Stochastic Metamaterials

- **arXiv**: [2603.15917](https://arxiv.org/abs/2603.15917)
- **Authors**: Hooman Danesh, Henning Wessels
- **Submitted**: 2026-03-16
- **Keywords**: active learning, bayesian optimization, multimodal inverse design, process variation, surrogate modeling, sensitivity-aware sampling

## Methods

This paper addresses the inverse design of hyperelastic microstructures where the goal is to identify a structure achieving a target macroscopic stress response from a pool of 50,000 candidate designs. The key challenge is that brute-force evaluation is infeasible due to costly computational homogenization.

1. **Statistical Feature Engineering for Dimensionality Reduction**: The high-dimensional geometry of candidate microstructures is compressed into low-dimensional descriptors using statistical features (spatial correlation functions, morphological descriptors). This enables the surrogate to operate in a tractable space rather than over raw geometry.

2. **Multi-Output Gaussian Process Surrogate**: A multi-output GP maps the low-dimensional geometric descriptors to effective constitutive parameters of the macroscopic hyperelastic response. The GP provides both predictions and calibrated uncertainty estimates, enabling principled decision-making under limited data.

3. **Uncertainty-Driven Active Learning**: Instead of labeling the entire candidate pool, the framework uses active learning to sequentially select the most informative samples for labeling. The acquisition function prioritizes candidates where the surrogate's predictive uncertainty is highest, thereby maximizing information gain per oracle query. Under severe budget constraints, active learning requires labeling less than 0.5% of the full dataset.

4. **Bayesian-Guided Inverse Selection**: Given a target stress response, the framework evaluates all candidates via the trained surrogate and ranks them by predicted proximity to the target, weighted by predictive confidence. The Bayesian formulation naturally accounts for process variation in the stochastic metamaterials by propagating uncertainty through the surrogate.

5. **Stochastic Metamaterial Context**: The candidate structures are drawn from stochastic processes, introducing inherent process variation. The framework is designed to be robust to this variability, identifying designs whose performance is reliable despite structural randomness.

## Conclusion

The Bayesian-guided framework achieves effective inverse design with less than 0.5% of the candidate pool labeled, demonstrating that uncertainty-driven active learning can drastically reduce the cost of inverse design in settings with expensive oracles. The multi-output GP surrogate accurately captures the structure-property linkage for hyperelastic responses, and the Bayesian formulation naturally propagates uncertainty from stochastic process variations through to design recommendations. The approach is particularly powerful for problems where gradient-based optimization is inapplicable due to non-parameterizable geometries, offering a principled alternative based on surrogate-driven search with active data acquisition.

```python
import numpy as np
from sklearn.gaussian_process import GaussianProcessRegressor
from sklearn.gaussian_process.kernels import RBF, ConstantKernel

class BayesianInverseDesign:
    def __init__(self, feature_dim, response_dim):
        self.feature_dim = feature_dim
        self.response_dim = response_dim
        self.surrogates = [
            GaussianProcessRegressor(
                kernel=ConstantKernel() * RBF(),
                n_restarts_optimizer=5,
                normalize_y=True
            )
            for _ in range(response_dim)
        ]
        self.X_train = None
        self.Y_train = None

    def extract_features(self, microstructure):
        from scipy.ndimage import label
        flat = microstructure.flatten()
        features = [
            np.mean(flat),
            np.std(flat),
            np.corrcoef(flat[:-1], flat[1:])[0, 1],
        ]
        labeled, n_components = label(microstructure > 0.5)
        features.append(n_components / microstructure.size)
        return np.array(features)

    def fit(self, X, Y):
        self.X_train = X
        self.Y_train = Y
        for i, gp in enumerate(self.surrogates):
            gp.fit(X, Y[:, i])

    def predict(self, X):
        means, stds = [], []
        for gp in self.surrogates:
            mu, sigma = gp.predict(X, return_std=True)
            means.append(mu)
            stds.append(sigma)
        return np.column_stack(means), np.column_stack(stds)

    def acquisition_uncertainty(self, X_pool):
        _, stds = self.predict(X_pool)
        return np.mean(stds, axis=1)

    def active_learning_step(self, X_pool, batch_size=1):
        scores = self.acquisition_uncertainty(X_pool)
        selected = np.argsort(scores)[-batch_size:]
        return selected

    def inverse_design(self, target_response, X_candidates, top_k=5):
        means, stds = self.predict(X_candidates)
        errors = np.linalg.norm(means - target_response, axis=1)
        avg_std = np.mean(stds, axis=1)
        score = errors + 0.5 * avg_std
        best_indices = np.argsort(score)[:top_k]
        return best_indices, means[best_indices], stds[best_indices]
```
