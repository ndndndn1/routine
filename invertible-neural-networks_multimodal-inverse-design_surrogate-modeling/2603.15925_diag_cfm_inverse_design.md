# Generative Inverse Design with Abstention via Diagonal Flow Matching

- **arXiv:** [2603.15925](https://arxiv.org/abs/2603.15925)
- **Authors:** Miguel de Campos, Werner Krebs, Hanno Gottschalk
- **Submitted:** 2026-03-16
- **Keywords:** Invertible Neural Networks, Multimodal inverse design, surrogate modeling

## Methods

1. **Diagonal Flow Matching (Diag-CFM)**
   - 기존 Conditional Flow Matching(CFM)을 역설계에 적용할 때, 설계 파라미터의 임의 순서(ordering)와 스케일링에 극도로 민감한 문제를 식별
   - Zero-anchoring 전략: 설계 좌표(design coordinates)는 noise와, 라벨(label)은 zero와 쌍을 이루도록 대각(diagonal) 경로를 구성
   - 이로써 좌표 순열(coordinate permutation)에 대해 학습이 **증명 가능하게 불변(provably invariant)**
   - CFM 및 INN 대비 round-trip accuracy에서 1~2 자릿수 개선, 설계 차원 P=100까지 확장 가능

2. **Architecture-Intrinsic Uncertainty Metrics**
   - **Zero-Deviation**: 생성된 설계가 zero-anchored path에서 벗어나는 정도를 측정 — OOD 타깃 감지
   - **Self-Consistency**: 동일 타깃에서 복수 생성을 수행한 뒤 round-trip 일관성을 평가
   - 외부 앙상블이나 MC-Dropout 없이도 신뢰도 기반 abstention(기권) 가능

3. **Abstention Mechanism**
   - 신뢰도가 낮은 예측을 자동으로 기각하여, 물리적으로 불가능한 해를 출력에서 제거
   - 여러 후보 중 최적 후보 선택(best candidate selection)에도 활용

4. **Benchmark**
   - 해석적 벤치마크, 에어포일 역설계, 가스터빈 연소기 역설계에서 검증
   - 다봉(multimodal) 해 공간에서 모드 커버리지와 물리적 타당성을 동시에 달성

## Conclusion

- 기존 CFM/INN 방법의 좌표 순서 의존성 문제를 Diag-CFM으로 해결
- 내재적 불확실성 지표가 추가 비용 없이 OOD 감지와 abstention을 가능하게 함
- One-to-many 역설계에서 해의 다중성 문제를 flow-based generative model + abstention으로 효과적으로 억제
- 고차원(P=100) 설계 공간에서도 안정적으로 작동
