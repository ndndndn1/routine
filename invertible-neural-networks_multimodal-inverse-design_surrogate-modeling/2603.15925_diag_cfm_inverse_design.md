# Generative Inverse Design with Abstention via Diagonal Flow Matching

- **arXiv**: https://arxiv.org/abs/2603.15925
- **Authors**: Miguel de Campos, Werner Krebs, Hanno Gottschalk
- **Published**: 2026-03
- **Categories**: cs.LG
- **Keywords**: invertible neural networks (flow matching), multimodal inverse design, surrogate modeling

## Methods

본 논문은 conditional flow matching(CFM)을 역설계에 적용할 때 발생하는 좌표 순서/스케일 민감도 문제를 해결하고, out-of-distribution 타겟에 대해 "기권(abstention)" 메커니즘을 도입한다.

핵심 구성:
1. **Conditional Flow Matching의 역설계 적용 문제**: 표준 CFM은 라벨(타겟)과 설계 파라미터를 paired하여 학습하지만, 설계 파라미터의 임의적 순서와 스케일링에 강하게 민감하여 학습 불안정 초래.
2. **Diagonal Flow Matching (Diag-CFM)**: "Zero-anchoring" 전략 도입.
   - 설계 좌표(design coordinates)를 noise와 pair, 라벨(target labels)을 zero와 pair.
   - 이 구조가 좌표 순열(permutation)에 대해 증명적으로 불변(invariant).
   - 기존 CFM 및 INN 대비 round-trip accuracy에서 order-of-magnitude 향상.
3. **Abstention Mechanism**: 학습 분포 외의 타겟이 주어졌을 때, 생성된 설계의 신뢰도를 평가하여 무효한 설계를 거부. 역설계의 hallucination 문제에 대응.
4. **Round-trip Consistency**: 생성된 설계 x를 forward model에 통과시켜 타겟 y와 비교하는 round-trip 평가. Diag-CFM이 표준 CFM 대비 현저히 높은 일관성.

다중성 억제 및 탐색 공간 제어:
- Flow matching의 연속적 변환이 설계 공간의 다중 모드를 학습 → 다양한 유효 해 생성.
- Permutation invariance로 인한 불필요한 대칭 모드 제거 → 실질적 탐색 공간 축소.
- Abstention으로 OOD 영역의 비유효 해 자동 배제.
- 높은 round-trip accuracy가 역매핑의 신뢰성 보장.

## Conclusion

- Diag-CFM이 설계 차원 증가에 따라 기존 CFM 및 INN 대비 round-trip accuracy에서 큰 폭의 우위.
- Zero-anchoring이 좌표 순열 불변성을 수학적으로 보장하여 학습 안정성 확보.
- Abstention 메커니즘이 infeasible target에 대한 잘못된 설계 생성을 방지.
- 다양한 설계 차원(low-dim ~ high-dim)에서 일관된 성능.
- INN(invertible neural network) baseline 대비 더 유연한 아키텍처 선택 가능(strict architectural constraints 불필요).
- 한계: 연속 설계 파라미터에 한정. 이산(discrete) 설계 변수 처리 미검증.

## Code

공식 코드 미공개. 아래는 Diagonal Flow Matching 기반 역설계의 핵심 재현 구현.

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
import numpy as np


class VelocityNetwork(nn.Module):
    """Neural network predicting velocity field for flow matching."""
    def __init__(self, design_dim, label_dim, hidden_dim=256, time_embed_dim=32):
        super().__init__()
        self.time_embed = nn.Sequential(
            nn.Linear(1, time_embed_dim),
            nn.SiLU(),
            nn.Linear(time_embed_dim, time_embed_dim),
        )
        self.net = nn.Sequential(
            nn.Linear(design_dim + label_dim + time_embed_dim, hidden_dim),
            nn.SiLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.SiLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.SiLU(),
            nn.Linear(hidden_dim, design_dim),
        )

    def forward(self, x_t, y, t):
        t_emb = self.time_embed(t.unsqueeze(-1))
        inp = torch.cat([x_t, y, t_emb], dim=-1)
        return self.net(inp)


class DiagonalFlowMatching(nn.Module):
    """
    Diagonal Flow Matching (Diag-CFM) for inverse design.
    Zero-anchoring strategy: design coords paired with noise, labels with zero.
    """
    def __init__(self, design_dim, label_dim, hidden_dim=256):
        super().__init__()
        self.design_dim = design_dim
        self.label_dim = label_dim
        self.velocity_net = VelocityNetwork(design_dim, label_dim, hidden_dim)

    def compute_loss(self, designs, labels):
        """
        Training loss with zero-anchoring:
        - x_0 ~ N(0, I) (noise source for design)
        - x_1 = design (target design)
        - Label conditioning: y is provided as-is (anchored at zero in the paired space)
        """
        batch_size = designs.shape[0]
        t = torch.rand(batch_size, device=designs.device)

        # Source noise
        x_0 = torch.randn_like(designs)

        # Interpolation (OT path)
        x_t = (1 - t.unsqueeze(-1)) * x_0 + t.unsqueeze(-1) * designs

        # Target velocity (straight-line OT)
        target_v = designs - x_0

        # Predicted velocity
        pred_v = self.velocity_net(x_t, labels, t)

        return F.mse_loss(pred_v, target_v)

    @torch.no_grad()
    def sample(self, labels, n_steps=100):
        """Generate designs conditioned on target labels via ODE integration."""
        batch_size = labels.shape[0]
        x = torch.randn(batch_size, self.design_dim, device=labels.device)

        dt = 1.0 / n_steps
        for i in range(n_steps):
            t = torch.full((batch_size,), i * dt, device=labels.device)
            v = self.velocity_net(x, labels, t)
            x = x + v * dt

        return x

    @torch.no_grad()
    def sample_diverse(self, labels, n_samples=50, n_steps=100):
        """Generate multiple diverse designs for the same target."""
        labels_expanded = labels.unsqueeze(0).expand(n_samples, -1, -1).reshape(-1, self.label_dim)
        designs = self.sample(labels_expanded, n_steps)
        return designs.view(n_samples, -1, self.design_dim)


class AbstentionMechanism:
    """Detect OOD targets and abstain from generating unreliable designs."""
    def __init__(self, forward_model, diag_cfm, threshold=0.1):
        self.forward_model = forward_model
        self.diag_cfm = diag_cfm
        self.threshold = threshold

    def round_trip_score(self, target_labels, n_samples=20, n_steps=100):
        """Compute round-trip consistency: generate design -> predict label -> compare."""
        designs = self.diag_cfm.sample_diverse(target_labels, n_samples, n_steps)
        designs_flat = designs.view(-1, designs.shape[-1])

        with torch.no_grad():
            predicted_labels = self.forward_model(designs_flat)

        target_expanded = target_labels.expand(n_samples, -1, -1).reshape(-1, target_labels.shape[-1])
        errors = (predicted_labels - target_expanded).abs().mean(dim=-1)
        errors = errors.view(n_samples, -1)

        # Mean and variance of round-trip error
        mean_error = errors.mean(dim=0)
        std_error = errors.std(dim=0)
        return mean_error, std_error

    def should_abstain(self, target_labels, n_samples=20):
        """Return True if the target is likely OOD (high round-trip error)."""
        mean_err, std_err = self.round_trip_score(target_labels, n_samples)
        return (mean_err > self.threshold).any().item()

    def generate_with_abstention(self, target_labels, n_candidates=50, n_steps=100):
        """Generate designs, rejecting OOD targets."""
        if self.should_abstain(target_labels):
            return None, "ABSTAINED: target likely out-of-distribution"

        designs = self.diag_cfm.sample_diverse(target_labels, n_candidates, n_steps)
        designs_flat = designs.view(-1, designs.shape[-1])

        # Validate each candidate
        with torch.no_grad():
            predicted = self.forward_model(designs_flat)
        target_exp = target_labels.expand(n_candidates, -1, -1).reshape(-1, target_labels.shape[-1])
        errors = (predicted - target_exp).abs().mean(dim=-1)

        # Filter valid designs
        valid_mask = errors < self.threshold
        valid_designs = designs_flat[valid_mask]

        if len(valid_designs) == 0:
            return None, "ABSTAINED: no valid designs generated"

        return valid_designs, f"Generated {len(valid_designs)} valid designs"


def train_diag_cfm(model, dataloader, epochs=1000, lr=1e-3):
    """Train Diagonal Flow Matching model."""
    optimizer = torch.optim.AdamW(model.parameters(), lr=lr)
    scheduler = torch.optim.lr_scheduler.CosineAnnealingLR(optimizer, epochs)

    for epoch in range(epochs):
        total_loss = 0
        for designs, labels in dataloader:
            optimizer.zero_grad()
            loss = model.compute_loss(designs, labels)
            loss.backward()
            torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)
            optimizer.step()
            total_loss += loss.item()
        scheduler.step()
    return model
```
