## Why this paper fits the topic "sequential variation propagation"

다대일 순방향 문제를 역으로 풀 때 사후분포(posterior)가 다봉(multimodal)이 되는 것은 해의 다중성(ambiguity)의 직접적 표현이다. 표준 normalizing flow는 단봉(unimodal) 기저 분포에서 시작하므로, 분리된 모드 사이에 **가짜 확률 다리(spurious probability bridge)** 를 만들어 탐색 공간을 부정확하게 팽창시킨다. 이 논문은 **likelihood-weighted importance sampling** 과 **GMM 초기화** 를 결합하여 다봉 사후분포의 위상 구조(topology)를 정확히 포착하고, 역문제의 분산을 효과적으로 제어한다.

## Methods

### 1. Likelihood-Weighted Training

사후분포 샘플 없이, likelihood 평가만으로 normalizing flow를 학습:

```
L = E_z~q(z|x) [ w(z) · (-log p_flow(z)) ]

w(z) = L(x|z) / q(z|x)   (importance weight)
```

- 사전 분포(prior)에서 샘플링 → likelihood로 가중 → flow가 사후분포 직접 학습
- MCMC 등 사후 샘플 생성 불필요 → **amortized** inference

### 2. GMM Base Distribution

표준 가우시안 대신 **Gaussian Mixture Model(GMM)** 을 기저 분포로 사용:

```
p_base(z) = Σₖ πₖ · N(z | μₖ, Σₖ)
```

- GMM의 컴포넌트 수 K를 목표 사후분포의 모드 수에 맞춤
- 각 컴포넌트가 개별 모드로 매핑되어 **분리된 지지(disconnected support)** 정확 포착
- 단봉 기저 분포의 spurious bridge 문제를 근본적으로 해결

### 3. Flow Architecture

RealNVP 또는 NSF(Neural Spline Flow) 기반의 invertible 변환:

```
z → T₁ → T₂ → ... → Tₗ → θ  (parameter space)
```

- 각 변환 Tᵢ는 가역(invertible)하고 Jacobian이 해석적
- GMM 기저 → flow 변환 → 다봉 사후분포의 정확한 근사

### 4. 검증

- 2D/3D multi-modal 벤치마크에서 모드 포착 정확도 평가
- GMM 초기화가 distance/divergence 메트릭에서 **단봉 기저 대비 현저한 개선**
- 고차원 역문제에서 amortized inference의 확장성 검증

## Conclusion

- 단봉 기저 분포를 사용하는 기존 normalizing flow는 다봉 사후분포에서 **모드 간 가짜 확률 밀도**를 생성하여 역문제의 해 공간을 왜곡한다.
- GMM 기저 + likelihood-weighted 학습이 이 문제를 해결하여, 다봉 사후분포의 **위상 구조를 보존**하면서 정확한 밀도 추정을 달성.
- Amortized 접근법이므로 새로운 관측에 대해 MCMC 없이 즉시 사후 추론 가능.
- 역문제의 해 다중성(ambiguity)에서 비롯되는 탐색 공간 팽창을, 기저 분포의 구조적 설계를 통해 근본적으로 억제.
